# 커밋 전 민감정보 검사 (git 훅)

이 저장소와 `guide.bdseasy.com` 은 **누구나 봅니다.**
한 번 푸시하면 커밋을 지워도 해시로 접근되고 포크·캐시에 남습니다.

그래서 커밋할 때 **자동으로 한 번 걸러 줍니다.** 사람이 손으로 커밋해도 걸립니다.

## 한 번만 켜면 됩니다

저장소를 새로 받으셨다면 이 한 줄을 실행하세요. **한 번이면 됩니다.**

```bash
git config core.hooksPath .githooks
```

`git config core.hooksPath` 를 쳤을 때 `.githooks` 가 나오면 켜져 있는 것입니다.

## 무엇을 검사하나

| 언제 | 무엇을 |
| --- | --- |
| `pre-commit` | 커밋에 담기는 **파일 내용** |
| `commit-msg` | **커밋 메시지** — 파일보다 여기서 새기 쉽습니다 |

찾는 것은 다섯 가지입니다.

- 주민등록번호
- 휴대폰번호
- 토큰·비밀키 (`ghp_…`, `github_pat_…`, `sk-…`, AWS 키, 개인키 블록)
- **지번주소** — `○○동 000-00번지` 처럼 가린 줄은 넘어갑니다
- **금지어 목록** — 아래 참고

스크린샷(`.png`)은 기계가 읽지 못해 검사하지 않습니다.
**찍은 뒤 한 장씩 눈으로 확인**하는 규칙이 따로 있습니다 → `CLAUDE.md` 의 「스크린샷」

## 걸렸을 때

무엇이 어느 줄에 있는지 보여주고 커밋을 멈춥니다. 셋 중 하나를 하시면 됩니다.

1. **실제 정보면** — 가상 데이터나 `○○` 표기로 바꿉니다
2. **예시·공개정보라 괜찮으면** — `allow.txt` 에 그 문자열을 한 줄 추가합니다
3. **판단이 어려우면** — 커밋하지 마시고 작업자에게 확인합니다

정말 의도한 것이라면 `git commit --no-verify` 로 넘길 수 있습니다.
**다만 그건 "알고 올린다"는 뜻입니다.**

## 파일

| 파일 | 무엇 |
| --- | --- |
| `scan.sh` | 실제 검사를 하는 스크립트 |
| `pre-commit` · `commit-msg` | git이 부르는 훅 |
| `allow.txt` | **괜찮은 문자열.** 사무소 공개 전화, 체험 계정, 예시 번호가 들어 있습니다 |
| `deny.local.txt` | **이 컴퓨터에만 두는 금지어 목록.** 실제 단지명·계정이 들어가므로 `.gitignore` 에 있습니다 |

`deny.local.txt` 는 저장소에 올라가지 않습니다. **그 목록 자체가 민감하기 때문입니다.**
새 컴퓨터에서 작업하실 때는 직접 만드시면 됩니다 — 한 줄에 하나씩, 막고 싶은 말을 적습니다.

```
(실제 법정동 이름)
(실제 단지명)
(사무소 실계정 아이디)
```

이 예시에도 **실제 이름을 적지 마세요.** 이 파일은 저장소에 올라갑니다.

없어도 나머지 검사는 그대로 동작합니다.

## 직접 검사해 보기

커밋 전에 저장소 전체를 훑어보고 싶으시면.

```bash
for f in $(git ls-files); do sh .githooks/scan.sh "$f" "$f"; done
```
