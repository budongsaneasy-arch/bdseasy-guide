# 화면 설명

각 화면의 버튼과 입력 항목이 무엇을 하는지 찾아보는 곳입니다.
처음 배우실 때는 [업무별 방법](/howto/contract-apartment)을 보시고,
특정 항목이 무슨 뜻인지 확인하실 때 여기를 쓰세요.

## 돈이 얼마나 드나

값이 궁금하실 때 여기부터 보세요. **세 문서가 금액의 기준**입니다.

| 문서 | 무엇이 있나 |
| --- | --- |
| [**요금제 — 베이직과 플러스**](/reference/plan) | 월 2,000원으로 무엇이 더 되나. 무료로 어디까지 되나 |
| [**공적장부 — 서류와 수수료**](/reference/public-records-fee) | 등기 700원 · 나머지 무료 · 하루 몇 건까지 |
| [**네이버 광고 — 가격과 노출순위**](/reference/naver-ad-price) | 멤버십 99,000원 · 전송비 1,530~50,500원 · 순위 보는 법 |
