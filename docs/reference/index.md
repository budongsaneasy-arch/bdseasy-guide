# 화면 설명

각 화면의 버튼과 입력 항목이 무엇을 하는지 찾아보는 곳입니다.
처음 배우실 때는 [업무별 방법](/howto/contract-apartment)을 보시고,
특정 항목이 무슨 뜻인지 확인하실 때 여기를 쓰세요.

## 준비 중입니다

아래 순서로 채울 예정입니다. 강의자료에 이미 표로 정리된 것부터 옮깁니다.

| 문서 | 상태 |
| --- | --- |
| 요금제 — 베이직과 플러스는 무엇이 다른가 | 준비 중 |
| 공적장부 — 뗄 수 있는 서류와 수수료 | 준비 중 |
| 네이버 광고 — 상품별 가격과 노출순위 | 준비 중 |
| 매물 접수 화면 — 입력 항목 전체 | 준비 중 |
| 계약서 — 종류 9가지와 각각 언제 쓰나 | 준비 중 |
| 확인설명서 — 기본·세부 확인사항 항목 전체 | 준비 중 |

::: tip 이 종류를 나중에 만드는 이유
"화면 설명"은 분량이 가장 많고 가장 빨리 낡습니다.
업무별 방법 문서 10개가 자리 잡기 전에 여기를 먼저 채우면,
화면이 한 번 바뀔 때 고칠 곳이 감당이 안 됩니다.
:::
