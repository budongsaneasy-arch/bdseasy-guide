# 네이버 광고 — 가격과 노출순위

> **어디서 보나** 멤버십·충전금은 **렛츠** 화면, 순위는 `매물 → N 광고 관리`

**돈이 두 번 나갑니다.** 이걸 모르고 멤버십만 결제했다가 광고가 안 나가는 일이 가장 많습니다.

| 언제 | 무엇 | 얼마 |
| --- | --- | ---: |
| **처음 한 번** | 렛츠 **멤버십** (6개월) | **99,000원** |
| **매물 보낼 때마다** | **충전금**에서 전송비 차감 | 아래 표 |

## 전송 단가 — 검증방식에 따라 33배 차이입니다

충전금에서 **매물 한 건을 보낼 때마다** 빠집니다.

| 검증방식 | 전송가격(부가세 포함) | 알아두실 것 |
| --- | ---: | --- |
| **현장확인2** | **50,500원** | 사업자등록번호당 **100건까지 12,000원**으로 할인<br>100건은 **모든 CP사 합산** |
| **일반현장확인** | **21,100원** | 부산·인천·대구·대전·경북 경산·경기 양주·경남 양산·세종은 **4,600원**<br>서울·경기의 빌라/연립·단독/다가구는 **10,100원** |
| **원룸현장확인** | **2,900원** | 월 100건 넘으면 21,100원 적용 |
| **홍보확인서** | **2,030원** | |
| **신홍보확인서** | **1,530원** | **등기부등본 첨부** 방식 |
| **모바일확인 · 모바일확인2**(집주인확인) | **1,530원** | |

*(2026.09 기준. 정확한 금액은 렛츠 충전 화면에서 확인하세요)*

화면 아래에 이런 단서가 붙어 있습니다.

> 충전금 전송 단가는 네이버 정책 및 매물의 조건에 따라 추가로 조정(무료, 하향 혹은 상향)될 수 있음

::: danger 검증방식을 잘못 고르면 한 건에 5만원이 나갑니다
**현장확인2(50,500원)와 신홍보확인서(1,530원)는 33배 차이**입니다.
전송 버튼을 누르면 **되돌릴 수 없고 환급도 되지 않습니다.**

**재검증도 돈이 다시 듭니다.** 검증에 실패하면 고치고 다시 보내야 하는데, 그때 또 차감됩니다.
보내기 전에 **의뢰인 성명·연락처가 등기와 맞는지** 반드시 확인하세요.
:::

::: tip 충전금은 만기가 없습니다
멤버십은 6개월이지만 **충전금은 기한이 없습니다.** 남으면 다음에 씁니다.
**법인은 계좌이체가 안 됩니다** — 카드로만 충전됩니다.
:::

## 노출순위 보는 법

`매물 → N 광고 관리`에 두 가지 순위가 나옵니다.

| 항목 | 뜻 |
| --- | --- |
| **매물전체순위** | 네이버에서 그 조건으로 검색했을 때 내 매물이 몇 번째인가 |
| **동일매물순위** | `3 / 38` = **같은 매물을 38곳이 광고 중이고 내가 3번째** |

별 색으로 구간을 구분합니다.

| 표시 | 뜻 |
| --- | --- |
| 별 + 숫자 | 그 순위. **1~3 / 4~6 / 7~9 / 10~20** 구간마다 별 색이 다릅니다 |
| **⚠ 순위 밖** | 매물전체순위가 **20위 밖**이라는 뜻입니다 |

## 알림 세 가지가 「왜 밀렸나」의 답입니다

| 알림 | 뜻 |
| --- | --- |
| **가격** | 나보다 **싸게 올린 곳**이 있습니다 |
| **사진** | 사진 수가 부족합니다 |
| **설명** | 매물 설명이 부족합니다 |

알림은 **순위를 갱신할 때 함께 갱신**됩니다.

## 비용을 아끼는 순서

1. **신홍보확인서(1,530원)로 시작하세요.** 등기부등본만 있으면 됩니다
2. 등기는 **발급 후 120일 이내분**만 첨부됩니다. 접수 단계에서 미리 떼어두면 재발급이 필요 없습니다
3. **접수할 때 사진을 충실히** 올려두면 광고에 자동 첨부되어 「사진」 알림이 줄어듭니다

→ [공적장부 서류와 수수료](/reference/public-records-fee)

::: warning 이 단계 문의는 렛츠로 하세요
결제·승인·환불은 **렛츠 담당**입니다. **렛츠 고객센터 02-430-4909** (평일 09~18시, 점심 12:30~13:30)
부동산이지 고객센터에서는 처리할 수 없습니다.
:::
