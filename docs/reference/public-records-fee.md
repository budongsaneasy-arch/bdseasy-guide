# 공적장부 — 뗄 수 있는 서류와 수수료

> **어디서 보나** `부동산 원장 → 공적장부` &nbsp;·&nbsp; 매물 접수 화면과 계약서 작성 화면에서도 들어갑니다

**돈이 드는 것은 등기 두 가지뿐입니다.** 나머지 대장류는 전부 무료입니다.

## 서류와 비용

| 서류 | 어디서 | 비용 | 열람/발급 |
| --- | --- | ---: | --- |
| 부동산 등기사항증명서(**건물**) | 등기소 | **700원** | 열람 |
| 부동산 등기사항증명서(**토지**) | 등기소 | **700원** | 열람 |
| 일반건축물대장 | 세움터 | 무료 | 발급 |
| 집합건축물대장 (총괄표제부 · 표제부 · 전유부) | 세움터 | 무료 | 발급 |
| 건축물대장 다가구주택의 호(가구)별 면적대장 | 세움터 | 무료 | 발급 |
| 토지대장 · 임야대장 | 정부24 | 무료 | 발급 |
| 지적도 · 임야도 | 정부24 | 무료 | 발급 |
| 대지권등록부 | 정부24 | 무료 | 발급 |
| 토지이용계획확인서 | 토지이음 | 무료 | 열람 |

*(2026.09 기준)*

::: warning 열람과 발급은 다릅니다
**열람한 공부는 법적 효력이 없습니다.** 계약서 작성에 쓰는 공부는 반드시 **발급**받으시고,
발급받은 서류에 **직인이 찍혀 있는지** 확인하세요.
:::

## 하루 몇 건까지 되나

| | 베이직 | 플러스 |
| --- | --- | --- |
| 공적장부 일괄열람 | **하루 3건** | **하루 10건** |
| 등기사항증명서 | **제한 없음** (건당 700원) | **제한 없음** (건당 700원) |

::: tip 「1건」은 서류 한 장이 아니라 요청 한 번입니다
여러 장부를 한꺼번에 골라 **발급요청을 한 번 누르면 1건**입니다.
2026.09 시연에서 **9종을 한 번에 신청해도 1건**으로 계산되는 것을 확인했습니다.

그러니 한 주소의 공부는 **한 번에 다 고르는 편**이 이득입니다. 나눠 누르면 한도만 깎입니다.
:::

## 비용이 어떻게 빠지나

등기는 **포인트**에서 빠집니다. 미리 충전해 두셔야 합니다.
→ [등기 열람 포인트 충전하기](/howto/points)

| | |
| --- | --- |
| **부가세** | 본사 부담입니다. 700원만 나갑니다 |
| **발급 실패** | 차감된 포인트가 **즉시 반환**됩니다. 충전내역에 「등기 발급 취소」로 남습니다 *(2026.09 실증)* |
| **보관 기간** | **3년**. 그동안 언제든 다시 내려받을 수 있습니다 |
| **재발급** | 이미 뗀 서류를 다시 보는 것은 **돈이 들지 않습니다** |

## 이 서류들이 어디에 쓰이나

한 번 떼면 **세 곳에서 다시 씁니다.** 그래서 공부를 먼저 떼는 것이 모든 업무의 출발점입니다.

| 어디 | 무엇이 채워지나 |
| --- | --- |
| **매물 접수** | 구조 · 주용도 · 면적 · 지목 · 대지권 |
| **확인설명서** | ① 대상물건의 표시 · ② 권리관계 · ③ 토지이용계획 |
| **네이버 광고** | 등기부등본이 **자동 첨부**됩니다 (발급 후 **120일** 이내분만) |

→ [왜 대장이 먼저인가](/concept/why-records-first)
