# 요금제 — 베이직 · 플러스 · 프로는 무엇이 다른가

> **어디서 보나** `마이페이지 → 결제 관리`의 **구독정보** 탭

| | **베이직** | **플러스** <small>실속</small> | **프로** <small>추천</small> |
| --- | --- | --- | --- |
| 요금 | **평생 무료** | **월 2,000원** / 6개월 10,000원 <br>*(부가세 별도)* | **월 30,000원** / 6개월 150,000원 <br>*(부가세 별도)* |

**결제하지 않아도 중개 업무는 다 됩니다.** 원장·매물·의뢰·계약·계약서·일정 모두 베이직에 들어 있습니다.
**플러스는 AI와 한도**를, **프로는 통화녹음·AI 점검 같은 새 기능과 더 큰 한도**를 더하는 요금제입니다.

## 네이버 광고비는 요금제와 별개입니다

네이버 부동산 광고는 어느 요금제든 **부동산이지가 광고비를 더 받지 않습니다** (원가 전송).

다만 네이버 광고는 **렛츠(CP사)** 를 거치므로, **렛츠 멤버십 99,000원/6개월**과
**광고상품별 전송비(건당)** 가 렛츠 쪽에 따로 듭니다.
→ [네이버 광고 가격과 노출순위](/reference/naver-ad-price)

## 바꾸는 곳

`마이페이지 → 결제 관리`의 **구독** 탭에서 바꿉니다. 결제 내역은 **결제내역** 탭, 쿠폰은 **쿠폰** 탭입니다.

쓰던 요금제가 남아 있는 상태에서 상위 요금제로 바꾸면 **남은 금액만큼 빼고 차액만 결제**됩니다.
결제 전에 차감 금액과 결제 금액이 화면에 먼저 표시됩니다.
