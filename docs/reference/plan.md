# 요금제 — 베이직과 플러스는 무엇이 다른가

> **어디서 보나** `마이페이지 → 결제 관리`의 **구독정보** 탭

| | **베이직** | **플러스** |
| --- | --- | --- |
| 요금 | **평생 무료** | **월 2,000원** / **6개월 10,000원** <br>*(부가세 별도)* |

**결제하지 않아도 중개 업무는 다 됩니다.** 원장·매물·의뢰·계약·계약서·일정 모두 베이직에 들어 있습니다.
플러스는 **AI와 한도**를 더 쓰는 요금제라고 보시면 맞습니다.

## 무엇이 다른가

| 기능 | 베이직 | 플러스 |
| --- | --- | --- |
| **기본 기능** <br>원장관리 · 원장지도 · 매물관리 · 매물접수 · 의뢰관리 · 계약관리 · 계약서작성 · 일정관리 | 무료 | 포함 |
| **확인설명서 자동 작성** (과태료 방지) | 무료 | 포함 |
| **매물 요약표 · 창문게시용 매물장** 자동 생성 | 제공 | 포함 |
| **네이버 부동산 광고** · 노출 순위(전체·묶음) | 원가 전송 | 원가 전송 |
| **AI 권리분석 · AI 특약 · AI 광고 설명글** | **✕** | **제공** |
| **공적장부 일괄열람** | **하루 3건** | **하루 10건** |
| **등기사항증명서 변동 알림** | 5건 | 10건 |
| **직원 관리** (재직중 기준) | 1인 | 2인 |
| **매물 사진 등록** | 100장 | 1,000장 |
| **스마트폰 고객관리 · 콜백기능** | **✕** | **제공** |
| **등기·대장 파싱** <br>특약·확인설명서·소유권에 자동입력 | **✕** | **제공** |

::: tip 공적장부 하루 한도는 「요청 1회」 기준입니다
여러 장부를 한꺼번에 골라 **발급요청을 한 번 누르면 1건**으로 셉니다.
그래서 베이직 하루 3건이라도 **한 주소의 공부 전체를 세 번** 뗄 수 있습니다.

**등기사항증명서는 한도에 포함되지 않습니다.** 대신 건당 700원이 나갑니다.
→ [공적장부 서류와 수수료](/reference/public-records-fee)
:::

::: warning 중개사무소 홈페이지는 요금제와 관계없이 쓰실 수 있습니다
구독정보 화면에는 **「부동산 매물 광고용 중개사무소 홈페이지 제공」이 플러스 전용**으로 적혀 있습니다.
**지금은 아닙니다.** 이지허브 전체 포털도, 사무소 홈페이지도 **전 요금제에 제공**됩니다.
*(2026.09 개발팀 확인 — 화면 표기는 수정 요청 중)*
→ [이지허브에 매물 올리고 의뢰 받기](/howto/ez-hub)
:::

## 네이버 광고비는 요금제와 별개입니다

표에 **원가 전송**이라고 적힌 그대로입니다. 베이직이든 플러스든 **부동산이지가 광고비를 더 받지 않습니다.**

네이버 광고는 **렛츠(CP사)** 를 거치고, **렛츠 멤버십과 광고상품별 전송비**가 따로 듭니다.
→ [네이버 광고 가격과 노출순위](/reference/naver-ad-price)

## 바꾸는 곳

`마이페이지 → 결제 관리`의 **구독** 탭에서 바꿉니다. 결제 내역은 **결제내역** 탭, 쿠폰은 **쿠폰** 탭입니다.
