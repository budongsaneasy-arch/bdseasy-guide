## 접속이 안 되시나요

::: details 처음이신가요 — 가입하기
1. [bdseasy.com](https://bdseasy.com/)에서 **회원가입**을 누릅니다.
   공인중개사 자격 확인을 위해 **등록번호**가 필요합니다.
2. 사무소 정보를 입력하고 **인증**을 받습니다. 보통 당일 안에 처리됩니다.
3. 로그인해서 **첫 매물을 하나 등록**해 봅니다.
   → 이어서 [가입부터 첫 계약서까지](/start/first-contract)를 따라가세요.

가입은 무료이고, 계약서와 확인설명서 작성에는 비용이 들지 않습니다.
등기부·대장 열람 수수료와 네이버 광고비만 별도입니다.
:::

::: details 아이디나 비밀번호를 잊으셨나요
1. 로그인 화면에서 **아이디 찾기**를 누릅니다.
   가입할 때 쓰신 **이메일 또는 휴대폰 번호** 기준입니다.
2. 아이디가 확인되면 **비밀번호 재설정** 메일이 갑니다.
   메일이 안 오면 스팸함을 먼저 확인해 주세요.
3. 그래도 안 되면 **help@neobsoft.co.kr** 또는 **010-9699-5350**.
   사무소 등록번호를 함께 알려주시면 처리가 빠릅니다.

사무소를 이전하셨거나 대표자가 바뀐 경우는 계정 이관 절차가 따로 있습니다.
:::

::: details 가입 전에 먼저 둘러보고 싶어요
체험용 화면에서 샘플 매물로 계약서를 한 장 만들어 보실 수 있습니다.
저장과 출력까지 모두 되고, 실제 매물·고객 데이터와는 완전히 분리되어 있습니다.

> **준비 중입니다.** 체험 계정 발급 방식이 정해지면 이 자리에 안내가 올라갑니다.
> 공개된 공용 아이디를 쓰면 여러 분이 같은 화면에서 서로의 연습 데이터를 지우게 되므로,
> 1인 1계정 방식으로 준비하고 있습니다.
:::

## 자주 막히는 곳

1. 확인설명서 내용이 계약서에 안 넘어올 때
2. 네이버 부동산 연동이 끊겼을 때
3. 같은 단지 다른 호수인데 정보가 섞여 보일 때
4. 계약서를 출력하면 글자가 밀려 나올 때
5. 등기부 열람이 실패할 때

문의 메일·전화 응대 메모·카페 질문글·유튜브 댓글에서 최근 3개월치를 모아
중복이 많은 순으로 다시 정리하세요. 이 순서가 문서를 쓰는 순서입니다.
:::
