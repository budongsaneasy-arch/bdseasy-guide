# 네이버 부동산 CP 연동이란

> 조작 방법이 아니라 **구조를 이해하기 위한 문서**입니다.
> 연동이 왜 끊기는지, 순위가 왜 밀리는지를 알려면 이 구조를 먼저 아셔야 합니다.

## 한 문장으로

네이버 부동산에는 중개사가 매물을 직접 올릴 수 없습니다.
**네이버가 인정한 매물 정보 제공사(CP, Content Provider)를 거쳐야만** 올라갑니다.
부동산이지는 그 CP 중 하나인 **렛츠**와 연결되어 있습니다.

## 매물이 광고로 나가는 경로

```
부동산이지에 등록한 매물
        ↓  (연동)
      렛츠 (CP)
        ↓  (송출)
    네이버 부동산 노출
```

중간에 한 단계가 더 있다는 것이 중요합니다.
**부동산이지에서 매물을 고쳐도 네이버에 곧바로 반영되지 않습니다.**
렛츠를 거쳐 네이버로 넘어가는 데 시간이 걸리고, 그 사이에 두 쪽 정보가 다를 수 있습니다.

## 어디까지가 부동산이지 일인가

광고 한 건이 나가기까지 열두 단계쯤 됩니다. 그중 부동산이지에서 하는 것과 렛츠에서 하는 것이 나뉩니다.

| 단계 | 어디서 |
| --- | --- |
| 렛츠 가입 | **부동산이지** (자동으로 넘어갑니다) |
| 멤버십 결제 · 충전금 결제 | 렛츠 |
| 광고 접수 | **부동산이지** |
| 광고 정보 확인 · 사진 첨부 · 등기부 첨부 | 렛츠 (자동 첨부됩니다) |
| 소유자 정보 확인 · 광고 결제 | 렛츠 |
| 매물 전송 | **부동산이지** |
| 확인매물 관리 | 렛츠 |
| 광고 상태 확인 · 노출 순위 확인 | **부동산이지** |

렛츠에서 해결해야 하는 일은 **렛츠 고객센터 02-430-4909** 로 문의하셔야 합니다.
부동산이지 고객센터에서는 처리할 수 없습니다.

## 돈은 누구에게 내나

세 가지가 각각 다릅니다. 헷갈리시는 분이 많습니다.

| 무엇 | 누구에게 | 얼마 |
| --- | --- | --- |
| 부동산이지 이용료 | 네오비소프트 | 베이직 무료 / 플러스 월 2,000원 |
| **렛츠 멤버십** | 렛츠 | **99,000원 / 6개월** |
| **광고비(충전금)** | 렛츠를 통해 | 광고 상품별로 건당 |

*(2026.09 기준)* 렛츠 멤버십은 CP사 중에서는 저렴한 편입니다.
부동산이지는 매물 정보를 보내주는 역할까지이고, 광고비를 대신 받지 않습니다.

## 광고 상품에 따라 순위가 갈립니다

같은 매물이라도 어떤 검증방식으로 올리느냐에 따라 노출 순위가 달라집니다.

| 매물검증방식 | 대략 가격 | 노출 순위 |
| --- | --- | --- |
| 현장확인2 | 50,500원 | 최상위 |
| 현장확인 | 21,100원 | 1위 |
| 모바일확인 | 1,530원 | 2~3위 |
| 신용보호확인서 | 1,530원 | 3위 |
| 홍보확인서확인 | 2,030원 | 5·7위 |
| 전화확인 | 1,990원 | 6위 |

*(2026.09 기준. 정확한 금액은 렛츠 전송가격표를 보세요)*

## 그래서 이런 일이 생깁니다

**연동이 끊기는 경우**
렛츠 계정 인증이 만료되었거나, 사무소 정보가 렛츠 쪽과 달라졌을 때 발생합니다.
부동산이지 화면에서는 정상으로 보여도 실제로는 송출이 멈춰 있을 수 있습니다.

**고쳤는데 네이버에 그대로인 경우**
대부분 반영 대기 상태입니다. 다만 몇 시간이 지나도 그대로면 연동 상태를 확인하셔야 합니다.
매물종류와 면적은 **전송 후에는 수정할 수 없고**, 가격은 최초등록가의 **±20% 이내**로만 고칠 수 있습니다.

**등기부등본이 첨부되지 않는 경우**
**최근 90일 이내에 발급(열람)한 등본만** 쓸 수 있습니다.
부동산이지에서 등기를 떼어 두셨다면 자동으로 첨부되고, 소유자명과 발급일자가 검증되어 표시됩니다.

**순위가 밀리는 경우**
노출 순서는 네이버가 정합니다. 부동산이지나 렛츠가 정하지 않습니다.
확인매물 여부, 등록 시점, 정보의 충실도, 사진 수가 영향을 줍니다.

## 순위 알림 두 가지를 꼭 보세요

`매물 → 매물 관리`의 **네이버(R)** 버튼을 누르면 광고 상태 창이 뜹니다.
여기에 **매물전체순위**와 **동일매물순위**가 나오고, 알림이 두 종류 붙습니다.

| 알림 | 무슨 뜻인가 | 무엇을 해야 하나 |
| --- | --- | --- |
| **[가격]** | 나보다 더 싼 가격으로 광고하는 매물이 있다 | 중개의뢰인께 확인하고 광고 가격을 조정 |
| **[층]** | 나는 저/중/고로 올렸는데 다른 곳은 층을 노출해서 위에 있다 | 층 노출로 광고를 수정 |

**매물전체순위**는 그 단지·지역에서 몇 번째로 보이는지이고, 20번째 안에 들면 숫자가 나옵니다.
**동일매물순위**는 같은 매물로 묶였을 때 그 묶음 안에서 몇 번째인지입니다.

## 위반건축물은 반드시 적어야 합니다

**위반건축물은 매물설명란에 반드시 기재**해야 합니다. 2025년 1월 1일부터 시행되었습니다.

부동산이지에서 일반건축물대장을 떼면 **(위반)** 배지가 자동으로 붙고,
건축물대장 변동내용에서 **위반항목만 복사**로 뽑아 쓰실 수 있습니다.

## 부동산이지에서 어디를 보면 되나

| 하려는 일 | 메뉴 |
| --- | --- |
| 네이버 광고 등록·관리 | `매물 → N 광고 관리` |
| 네이버에 올라간 내 매물 상태 확인 | `매물 → N 매물 모니터링` |
| 이미 광고 중인 내 매물 가져오기 | `매물 → N 매물 모니터링 → 내 N 매물 가져오기` |
| 부동산이지 자체 광고 | `매물 → 이지 광고 관리` |
