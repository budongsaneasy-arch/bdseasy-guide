# 분양권 매매계약서 쓰기

> **걸리는 시간** 약 15분 &nbsp;·&nbsp; **미리 준비할 것** 분양계약서, 분양대금 납부 내역, 옵션 계약 내용

아직 등기가 나지 않은 **분양권**을 사고파는 계약서입니다.

`계약 → 계약 생성`에서 거래 유형 **매매/권리금** → 계약서 유형 **분양권 매매 계약서**를 고릅니다.
공통 단계는 [아파트 매매계약서 쓰기](/howto/contract-apartment)와 같습니다.

![계약서 유형 고르기](/images/contract-presale-01.png)

## 매매계약서와 결정적으로 다른 점

일반 매매는 **지금 있는 물건**을 사고팝니다.
분양권은 **앞으로 지어질 물건에 대한 권리**를 사고팝니다.

그래서 계약서에 **분양계약 내용을 그대로 옮겨 적는 칸**이 따로 있습니다.

## 1. 부동산 표시

일반 매매와 달리 이렇게 들어갑니다.

- 소재지
- **분양면적 · 전용면적 · TYPE**
- 대지권의 목적인 토지의 표시 면적 · 대지권비율

TYPE(59A, 84B 같은 것)은 분양계약서에 적힌 그대로 씁니다.

## 2. 분양계약 내용 옮겨 적기

![분양계약 내용](/images/contract-presale-02.png)

여기가 이 계약서의 핵심입니다. **분양계약서를 보면서** 채웁니다.

| 항목 | 무엇을 넣나 |
| --- | --- |
| 분양금액 | 분양계약서상 총 분양가 |
| 분양계약금 | 금액과 **비율(%)** |
| 중도금 대출금액 | 금액·비율과 **대출 회차** |
| 중도금 자납금액 | 금액과 **자납 회차** |
| 잔여 금액 | 중도금+잔금, 잔금비율(%) |

**옵션비**와 **발코니확장비**도 따로 있습니다.

| 항목 | 넣는 것 |
| --- | --- |
| 옵션비 · 옵션타입 | 금액과 종류 (예: 시스템에어컨) |
| 옵션 납부금액 · 옵션 잔금 | 비율(%)과 납부 회차 |
| 발코니확장비 | 금액 |
| 발코니 납부금액 · 발코니 잔금 | 비율(%)과 납부 회차 |

이것들이 모여 아래 두 값이 자동으로 계산됩니다.

- **실분양금액** = 분양금액 + 옵션 + 발코니확장비
- **납부한 금액** = 분양계약금 + 중도금(자납) + 옵션납부금액 + 발코니납부금액

::: warning 중개보수 계산에 주의하세요
화면에 이런 안내가 있습니다.

> 중개보수계산 시 중도금[대출]금액은 포함할 수 있습니다.
> 이 경우, [확인설명서 > 중개보수 산출내역 > 거래예정금액]에서
> 중도금[대출]금액을 포함한 금액으로 **직접입력**하여 인쇄해야 합니다.

자동으로 반영되지 않습니다. 직접 넣으셔야 합니다.
:::

::: warning 회차를 정확히 적으세요
중도금이 몇 회차까지 납부되었는지가 **정산지불금 계산의 기준**입니다.
분양계약서와 납부 영수증을 대조해서 확인하세요.
:::

## 3. 매매대금은 정산지불금입니다

아래쪽 **매매대금**은 일반 매매의 매매가가 아니라 **정산지불금**입니다.
분양권을 넘겨받는 사람이 실제로 지급하는 금액이고, 여기에 계약금·중도금·잔금을 나눠 넣습니다.

## 4. 조문이 다릅니다

제2조부터 제7조까지가 분양권 전용 조문입니다.

- 분양계약서·당첨권 등의 교부
- 위반 시 배액 상환·귀속
- 관련법과 일반관례
- 중개보수 / 쌍방 합의
- **제7조 중개대상물 확인설명서 교부 등**

## 여기서 막히셨다면

::: details 분양면적과 전용면적 중 무엇을 면적으로 보나요
계약서에는 **둘 다 적습니다.** 분양계약서에 적힌 값을 그대로 옮기세요.
:::

::: details 마이너스 프리미엄이면 어떻게 하나요
총 매매금액 및 정산금액 영역의 프리미엄 칸 옆에 **마이너스프리미엄** 체크가 있습니다.
체크하면 프리미엄이 빼는 값으로 계산됩니다.
:::

::: details 옵션 계약이 여러 개입니다
옵션타입 칸에 함께 적고, 상세 내역은 **특약사항**으로 정리하세요.
:::
