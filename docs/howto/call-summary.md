# 통화 녹음을 AI로 요약하기

> **걸리는 시간** 처음 설정 5분, 그 뒤로는 통화마다 자동 &nbsp;·&nbsp; **미리 준비할 것** 플러스 이상 요금제 (자동 요약은 프로) · 안드로이드 휴대폰 · 휴대폰 통화녹음 켜기
>
> 통화가 끝나면 **녹음을 대화 글로 바꾸고, 한 줄로 요약**해 줍니다.
> 고객이 무슨 말을 했는지 다시 들을 필요가 없어지고, 분쟁이 생기면 **녹취록이 증빙**이 됩니다.

::: warning 안드로이드 전용입니다 · 플러스는 맛보기, 프로는 월 300분
- **프로 요금제**는 월 300분, **플러스는 맛보기로 월 10분** 쓰실 수 있습니다 *(2026.10)*.
  **통화가 끝날 때 자동으로 요약되는 기능은 프로 전용**입니다 — 플러스는 눌러서 요약합니다.
  구독은 부동산이지 웹사이트의 `마이페이지 → 결제 관리 → 구독`에서 합니다 → [요금제 비교](/reference/plan)
- 부동산이지 앱이 **안드로이드 전용**이라 **아이폰에서는 쓸 수 없습니다**
- 안내와 공지에서 부르는 앱 이름은 **EZ콜매니저**입니다. **플레이스토어 등록명과 설치 후
  홈 화면의 아이콘 이름은 「부동산이지」**이니, 찾을 때는 부동산이지로 보시면 됩니다.
  2026.10 말에 **아이콘 그림이 바뀌었습니다** — 그림만 바뀌었고 이름은 그대로입니다
:::

## 어떻게 동작하나

앱이 통화를 직접 녹음하는 것이 아닙니다. **휴대폰이 저장해 둔 통화 녹음 파일**을 찾아
글로 바꿉니다. 그래서 **휴대폰의 통화 녹음 기능이 먼저 켜져 있어야** 합니다.

**지원하는 녹음은 휴대폰 기본 전화앱의 통화 녹음입니다** (삼성 갤럭시 기준: 전화 앱
`설정 → 통화 녹음`). T전화 같은 별도 통화 앱이나 녹음 앱의 파일은 찾지 못할 수 있습니다.
다른 녹음 앱이 다른 폴더나 파일명을 쓰면 파일을 찾지 못할 수 있습니다.

::: warning 보관 기간과 상대방 안내
- 녹음 파일은 **등록일부터 1년** 보관됩니다. 그 전에라도 **통화내역을 삭제하면 바로 파기**됩니다
- **통화 상대에게 녹음·요약 사실을 알릴 책임은 중개사에게 있습니다.**
  개인정보 처리방침에 그렇게 적혀 있습니다 — 요약을 요청한 통화만 처리되고,
  상대방 안내는 회원의 몫입니다
- 자세한 보관·파기 기준은 부동산이지 **개인정보 처리방침**에 게시되어 있습니다
:::

그리고 **이 휴대폰에서 건·받은 통화만** 요약됩니다. 사무실 전화나 다른 폰으로 한 통화,
연결되지 않은 부재중 전화는 요약할 수 없습니다.

## 1. 켜기 — 설정 탭의 AI 통화요약

![설정 탭의 AI 통화요약 카드 — 수동(기본)과 자동](/images/call-summary-01.png)

앱 아래 탭 **설정**에 **AI 통화요약** 카드가 있습니다 *(2026.11 플레이스토어 앱 기준)*.

- **이번 달 사용 / 300분**과 **남은 시간**이 보입니다
- 그 아래 적힌 그대로 — **사무실 공용 · 매월 1일 초기화 · 건당 최대 60분**
- **자동 요약** 스위치 — 기본은 **수동**입니다. 자동으로 켜면 통화가 끝날 때마다 알아서 요약을 신청합니다

**플러스**에서는 같은 카드에 **0분 / 10분**, 그 아래 **맛보기**라고 나옵니다.
**자동 요약** 자리에는 스위치 대신 **프로 플랜 이상**이 보입니다. 플러스는 눌러서 요약합니다.

![플러스의 AI 통화요약 카드 — 맛보기 10분 · 자동 요약은 프로 플랜 이상](/images/call-summary-06.png)

::: tip 자동으로 켤까, 수동으로 둘까
**월 300분은 사무실 전체가 같이 쓰는 시간**입니다. 자동으로 켜면 요약이 필요 없는
통화도 전부 차감되므로, 통화가 많은 사무소라면 **수동으로 두고 필요한 통화만**
요약하는 편이 오래 갑니다.

**다른 아이디로 로그인하면 자동 설정이 수동으로 돌아갑니다.** 화면에도 안내가 붙어 있습니다.
:::

## 2. 요약 신청하기 — 세 가지 길

![통화가 끝난 뒤의 AI 통화요약 버튼 — 누르면 요청됨](/images/call-summary-02.png)

**① 통화가 끝난 직후** — 고객 창 아래에 `콜백문자 · 상담일지 · AI 통화요약`
버튼이 붙습니다. **AI 통화요약**을 누르면 `✓ 요청됨`으로 바뀝니다 *(2026.11 디자인 변경)*.

**② 지난 통화를 골라서** — 아래 탭 `통화이력`에서 통화를 누르면 **통화 상세**가 열립니다.
가운데 **AI 통화요약 요청** 버튼을 누르세요. 아직 요약하지 않은 통화에만 보입니다.
버튼 아래에 **이번 달 사용 · 남은 시간 · 이 통화**(이 통화의 길이)가 함께 나와, 얼마나 차감될지 미리 보입니다.

![통화 상세 — 고객정보 · 전화 · 문자 · 상담일지, AI 통화요약 요청](/images/call-summary-05.png)

**폰에 녹음이 남아 있는 지난 통화라면, 가입 첫날부터 바로 요약해 볼 수 있습니다.**

**③ 자동** — 1번의 자동 요약을 켜 두면 신청할 필요가 없습니다.

::: tip 시간은 이렇게 차감됩니다
- **실제 녹음 길이만큼**만 차감됩니다. **실패한 건은 차감되지 않습니다**
- 같은 통화를 두 번 요약해도 **한 번만** 차감됩니다
- 한 통화는 **최대 60분**까지입니다
:::

## 3. 결과 보기 — 앱에서

![요약이 끝난 통화 상세](/images/call-summary-03.png)

요약이 끝나면 통화 상세가 이렇게 바뀝니다. *(사진은 2026.11 디자인 변경 전 화면입니다)*
<!-- 확인 필요: 플레이스토어 앱에서 요약이 끝난 통화 상세 화면 -->

- **한 줄 요약** — 거래유형 · 지역 · 면적 · 금액 · 약속 일시 위주로 60자 안팎.
  *예) "○○동 30평대 전세 8억 이하 문의, 토요일 14시 매물 2곳 방문 약속"*
  업무 얘기가 없던 통화는 *"간단 통화(특이사항 없음)"* 처럼 나옵니다
- **대화 말풍선** — 나와 고객이 나눈 말이 글로. **말풍선을 누르면 그 부분부터 재생**됩니다
- **통화내용 검색** — "분양권"처럼 단어로 지난 통화를 찾습니다
- 말풍선을 **길게 누르면** 내용 수정·삭제, 나/고객 위치 바꾸기(좌우반전)가 됩니다

처리는 신청 순서대로 한 건씩 진행되고, 통화가 끝나고 약 15초 뒤에 시작됩니다.
밀리면 *"먼저 요청한 통화부터 순서대로 진행됩니다"* 라고 보여줍니다.

## 4. 결과 보기 — 사무실 컴퓨터에서

![웹 마케팅 → 통화 내역의 통화 상세](/images/call-summary-04.png)

웹의 **`마케팅 → 통화 내역`** 에도 같은 내용이 올라옵니다.

- 검색 조건과 목록 사이에 **이번 달 사용량과 남은 시간**이 보입니다 — 사무실 공용 잔량을 여기서 확인하세요
- 목록의 **상담 내용** 칸에 한 줄 요약이 들어갑니다
- 행을 누르면 **대화 전문과 녹음 재생**이 열리고, 요약과 대화를 **수정**할 수 있습니다
- 웹에서는 **보기와 수정만** 됩니다. 요약 신청과 재시도는 앱에서 합니다

통화한 번호가 고객으로 등록되어 있으면 **고객 이름(별칭)** 으로 연결되어,
그 고객의 지난 통화가 상담 기록과 한 줄에 모입니다.

## 5. 통화를 상담일지로 남기기

*(2026.11 신설)*

요약된 통화를 **그 고객의 상담일지로 그대로 옮길 수 있습니다.** 다시 타이핑하지 않으셔도 됩니다.

`마케팅 → 통화 내역`에서 통화를 열면 오른쪽에 **상담일지** 칸이 생겼습니다.

- 아직 남기지 않은 통화는 **미등록**으로 나오고, 옆에 **상담일지로 등록** 버튼이 있습니다
- 누르면 **상담일지 추가** 창이 열립니다. **상담 일시 · 상담 수단 · 상담 내용**이
  그 통화 내용으로 **미리 채워져** 있습니다
- 고칠 것만 고치고 **추가**를 누르면 그 고객의 상담일지로 들어갑니다
- 상담일지로 남긴 통화는 **목록의 상담 내용 앞에 `상담일지` 표시**가 붙습니다. 어느 통화를 이미 옮겼는지 목록에서 바로 보입니다

::: tip 고객으로 등록해 두면 다음부터는 저절로 기록됩니다
AI 통화 요약이 끝나면 **그 고객의 상담일지에 자동으로 올라갑니다.**
통화 한 건에 상담일지 한 건이고, 이미 그 통화로 써 둔 상담일지가 있으면
**거기에 요약이 덧붙습니다.** 인사만 하고 끊은 통화처럼 **업무 내용이 없는 통화는 기록되지 않습니다.**

자동으로 올라가는 것은 **그 번호로 등록된 고객이 한 명일 때**입니다.
→ [고객 등록하고 관리하기](/howto/customer)
:::

::: warning 등록되지 않은 번호로 걸려온 전화라면
**상담일지로 등록**을 누르면 이렇게 묻습니다.

> 이 번호(010-○○○○-○○○○)는 등록된 고객이 없습니다.
> 고객으로 등록하면 다음 통화부터 통화 요약이 상담일지에 자동으로 기록됩니다.

**새 고객으로 등록 · 기존 고객에 연결 · 취소** 셋 중에 고르시면 됩니다.
한 번 등록해 두면 그 다음부터는 손대실 일이 없습니다.
→ [고객을 왜 한 곳에 모으나](/concept/why-one-customer)
:::

::: tip 한 번호를 여러 사람이 쓰고 있다면
가족이 번호 하나를 같이 쓰는 경우처럼 **같은 번호로 등록된 고객이 여럿**이면,
상담일지 추가 창에 **같은 번호 고객 목록**이 나옵니다. 거기서 고르시면 됩니다.

이때는 **자동으로 기록되지 않습니다.** 누구의 상담일지인지는 중개사가 정하셔야 하기 때문입니다.
:::

반대로 **상담일지 쪽에서도 그 통화로 건너갈 수 있습니다.** `마케팅 → 상담 일지 관리`에서
통화로 만든 상담일지는 **상담 수단 아래에 「통화 보기」** 가 붙어 있습니다.
누르면 그 통화의 **녹음과 대화 내용**이 바로 열립니다 *(2026.11 신설)*.

## 여기서 막히셨다면

::: details [AI 통화요약] 버튼이 안 보입니다
**플러스와 프로 모두 버튼이 보입니다.** 플러스는 맛보기로 월 10분입니다.

- 통화이력에서는 **이미 요약한 통화**에는 버튼이 없습니다. 요약 결과가 대신 보입니다
- 설정 탭의 **자동 요약** 옆에 **프로 플랜 이상**이라고 나오는 것은 **자동 요약만** 프로 전용이라는 뜻입니다.
  눌러서 요약하는 것은 플러스에서도 됩니다

구독은 부동산이지 **웹사이트**의 `마이페이지 → 결제 관리 → 구독`에서 합니다.
:::

::: details "녹음 파일이 없습니다"가 뜹니다
문구에 따라 원인이 다릅니다.

| 화면 문구 | 원인과 대처 |
| --- | --- |
| *"녹음 파일이 없습니다. 이 기기에서 통화한 내역만 요약할 수 있습니다."* | **다른 폰·사무실 전화로 한 통화**입니다. 이 폰의 통화만 요약됩니다 |
| *"통화 녹음파일을 찾을 수 없습니다. 기본 전화앱의 통화 녹음만 지원합니다."* | 이 폰의 통화인데 **녹음이 저장되지 않은 경우**입니다. 화면 안내대로 `전화앱 → 설정 → 통화 녹음`에서 **통화 자동 녹음**을 켜세요 |

앱 권한 중 **저장공간(오디오)** 이 허용인지도 확인하세요.
:::

::: details "연결된 통화만 요약할 수 있습니다"가 뜹니다
부재중 전화처럼 **통화가 이루어지지 않은 기록**입니다. 녹음이 없어 요약할 수 없습니다.
:::

::: details "60분 이하 통화만 요약할 수 있습니다"가 뜹니다
한 통화의 상한이 **60분**입니다. 그보다 긴 통화는 요약되지 않습니다.
:::

::: details "이번 달 통화 요약 가능 시간이 부족합니다"가 뜹니다
**사무실 공용 월 300분**(플러스는 맛보기 10분)을 다 쓴 상태입니다. **매월 1일에 초기화**됩니다.
남은 시간이 빠듯하면 설정 탭의 사용량이 **빨간색**으로 바뀝니다.

화면 안내대로, **추가 시간이 필요하면 부동산이지 웹의 `고객센터 → 문의하기`** 로 문의하시면 됩니다.
:::

::: details "인식된 대화 내용이 없습니다"가 뜹니다
녹음에 말소리가 없었던 경우입니다. 시간은 차감되지 않습니다.
:::

::: details 요약을 신청했는데 소식이 없습니다
인터넷이 끊겨 있으면 연결된 뒤에 처리되고, 일시적인 오류는 자동으로 다시 시도합니다.
진행되지 못한 건은 **휴대폰 알림**("통화 요약이 진행되지 않았습니다")으로 알려줍니다.
상세 화면에 **[다시 시도]** 가 보이면 눌러 주세요.
:::
