# 등기 변동 알림 받기

> **걸리는 시간** 한 건 등록에 2분 &nbsp;·&nbsp; **미리 준비할 것** 지켜볼 부동산의 주소, **등기부상 소유자 이름**
>
> 지켜보는 부동산에 **근저당이 잡히거나 소유자가 바뀌면** 알려 줍니다.
> 등기를 매번 떼어 보지 않아도 **움직임이 생긴 것만** 알 수 있습니다.

## 왜 쓰나

전속으로 받아 둔 매물, 잔금을 앞둔 계약, 만기가 다가오는 임대차 —
**등기가 조용한지 아닌지가 중요한 물건**이 있습니다.

그런데 등기는 **뗄 때마다 700원**이고, 바뀐 게 없으면 그 돈은 그냥 나갑니다.
등기 변동 알림은 반대로 움직입니다. **등록해 두면 부동산이지가 대신 지켜보고,
접수된 사건이 있을 때만** 목록에 쌓입니다.

→ [공적장부 한 번에 떼기](/howto/public-records) · [등기 열람 포인트 충전하기](/howto/points)

## 들어가기

상단 메뉴 **부동산 원장 → 등기변동**입니다.

![등기변동 화면 — 왼쪽 목록과 오른쪽 상세](/images/registry-alarm-01.png)

화면이 둘로 나뉩니다.

| 어디 | 무엇이 있나 |
| --- | --- |
| **왼쪽** | 지켜보는 부동산 목록. 주소 아래에 **상태**가 색 점으로 표시됩니다 |
| **오른쪽 위** | 고른 부동산의 **선택된 부동산 정보** |
| **오른쪽 아래** | **등기변동 내역** — 접수된 등기 사건 목록 |

왼쪽 위 **추가** 옆의 숫자가 **지금 등록한 건수 / 쓸 수 있는 건수**입니다.

## 1. 지켜볼 부동산 등록하기

**추가**를 누르면 **등기변동 알림 신청** 창이 열립니다.

![등기변동 알림 신청 창](/images/registry-alarm-02.png)

1. **불러오기**를 누릅니다. 익숙한 **부동산 소재지 추가** 창이 열립니다.
   주소를 검색해서 고르면 아래 칸들이 채워집니다.
2. **신청 유형**을 확인합니다 — **토지 · 건물 · 집합건물** 중 하나입니다.
   아파트·오피스텔처럼 호수가 있는 건물은 **집합건물**입니다.
3. **소유자**를 넣습니다.
4. **저장**을 누릅니다.

::: danger 소유자 이름과 주소가 등기와 정확히 맞아야 조회됩니다
이 기능은 **주소 + 소유자 이름**으로 등기소에 조회합니다.
**둘 중 하나라도 등기부와 다르면 조회되지 않습니다.**

- 소유자는 **등기부에 적힌 그대로** 넣으세요. 법인은 상호를 등기부 표기대로
  (띄어쓰기 없이 `주식회사○○` 형태로 적혀 있는 경우가 많습니다)
- **공동명의**라면 등기부에 먼저 나오는 사람으로 맞춰 보세요
- 주소는 **반드시 불러오기로** 넣으세요. 직접 치면 번지 표기가 어긋나기 쉽습니다

등록해 두고 안심하고 계셨는데 **실은 한 번도 조회되지 않고 있었다**는 것이
가장 위험합니다. 등록한 뒤 **상태가 「정상등록」인지 꼭 확인하세요.**
:::

## 2. 상태 읽기

목록의 주소 옆에 상태가 붙습니다. **파란 점이면 정상, 빨간 점이면 손봐야 합니다.**

| 상태 | 무슨 뜻인가 | 무엇을 하나 |
| --- | --- | --- |
| **정상등록** | 제대로 등록되어 지켜보는 중입니다 | 그대로 두시면 됩니다 |
| **등기변동** | **움직임이 있습니다** | 오른쪽 **등기변동 내역**을 확인하세요 |
| **소유자명 불일치** | 넣은 소유자 이름이 등기와 다릅니다 | **수정**으로 이름을 고치세요 |
| **소재지 오류(수정 필요)** | 그 주소로 등기를 찾지 못했습니다 | **수정**에서 **불러오기**로 주소를 다시 넣으세요 |
| **소재지 다수(수정 필요)** | 그 주소에 해당하는 등기가 여러 건입니다 | 동·호까지 넣어 하나로 좁히세요 |

**수정 필요**가 붙은 것은 **지켜보지 못하고 있는 상태**입니다. 그대로 두면 변동이 생겨도 알 수 없습니다.

## 3. 변동 내역 보기

목록에서 부동산을 고르면 오른쪽에 **등기변동 내역**이 나옵니다.

| 칸 | 무엇인가 |
| --- | --- |
| **부동산구분** | 토지 / 건물 / 집합건물 |
| **접수일자** | 등기소에 접수된 날 |
| **접수번호** | 등기소 접수번호 |
| **소유자명** | 조회에 쓴 소유자 |
| **등기목적** | **근저당권설정 · 근저당권말소 · 질권설정 · 등기명의인표시변경** 같은 사건 이름 |
| **처리상태** | **접수완료** (처리 중) 또는 **등기완료** (끝남) |

::: warning 여기 보이는 것은 「접수된 사건」입니다
**등기부등본 그 자체가 아닙니다.** 어떤 사건이 접수·완료되었는지만 알려 줍니다.

그래서 **중요한 변동이 보이면 등기부등본을 실제로 떼어** 내용을 확인하셔야 합니다.
계약을 앞두고 있다면 **계약 당일 기준으로 다시 떼는 것**이 원칙입니다.
→ [공적장부 한 번에 떼기](/howto/public-records)
:::

::: tip 지금 바로 확인하고 싶을 때
오른쪽 위 **변동확인 요청**을 누르면 그 자리에서 다시 조회합니다.
**등기신청사건 직접조회하기**를 누르면 등기 신청사건을 직접 조회하는 화면이 새 창으로 열립니다.
:::

## 4. 고치기와 지우기

- **수정** — 오른쪽 위 버튼입니다. 신청 창이 다시 열려 주소·소유자를 고칠 수 있습니다
- **삭제** — 목록에서 각 줄 오른쪽의 **휴지통 아이콘**을 누릅니다

등록 건수는 요금제마다 정해져 있습니다. 다 차면 **안 쓰는 것을 지우고** 새로 넣으세요.
→ [요금제 비교](/reference/plan)

## 여기서 막히셨다면

::: details 등록했는데 「소유자명 불일치」가 뜹니다
넣은 이름이 **등기부상 소유자와 글자가 다른** 경우입니다.

- 법인은 **주식회사**를 앞에 쓰는지 뒤에 쓰는지, **띄어쓰기가 있는지**까지 등기부와 맞춰 보세요
- 사람 이름은 **동명이인·개명**으로 어긋날 수 있습니다
- 확실하지 않으면 **등기부등본을 한 번 떼어** 소유자 표기를 확인하고 그대로 넣으세요
:::

::: details 「소재지 오류(수정 필요)」가 뜹니다
그 주소로 등기를 찾지 못한 것입니다. **수정 → 불러오기**로 주소를 다시 넣어 보세요.

직접 입력한 주소는 **본번·부번 표기**가 등기소 기준과 어긋나기 쉽습니다.
검색해서 넣으면 대부분 해결됩니다.
:::

::: details 「소재지 다수(수정 필요)」가 뜹니다
한 지번에 등기가 여러 건이라 하나로 특정되지 않은 것입니다.
**수정**에서 **동·호**까지 넣어 좁혀 주세요.
:::

::: details 최근 조회일이 한참 전입니다
등기 변동 알림은 **아직 정식 제공 전**입니다. 구독정보 화면에도
**2026년 4분기 정식 제공 예정**이라고 적혀 있습니다.

지금도 알림은 발송되지만 **조회가 밀릴 수 있습니다.**
급한 건은 **변동확인 요청**으로 직접 돌리시고, 계약 직전이라면
**등기부등본을 떼어** 확인하세요. → [요금제 비교](/reference/plan)
:::

::: details 몇 건까지 등록할 수 있나요
요금제마다 다릅니다. 화면 왼쪽 위 **추가** 옆 숫자에서 지금 쓴 건수와 한도를 보실 수 있습니다.
→ [요금제 비교](/reference/plan)
:::
