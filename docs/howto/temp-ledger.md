# 신축 단지 원장 신청하기 (임시원장)

> **걸리는 시간** 신청 5분 &nbsp;·&nbsp; **미리 준비할 것** 동·호수 배치도, 타입별 전용면적 자료

입주를 앞둔 신축 아파트인데 **부동산이지에서 단지가 검색되지 않는** 경우가 있습니다.
이때는 **임시원장**을 만들어 달라고 요청하시면 됩니다.

## 왜 검색이 안 되나

부동산이지의 모든 원장은 **건축물대장**을 기준으로 만들어집니다.
그런데 신축 건물은 **준공 후에야 건축물대장이 생성**됩니다.
대장이 아직 없으니 가져올 정보도 없고, 그래서 단지가 뜨지 않습니다.

→ 왜 대장을 기준으로 삼는지는 [왜 대장이 먼저인가](/concept/why-records-first)를 보세요.

::: tip 예전과 방식이 달라졌습니다
전에는 **청약홈에 공시된 정보**를 기준으로 임시원장을 자동으로 만들었습니다.
그런데 청약홈에는 **조합원 물량·임대주택·보류지**가 빠져 있는 경우가 많아
정작 필요한 호실이 없는 일이 반복되었습니다.

그래서 지금은 **요청을 받아 자료를 확인한 뒤 생성**하는 방식으로 바뀌었습니다.
자료를 첨부해 주셔야 하는 이유입니다.
:::

## 1. 정말 없는지 먼저 확인하기

있는데 못 찾으신 경우가 의외로 많습니다. **통합검색 말고 지번으로** 다시 찾아보세요.

`부동산 원장 → 부동산 원장 관리`에서 부동산 유형을 **건축물**으로 고르고
**지번주소**로 검색합니다.

::: tip 통합검색은 원래 안 잡히는 경우가 있습니다
통합검색은 외부 API로 단지명을 찾는 방식이라 결과가 없을 때가 있습니다.
**건축물 탭을 고르고 지번으로 검색**하시면 대부분 나옵니다.

신축뿐 아니라 **평소에 건물이 검색되지 않을 때도** 먼저 써 보실 방법입니다.
:::

## 2. 첨부할 자료 준비하기

임시원장은 **모든 호실의 전용면적이 확인되어야** 만들 수 있습니다.
아래 두 가지가 **필수**입니다.

| 구분 | 자료 | 조건 |
| --- | --- | --- |
| **필수** | **동·호수 배치도** | 단지 내 **모든 호실의 타입**이 표시되어 있어야 합니다 |
| **필수** | **타입별 전용면적 정보** | 타입별 평면도 등 전용면적을 알 수 있는 자료 |
| 선택 | 상가 동·호수 배치도 | 상가까지 함께 만드실 경우 |
| 선택 | 상가 타입별 평면도 | 상가까지 함께 만드실 경우 |

::: warning 전용면적이 하나라도 비면 생성되지 않습니다
일부 타입의 면적을 알 수 없으면 그 단지는 만들어 드릴 수 없습니다.
분양 홈페이지나 입주자 모집공고에서 **전 타입 면적**을 먼저 확보하세요.
:::

## 3. 문의하기로 신청하기

`고객센터 → 문의하기`에 글을 남기시면 됩니다. 이렇게 쓰시면 됩니다.

> **[제목]** ○○ 임시원장 생성 요청
> **[내용]** 단지명, 주소
> **[첨부파일]** 동·호수 배치도, 타입별 전용면적 자료

## 4. 만들어진 임시원장 찾기

임시원장은 일반 원장과 **같은 자리에 나오지 않습니다.**

`부동산 원장 → 부동산 원장 관리`에서
부동산 유형 **건축물**, 지번·본번·부번을 넣고 검색하면
**목록 맨 하단**에 표시됩니다.

::: tip 목록 위쪽만 보고 없다고 판단하지 마세요
공공데이터 원장이 먼저 나오고, 임시원장은 그 아래에 붙습니다.
검색 결과를 **끝까지 내려서** 확인하세요.
:::

찾으셨으면 그 뒤로는 일반 원장과 똑같이 쓰실 수 있습니다.
매물 접수, 계약서 작성, 만기 관리가 모두 됩니다.

## 5. 건축물대장이 나온 뒤에 할 일

준공되어 건축물대장이 생성되어도 **바로 부동산이지에 들어오지는 않습니다.**

공공데이터에 반영되기까지 **약 2개월**이 걸립니다.
반영된 뒤 `고객센터 → 문의하기`로 다시 요청하시면
**임시원장에 쌓아 두신 내용을 공공데이터 원장으로 옮겨** 드립니다.

::: warning 호실이 맞지 않으면 옮기기 어려울 수 있습니다
임시원장의 호실과 실제 대장의 호실이 **매칭되지 않는 경우** 이전이 어려울 수 있습니다.
동·호수 배치도를 정확한 것으로 첨부해 두시는 것이 결국 여기서 도움이 됩니다.
:::

## 여기서 막히셨다면

::: details 임시원장으로 계약서를 써도 되나요
됩니다. 매물 접수부터 계약서까지 일반 원장과 똑같이 쓰실 수 있습니다.

다만 임시원장의 면적·호실은 **제출된 배치도를 근거로 만든 것**이고
건축물대장에서 가져온 값이 아닙니다.
대장이 나오면 **내용을 대조해 보세요.**
:::

::: details 언제까지 처리되나요
문의하기에 남기시면 순서대로 처리됩니다.
급하시면 글에 입주 예정일을 함께 적어 주세요.
:::

::: details 상가만 필요합니다
상가 자료는 선택 항목이라, 상가 배치도와 타입별 평면도를 첨부해 함께 요청하시면 됩니다.
:::

::: details 이미 다른 분이 요청한 단지일 수도 있나요
같은 단지를 여러 분이 요청하시는 경우가 많습니다.
먼저 **1단계의 지번 검색**으로 이미 만들어져 있는지 확인해 보세요.
:::
