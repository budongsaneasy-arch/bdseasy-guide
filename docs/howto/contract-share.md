# 계약서 공유해서 공동중개하기

> **걸리는 시간** 약 3분 &nbsp;·&nbsp; **미리 준비할 것** 작성 중인 계약서, 상대 부동산 연락처

작성한 계약서를 **공동중개 상대 부동산이나 고객에게** 링크로 공유합니다.

## 무엇이 해결되나

계약서를 주고받을 때 늘 걸리던 세 가지가 있습니다.

| 문제 | 부동산이지의 답 |
| --- | --- |
| 서로 고친 내용이 **일관되게 반영되지 않음** | 같은 문서를 함께 보고 함께 고칩니다 |
| 공유하고 싶지 않은 **고객 정보까지 넘어감** | 인적사항은 **링크를 만든 사람만** 수정·저장할 수 있습니다 |
| 고객이 미리 보고 싶다고 해도 **보여줄 방법이 없음** | 비회원도 링크로 조회·인쇄할 수 있습니다 |

## 어떻게 굴러가나

```
원본 계약 ──[계약 공유 생성]──▶ 공유 계약 ──[내 계약으로 등록]──▶ 상대방의 계약 사본
                                    │
                          공동 작업(함께 수정)
                                    │
                         [원본 계약에 저장](덮어쓰기)
```

**공유하면 계약서 사본이 만들어져 원본과 분리됩니다.** 원본은 그대로 보존됩니다.

## 1. 공유 링크 만들기

계약 상세 화면 위쪽 **계약 공유 생성**을 누릅니다.

![계약 공유 링크 만들기](/images/contract-share-01.png)

**문서 비밀번호를 6글자 이상** 넣고 **공유**를 누르면 링크가 만들어집니다.

창 안에 권한표가 그대로 들어 있습니다.

| 대상 | 조회 & 인쇄 | 수정 & 저장 | 내 계약으로 등록 |
| --- | :---: | :---: | :---: |
| **비회원** (고객 등) | O | X | X |
| **회원** (타부동산) | O | △ 인적사항 등 수정불가 | 사본생성 |
| **링크소유자** (본인) | O | O | 원본계약 덮어쓰기 |

## 2. 링크 보내기

만들고 나면 **계약 공유 링크 관리** 화면이 됩니다.

![계약 공유 링크 관리](/images/contract-share-02.png)

| 항목 | 할 수 있는 것 |
| --- | --- |
| 공유URL | 새 창으로 열어 볼 수 있습니다 |
| 문서 비밀번호 | 눈 아이콘으로 확인 |
| **만료기한** | 기본은 **한 달 뒤**. 연필 아이콘으로 고칩니다 |
| 안내문 | **클립보드에 복사**로 통째로 복사 |
| 공유링크 삭제 | 링크를 막습니다 |

복사되는 안내문은 이런 모양입니다.

> 계약 공유 링크입니다. 아래 url클릭 또는 복사해서 확인할 수 있습니다.
> (URL)
> 문서 비밀번호는 ○○○입니다.

::: warning 안내문에 비밀번호가 그대로 들어갑니다
복사한 문구를 그대로 보내면 **링크와 비밀번호가 같은 문자에 함께 갑니다.**
문자를 잘못 보내면 둘 다 넘어가니 **받는 사람을 꼭 확인**하세요.

걱정되시면 안내문에서 비밀번호 줄만 지우고 보낸 뒤, 비밀번호는 전화로 알려주세요.
:::

## 3. 함께 고치기

공유를 만들면 상단 버튼이 **계약 공유 관리**와 **공유된 계약으로 이동**으로 바뀝니다.

![바뀐 버튼](/images/contract-share-03.png)

**공유된 계약으로 이동**을 누르면 비밀번호 화면이 먼저 나옵니다.

![비밀번호 화면](/images/contract-share-04.png)

::: warning 링크를 만든 본인도 비밀번호를 넣어야 합니다
로그인되어 있어도 그냥 통과되지 않습니다. **정한 비밀번호를 기억해 두세요.**
잊으셨으면 **계약 공유 관리**의 눈 아이콘으로 확인하시면 됩니다.
:::

비밀번호를 넣으면 공유 계약 화면이 열립니다.

![공유된 계약](/images/contract-share-05.png)

탭은 **계약서 관리 · 확인 설명서 · 추가 서류 관리** 세 개만 있습니다.
계약 후 관리와 계약 업데이트는 원본에서만 합니다.

::: tip 무엇을 고칠 수 없나
화면에 이렇게 적혀 있습니다.

> [거래당사자 등 인적사항]과 [부속필지]등 일부항목은 [공유URL을 생성한 사용자만] 수정할 수 있습니다.

상대 부동산이 **고객 정보를 건드릴 수 없다**는 뜻입니다.
:::

## 4. 수정한 내용은 어디로 가나

두 방향을 구분하셔야 합니다.

| 어디서 고쳤나 | 어떻게 되나 |
| --- | --- |
| **공유 계약 안에서** 고침 | **상대방 화면에 바로 보입니다.** 최초 계약 원본은 그대로 보존됩니다 |
| **원본 계약에서** 고침 | 공유 계약에 **자동으로 따라가지 않습니다** |

화면 안내 그대로입니다.

> 내용 수정 시 상대방도 변경된 내용이 보입됩니다.(최초 계약원본은 보존됩니다.)

즉 공동 작업은 **공유 계약 쪽에서** 하시면 됩니다.

## 5. 작업이 끝나면

| 누가 | 무엇을 누르나 | 결과 |
| --- | --- | --- |
| 링크를 만든 사람 | **원본 계약에 저장** | 원본에 덮어쓰기 |
| 상대 부동산 | **내 계약으로 등록** | 자기 계약 사본이 생김 |

원본을 그냥 보고 싶으면 **원본 계약으로 이동**을 누릅니다.

::: warning 상대에게 넘어가는 고객 정보
상대가 내 계약으로 등록해도 **계약서에 표시된 사항만** 저장됩니다.
고객 정보 전체가 넘어가지 않습니다.
:::

## 여기서 막히셨다면

::: details 상대가 저장이 안 된다고 합니다
부동산이지 **비회원**이면 조회와 인쇄만 됩니다. 회원가입이 필요합니다.
:::

::: details 링크를 잘못 보냈습니다
**계약 공유 관리**에서 **공유링크 삭제**를 누르면 링크가 막힙니다.
만료기한을 짧게 바꾸는 방법도 있습니다.
:::

::: details 공유한 뒤 원본을 고쳤는데 상대 화면에 안 보입니다
원본에서 고친 것은 공유 계약에 따라가지 않습니다.
**공유된 계약으로 이동**해서 그쪽에서 고치세요. 그러면 상대방 화면에 바로 보입니다.
:::

::: details 비밀번호를 잊었습니다
**계약 공유 관리** 창의 문서 비밀번호 옆 **눈 아이콘**을 누르면 보입니다.
:::
