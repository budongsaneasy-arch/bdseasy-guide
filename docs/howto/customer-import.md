# 고객 한 번에 불러오기

> **걸리는 시간** 약 10분 &nbsp;·&nbsp; **미리 준비할 것** 구글 연락처 계정 또는 고객 명단 엑셀

핸드폰과 장부에 흩어져 있는 고객을 **한 번에** 부동산이지로 옮깁니다.

처음 한 번이 번거롭지, 이걸 해두면 그다음부터 일이 줄어듭니다.

## 1. 일괄 등록 열기

![고객 일괄 등록](/images/customer-import-01.png)

`고객 → 고객 관리`에서 **고객 일괄 등록 +** 를 누릅니다.

방법이 두 가지입니다.

| 유형 | 언제 쓰나 |
| --- | --- |
| **구글CSV** | 핸드폰 연락처를 구글에 동기화해 두신 경우 |
| **엑셀** | 이미 엑셀로 명단을 관리하고 계신 경우 |

## 2. 구글 연락처로 가져오기

화면의 **구글 연락처** 버튼을 누르면 구글 주소록으로 이동합니다.
거기서 **내보내기 → Google CSV** 형식으로 파일을 받습니다.

받은 파일을 **파일 선택**으로 올리고 **등록**을 누르면 끝입니다.

::: tip 핸드폰 연락처가 구글에 없다면
안드로이드는 대부분 자동으로 동기화되어 있습니다.
아이폰이라면 연락처를 구글 계정과 동기화한 뒤 내보내시면 됩니다.
:::

## 3. 엑셀로 가져오기

**엑셀**을 고르면 양식을 내려받을 수 있습니다. 그 양식에 맞춰 채운 뒤 올립니다.

::: warning 두 가지만 지키세요
- **이름은 반드시 있어야 합니다**
- **전화번호는 `-` 를 포함해서** 넣으세요 (010-0000-0000)
:::

## 4. 올린 뒤에 분류하세요

일괄 등록으로 들어온 고객은 **고객 유형과 구분이 비어 있습니다.**
매도·임대·매수·임차는 **한 명씩 직접** 지정해야 합니다.

::: tip 한꺼번에 다 하지 마세요
수백 명을 한 번에 분류하려면 지칩니다.
**상담이 생길 때마다 그 사람만** 분류해 나가는 편이 현실적입니다.
이름과 번호가 이미 들어와 있으니, 전화가 오면 누구인지 바로 뜹니다.
:::

## 여기서 막히셨다면

::: details 올렸는데 일부가 안 들어왔습니다
이름이 비어 있는 줄은 등록되지 않습니다. 파일에서 이름 칸을 확인하세요.
:::

::: details 전화번호가 이상하게 들어왔습니다
`-` 없이 넣으면 형식이 어긋날 수 있습니다. 양식대로 `010-0000-0000` 형태로 맞춰 주세요.
:::

::: details 중복으로 들어간 것 같습니다
같은 사람이 핸드폰에 두 번 저장되어 있으면 그대로 두 건이 들어옵니다.
구글 연락처에서 **중복 항목 병합**을 먼저 하고 내보내시면 깔끔합니다.
:::
