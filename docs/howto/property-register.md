# 매물 접수하기

> **걸리는 시간** 약 10분 &nbsp;·&nbsp; **미리 준비할 것** 부동산 지번주소, 의뢰인 연락처, 거래 조건

접수한 매물이 **계약서·확인설명서·네이버 광고의 원본**이 됩니다.
여기서 정확히 넣어두면 뒤에서 다시 칠 일이 없습니다.

토지 약 4,000만 필지, 건축물 약 750만 동, 집합건물 약 2,000만 호의 정보가 이미 들어 있어서
주소만 찾으면 구조·면적·지목·대지권이 자동으로 채워집니다.

## 접수하는 길은 세 가지입니다

| 언제 | 어디서 |
| --- | --- |
| 단지를 보면서 호실을 고를 때 | **부동산 원장 → 부동산 원장 관리** 의 원장 그리드 |
| 지도에서 건물을 찍을 때 | **부동산 원장 → 원장 지도** |
| 고객과 통화하면서 바로 받을 때 | **매물 → 매물 접수** |

네이버에 올라온 매물을 보고 바로 받으실 때는 **매물 → N 매물 모니터링**에서도 접수할 수 있습니다.

::: warning 주소는 반드시 검색해서 넣으세요
직접 타이핑하면 나중에 **공적장부 조회가 안 됩니다.**
중개업의 기본 주소는 **지번주소**입니다. 계약서 소재지도 지번주소로 들어갑니다.

왜 이렇게 만들어졌는지는 [왜 대장이 먼저인가](/concept/why-records-first)를 보세요.
:::

## 1. 매물 접수 화면 열기

<!-- 스크린샷: docs/public/images/property-register-01.png 로 저장하고 아래 주석을 푸세요 -->
![매물 접수 화면 열기](/images/property-register-01.png)

상단 메뉴에서 **매물 → 매물 접수**를 누릅니다.

**불러오기**를 누르면 '부동산 소재지 추가' 창이 뜹니다.
부동산 유형을 **통합 / 건축물 / 토지** 중에서 고르고 주소를 검색한 뒤 **선택**을 누릅니다.

## 2. 기초 정보 입력하기

<!-- ![기초 정보 입력](/images/property-register-02.png) -->

주소를 불러오면 구조·주용도·면적·지목·대지권종류·대지권비율이 자동으로 채워집니다.
비어 있으면 **다시 불러오기**나 **공적장부**를 눌러 보세요.

여기서 꼭 고르셔야 하는 것은 **물건유형**입니다.

> 아파트 · 연립/다세대 · 단독/다가구 · 원룸 · 1.5룸 · 투룸 · 쓰리룸 · 분양권 · 입주권 · 오피스텔 ·
> 부동산투자 · 상가 · 사무실 · 공장/창고 · 건물 · 토지 · 기타

나머지는 필요한 만큼만 넣으시면 됩니다. 의뢰수단(전화·방문), 담당자,
유입 경로(네이버부동산·블로그·유튜브·워킹 등), 중요도를 남겨두면 나중에 어디서 매물이 오는지 보입니다.

## 3. 상세 정보 입력하기

![상세 정보 입력](/images/property-register-03.png)

**층**은 **건축물 대장 조회**를 누르면 자동으로 표시됩니다.
직접 적지 마세요. 여기서 정확해야 **표시·광고 위반을 피할 수 있습니다.**

**면적타입**(59A, 59B 같은 것)은 네이버 부동산의 면적 정보를 그대로 쓰기 때문에
넣어두시면 네이버 광고를 낼 때 편합니다.

의뢰인과 소유자는 **새로 추가하기 +** 또는 **고객 목록에서 추가**로 연결합니다.
같은 사람을 두 번 등록하지 마세요. 한 번만 등록해야 상담일지·일정·의뢰·계약이 하나로 이어집니다.
→ [고객을 왜 한 곳에 모으나](/concept/why-one-customer)

## 4. 사진 등록하기

<!-- ![사진 등록](/images/property-register-04.png) -->

사진에는 카테고리가 있습니다.

> 대표사진 · 평면도 · 매물내부 · 매물외부 · **단지사진 · 단지시설 · 주변** · 보일러 · 기타 · 미분류

**단지사진 · 단지시설 · 주변**으로 지정한 사진은 **단지 안 모든 호실에 함께 표시됩니다.**
한 번만 올리면 되니 같은 단지를 여러 건 다루실 때 크게 줄어듭니다.

::: tip 사진 두 장이 뒤에서 일을 합니다
- **대표 사진** → 매물 브리핑과 목록 썸네일에 쓰입니다
- **보일러 사진** → 확인설명서 작성에 연동됩니다

등록해 둔 사진은 네이버 광고를 낼 때 **자동으로 첨부**됩니다.
:::

## 5. 추가 서류 챙기기

<!-- ![추가 서류](/images/property-register-05.png) -->

원장 상세의 **매물접수(첨부파일)** 탭에서 등기권리증·등기사항증명서·토지대장 같은 서류를 붙여 둘 수 있습니다.

미리보기는 이미지와 PDF(PC)만 됩니다.

## 접수한 뒤에 바로 할 수 있는 것

원장 상세의 **매물접수(첨부파일)** 탭에 버튼이 모여 있습니다.

| 버튼 | 무엇을 하나 |
| --- | --- |
| **AI 광고설명** | 네이버 광고 제목과 매물설명 초안을 만들어 줍니다 |
| **AI 권리분석** | 권리관계를 분석해 줍니다. **공적장부를 먼저 떼야 제대로 나옵니다** |
| **매물 브리핑 인쇄** | 매물리스트·매물요약표·매물포스트를 뽑습니다 |
| **네이버 광고 접수 (RETS)** | 네이버 부동산 광고로 바로 넘어갑니다 |

## 여기서 막히셨다면

::: details 통합검색으로 건물이 안 나옵니다
대장에 단지명이 있어야 통합검색에 잡힙니다.
안 나오면 **건축물** 또는 **토지**를 골라 **지번주소로 직접** 검색하세요.
:::

::: details 집합건물이 아닌데 호실을 나눠 관리하고 싶습니다
다가구·원룸·상가처럼 한 건물에 여러 호실이 있으면 **일부임대차**를 추가하시면 됩니다.
원장 그리드에서 **동명칭 없음**을 누르고 **일부임대차 추가**를 선택하세요.

건축물대장의 층별 정보를 바탕으로 **한 번에 여러 건을 만들 수도 있습니다.**
:::

::: details 주택임대사업자 매물은 뭐가 다른가요
주택임대사업자는 의무사항이 까다로워서 중개사고로 이어지는 경우가 많습니다.
시세보다 저렴한 매물이 많으므로 미리 등록해 두고 관리하시는 편이 좋습니다.

특히 **표준임대차계약서 사용 · 임대료 증액 제한 · 임대의무기간 준수 · 임대보증금 보증**은
계약 전에 반드시 확인하셔야 합니다.
:::

::: details 사진은 몇 장까지 올라가나요
베이직은 **100장**, 플러스는 **1,000장**입니다. *(2026.09 기준)*
:::
