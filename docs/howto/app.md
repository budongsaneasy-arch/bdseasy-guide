# 부동산이지 앱 설치하고 쓰기

> **걸리는 시간** 설치까지 약 15분 &nbsp;·&nbsp; **미리 준비할 것** 안드로이드 휴대폰, 부동산이지 아이디·비밀번호

사무실 컴퓨터 앞에 앉아 있을 때만 중개를 하는 것은 아닙니다.
**전화는 길에서, 차 안에서, 임장 현장에서 옵니다.**

부동산이지 앱은 그렇게 걸려 온 전화를 **그 자리에서 고객으로 만들고, 상담 내용을 바로 적어 두는** 도구입니다.
적어 둔 것은 사무실 컴퓨터의 부동산이지에 그대로 올라옵니다.

::: warning 안드로이드 휴대폰에서만 씁니다
**아이폰에서는 쓰실 수 없습니다.** 안드로이드 전용입니다.

안드로이드라도 **구글 플레이스토어에는 없습니다.** **원스토어**에서만 내려받을 수 있습니다.
그래서 설치가 조금 낯섭니다. 이 문서의 **1~5번을 순서대로** 따라가시면 됩니다.
:::

---

## 앱이 하는 일

앱은 부동산이지의 **전부가 아닙니다.** 전화와 문자에 관한 것만 다룹니다.

| 앱에서 하는 일 | 사무실 컴퓨터에서 보는 곳 |
| --- | --- |
| 걸려 온 전화를 **고객으로 등록** | `고객 → 고객 관리` |
| 통화하면서 **상담일지 작성** | `마케팅 → 상담 일지 관리` |
| 통화 기록이 **자동으로 쌓임** | `마케팅 → 통화 내역` |
| 전화 끊고 **콜백문자 보내기** | — |
| 못 받은 전화에 **자동응답 문자** | — |

매물 접수, 계약서 작성, 광고는 앱에서 하지 않습니다. 컴퓨터에서 하세요.

::: tip 왜 전화를 고객으로 만들어야 하나
부동산이지는 **한 고객에게 모든 것이 붙도록** 만들어져 있습니다.
전화번호만 핸드폰에 남기면 그 연결이 끊깁니다.
→ [고객을 왜 한 곳에 모으나](/concept/why-one-customer)
:::

::: tip 요금제와 관계없이 쓰실 수 있습니다
`마이페이지 → 결제 관리`의 구독정보 화면에는 **「스마트폰을 이용한 고객관리 및 콜백기능」이
플러스 전용**으로 적혀 있습니다. **지금은 아닙니다.**

**베이직에서도 앱 설치·고객관리·콜백문자를 모두 쓰실 수 있습니다.**
*(2026.09 확인 — 화면 표기는 수정 요청 중)*
→ [요금제 — 베이직과 플러스](/reference/plan)
:::

## 설치 — 가장 빠른 길

휴대폰으로 주소를 치는 것이 번거로우면 **부동산이지 안에 있는 QR코드**를 쓰세요.

컴퓨터에서 `마케팅 → 통화 내역`으로 들어가 오른쪽 **모바일 APP 다운로드**를 누릅니다.

![통화 내역의 모바일 APP 다운로드](/images/app-15.png)

뜬 QR코드를 **휴대폰 카메라로 찍으면** 설치 페이지가 바로 열립니다.
그래도 원스토어가 없으면 아래 1번부터 하셔야 합니다.

---

## 1. 원스토어 설치하기

부동산이지 앱은 원스토어에 들어 있습니다. **원스토어부터 휴대폰에 깔아야 합니다.**

휴대폰 인터넷에서 **원스토어**를 검색해 원스토어 사이트로 들어간 뒤, **원스토어앱 설치하기**를 누릅니다.

![네이버에서 원스토어 검색](/images/app-01.png)

**원스토어 다운로드**를 누르면 확인 창이 두 번 뜹니다.

![원스토어 내려받기](/images/app-02.png)

::: warning 「폰에 손상을 줄 수 있습니다」가 떠도 괜찮습니다
이 문구에서 멈추시는 분이 많습니다.

안드로이드는 **플레이스토어 밖에서 설치 파일(apk)을 받을 때 항상** 이 안내를 띄웁니다.
파일에 문제가 있다는 뜻이 아니라, **출처를 한 번 더 확인하라**는 안내입니다.

그러니 지우지 마시고 **출처 줄을 보세요.** `onestore.co.kr` 로 끝나면 원스토어 공식 서버에서 온 것입니다.
맞으면 **다운로드**를 누르시면 됩니다.

반대로, 문자나 카카오톡으로 받은 링크에서 이 창이 뜬다면 **그때는 누르지 마세요.**
:::

내려받은 뒤 **휴대폰 위에서 아래로 쓸어내려 알림 목록을 열고**, 받은 설치 파일을 눌러 설치합니다.
「출처를 알 수 없는 앱 설치」 안내가 나오면 **허용**으로 바꿔 주세요.

## 2. 원스토어에 로그인하기

원스토어에서 앱을 받으려면 **원스토어에 로그인**해야 합니다.
네이버 · 구글 · 카카오 가운데 **이미 쓰고 계신 것 하나**를 고르시면 됩니다.

![원스토어 로그인](/images/app-03.png)

::: tip 원스토어는 어디 것인가요
**원스토어**가 운영하는 앱 장터입니다. 통신사와 상관없이 누구나 쓸 수 있습니다.
자세한 것은 원스토어 홈페이지(`m.onestore.co.kr`) 맨 아래에서 확인하실 수 있습니다.
:::

## 3. 부동산이지 앱 설치하기

원스토어를 열고 위쪽 검색창에 **부동산이지**를 칩니다. 나온 앱에서 **설치**를 누릅니다.

![원스토어에서 부동산이지 검색](/images/app-04.png)

「앱을 설치하시겠습니까?」에 **설치**를 누르면 내려받기가 시작되고, 끝나면 **실행**으로 바뀝니다.

![부동산이지 앱 설치](/images/app-05.png)

## 4. 권한 허용하기

앱을 처음 열면 **「통화매니저 권한 설정 안내」** 화면이 나옵니다.
여기 적힌 권한은 **전부 허용하셔야** 앱이 제대로 움직입니다.

![권한 허용](/images/app-06.png)

| 권한 | 무엇에 쓰나 |
| --- | --- |
| **전화** | 가입자 인증 전화 발신 |
| **통화 기록** | 통화 기록 정보 보기 |
| **주소록** | 저장된 연락처 정보 보기 |
| **저장공간** | 녹취파일 접근 |
| **SMS** | SMS 메시지 전송 |
| **알림** | 앱에서 알림 전송 허용 |

::: warning 하나라도 「허용 안 함」을 누르면
전화가 와도 **고객 창이 뜨지 않거나**, 콜백문자가 나가지 않습니다.
이미 눌러 버리셨다면 휴대폰 `설정 → 앱 → 부동산이지 → 권한`에서 다시 켜실 수 있습니다.
:::

---

## 5. 배터리 최적화 끄기

안드로이드는 오래 안 쓰는 앱을 **혼자 잠재웁니다.** 그러면 전화가 와도 앱이 반응하지 못합니다.
그래서 부동산이지만 예외로 빼 둡니다.

권한 안내에 이어 나오는 목록에서 **부동산이지**를 찾아 스위치를 켭니다.

![목록에서 부동산이지 찾기](/images/app-07.png)

「배터리 사용량 최적화 중지」가 뜨면 **확인**을 누릅니다.

![배터리 사용량 최적화 중지](/images/app-08.png)

::: tip 「다른 앱 위에 표시」도 켜 주세요
전화가 왔을 때 통화 화면 **위에 고객 정보를 띄우려면** 이 권한이 필요합니다.
안내가 뜨면 켜 주시고, 안 떴다면 휴대폰 `설정 → 앱 → 부동산이지`에서 찾으실 수 있습니다.
:::

## 6. 로그인하고 첫 화면 보기

**쓰고 계신 부동산이지 아이디와 비밀번호** 그대로 로그인합니다. 따로 가입하지 않습니다.

![로그인과 첫 화면](/images/app-09.png)

로그인하면 **통화이력** 화면이 열립니다. 아래쪽에 탭이 네 개 있습니다.

| 탭 | 무엇 |
| --- | --- |
| **통화이력** | 걸고 받은 전화가 쌓입니다 |
| **상담일지** | 적어 둔 상담 내용 |
| **고객** | 앱에서 보는 고객 목록 |
| **설정** | 콜백문자 · 자동응답 · 명함 |

통화이력 화면 오른쪽 위의 **부동산이지 바로가기**를 누르면 부동산이지가 열립니다.
*(이 버튼은 통화이력 화면에만 있습니다)*

::: tip 설정에서 명함부터 등록하세요
설정 화면에 **「명함을 등록해 주세요」**가 있습니다.
먼저 넣어 두시면 콜백문자와 함께 나갑니다.
:::

---

## 7. 전화가 오면 — 고객 만들기

등록되지 않은 번호로 전화가 오면 **미등록고객**이라고 뜹니다.
여기서 **고객 생성**을 누르면 부동산이지의 고객으로 바로 들어갑니다.

![앱에서 고객 만들기](/images/app-12.png)

고객 이름 · 별칭 · 주소 · 고객노트 · 등급 · 담당자를 넣고 **저장하기**를 누릅니다.
연락처는 **걸려 온 번호가 이미 들어와 있습니다.**

::: warning 핸드폰 주소록에 저장하는 것과 다릅니다
핸드폰에 저장하면 **부동산이지에는 아무것도 남지 않습니다.**
이 화면에서 만드셔야 사무실 컴퓨터의 `고객 → 고객 관리`에 나타납니다.
:::

---

## 8. 통화하면서 상담일지 쓰기

같은 창에서 **상담일지 작성**을 누르면 입력칸이 열립니다.
통화가 끝나기 전에 **들은 말을 그대로** 적어 두세요.

![상담일지 작성](/images/app-13.png)

이미 적어 둔 것이 있으면 **통화 중에 그 고객의 지난 상담 내용이 함께 보입니다.**
"저번에 말씀하신 그 건" 을 바로 받아칠 수 있습니다.

---

## 9. 콜백문자 보내기

전화를 끊고 **콜백문자 보내기**를 누르면, 미리 정해 둔 문구가 그대로 나갑니다.

![콜백문자](/images/app-14.png)

::: tip 문구는 한 번만 정해 두면 됩니다
번호를 바꿔 넣거나 매번 쓰지 않습니다. **아래 10번에서 한 번 저장**해 두면 끝입니다.
:::

---

## 10. 콜백문자 내용 정하기

**앱에서** — 설정 탭 → **콜백문자 내용 설정**을 누르면 「메시지 수정」 창이 열립니다.

![앱에서 콜백문자 내용 고치기](/images/app-10.png)

**컴퓨터에서** — `마이페이지 → 템플릿 관리 → SMS 콜백`에서도 같은 내용을 고칠 수 있습니다.
긴 문구는 이쪽이 편합니다.

![마이페이지 → 템플릿 관리 → SMS 콜백](/images/app-17.png)

::: warning 문자에 들어갈 번호를 다시 확인하세요
콜백문자는 **고객에게 그대로 갑니다.** 사무소 대표번호가 맞는지,
개인 번호가 잘못 들어가 있지 않은지 저장 전에 한 번 보세요.
:::

---

## 11. 못 받은 전화에 자동응답 보내기

임장이나 상담 중이라 전화를 못 받았을 때, **자동으로 문자를 보내도록** 해 둘 수 있습니다.

설정 탭 → **자동응답 문자 설정**에서 스위치를 켜고, **시작 시간과 종료 시간**, 보낼 문구를 넣습니다.

![자동응답 문자 설정](/images/app-11.png)

- 정해 둔 시간 **밖에서는 나가지 않습니다.** 새벽에 문자가 가지 않도록 끝 시간을 정해 두세요
- 문구는 **글자 수 제한**이 있습니다. 입력칸 아래 숫자로 남은 양이 보입니다

## 12. 컴퓨터에서 확인하기

앱에서 쌓은 것은 **사무실 컴퓨터에서 그대로 보입니다.**

`마케팅 → 상담 일지 관리` — 앱에서 쓴 상담일지가 여기 모입니다.
상담 수단(방문 · 전화 수신 · 전화 발신 · 문자/카카오톡)과 상태(접수 · 완료)로 걸러 볼 수 있습니다.

![상담 일지 관리](/images/app-16.png)

`마케팅 → 통화 내역` — 걸고 받은 전화가 날짜순으로 쌓입니다.
수신·발신, 통화 일시, 상담 고객, 휴대폰 번호가 그대로 남습니다.

![통화 내역](/images/app-18.png)

`고객 → 고객 관리` — 앱에서 만든 고객이 들어와 있습니다.
→ [고객 등록하고 관리하기](/howto/customer)

## 여기서 막히셨다면

::: details 「폰에 손상을 줄 수 있습니다」가 무서워서 못 누르겠습니다
안드로이드가 **플레이스토어 밖 설치 파일에 항상 띄우는 안내**입니다.
출처 줄이 `onestore.co.kr` 로 끝나는지만 확인하시고 진행하세요.
→ [위 1번 설명](#_1-원스토어-설치하기)
:::

::: details 전화가 와도 고객 창이 뜨지 않습니다
세 가지를 차례로 보세요.

1. **권한** — 휴대폰 `설정 → 앱 → 부동산이지 → 권한`에서 전화·통화 기록·주소록이 허용인지
2. **다른 앱 위에 표시** — 꺼져 있으면 통화 화면 위에 아무것도 못 띄웁니다
3. **배터리 최적화** — 켜져 있으면 안드로이드가 앱을 잠재웁니다 (위 5번)
:::

::: details 앱에서 만든 고객이 컴퓨터에 안 보입니다
**핸드폰 주소록에 저장하신 것은 아닌지** 먼저 보세요. 그것은 부동산이지와 아무 상관이 없습니다.
앱의 **고객 생성**으로 만드셔야 `고객 → 고객 관리`에 들어갑니다.

이미 같은 분이 고객으로 등록되어 있으면 **미등록고객으로 뜨지 않습니다.**
그때는 전화번호 앞자리를 다르게 저장해 두신 것은 아닌지 확인해 보세요.
:::

::: details 콜백문자가 나가지 않습니다
- 설정에서 **문구를 저장하셨는지** 확인하세요. 비어 있으면 보낼 것이 없습니다
- **SMS 권한**이 허용인지 보세요 (휴대폰 `설정 → 앱 → 부동산이지 → 권한`)
- **요금제 때문은 아닙니다.** 베이직에서도 콜백문자는 나갑니다
:::

::: details 원스토어 로그인이 안 됩니다
