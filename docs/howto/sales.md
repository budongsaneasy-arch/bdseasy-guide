# 매출 관리하기

> **걸리는 시간** 약 3분 &nbsp;·&nbsp; **미리 준비할 것** 정산할 계약

계약에서 나온 중개보수를 매출로 잡고, 사무소 전체 매출을 봅니다.

## 1. 계약에서 매출 잡기

매출은 **계약에서 시작됩니다.**

계약 상세의 **계약 후 관리** 탭으로 가서 **정산관리**의 **매출 추가**를 누릅니다.
[직원 등록하고 배분비율 정하기](/howto/staff)에서 정해 둔 비율대로 나뉩니다.

같은 화면에서 **현금영수증 및 세금계산서 발행**도 관리합니다.

## 2. 전체 매출 보기

`마이페이지 → 매출 관리`에서 사무소 전체 매출을 봅니다.

기간과 담당자로 걸러 볼 수 있습니다.

::: tip 매출은 계약에서만 만들어집니다
매출 관리 화면에서 직접 숫자를 넣는 것이 아니라,
**계약마다 매출 추가를 눌러야** 여기에 쌓입니다.

계약을 끝내고 정산까지 누르는 습관을 들이시면
연말에 따로 집계할 일이 없어집니다.
:::

## 3. 정산 계좌

중개보수 안내문자에서 쓸 계좌는 `마이페이지 → 설정`의 **정산 설정** 탭에서 등록합니다.

등록해 두면 [계약 단계별 안내문자 보내기](/howto/contract-sms)의
**중개보수** 탭에서 계좌를 골라 문자에 넣을 수 있습니다.

## 여기서 막히셨다면

::: details 매출 관리에 아무것도 없습니다
계약에서 **매출 추가**를 누르지 않으셨습니다.
계약 상세 → 계약 후 관리 → 정산관리에서 추가하세요.
:::

::: details 배분이 잘못 나뉘었습니다
`마이페이지 → 배분 비율 관리`에서 비율을 고친 뒤 정산을 다시 확인하세요.
:::
