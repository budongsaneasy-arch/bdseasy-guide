# 권리금 계약서 쓰기

> **걸리는 시간** 약 15분 &nbsp;·&nbsp; **미리 준비할 것** 현 임대차계약서, 사업자등록증, 영업시설·비품 목록과 사진

상가를 넘기고 받을 때 쓰는 **상가건물 임대차 권리금계약서**입니다.

`계약 → 계약 생성`에서 거래 유형 **매매/권리금** → 계약서 유형 **권리금 계약서**를 고릅니다.

::: warning 당사자 이름이 다릅니다
- **임차인** — 권리금을 **받는** 사람 (지금 영업 중인 분)
- **신규임차인** — 권리금을 **주는** 사람 (들어오는 분)

매도인·매수인이 아닙니다. 헷갈리면 계약서 전체가 뒤집힙니다.
:::

![권리금 계약서](/images/contract-premium-01.png)

## 1. 상가건물의 표시

일반 계약서에 없는 항목이 들어갑니다.

- 소재지 / 임대면적 / 건물면적
- **상호**
- **업종**
- **허가(등록)번호**

업종과 허가번호는 사업자등록증을 보고 그대로 옮깁니다.

## 2. 임차인의 임대차계약 현황

지금 임차인이 건물주와 맺고 있는 계약 내용을 적습니다.

- 임차보증금 / 월차임 / 관리비
- **부가가치세 별도 / 포함**
- 계약기간 (12개월·24개월 버튼으로 빠르게 넣을 수 있습니다)

## 3. 권리금 지급 조건

**총 권리금**을 넣고 부가가치세 처리를 고릅니다.

> 부가가치세 별도 / 부가가치세 포함 / **포괄양수도 계약**

그다음 계약금 · 중도금 · 잔금으로 나눕니다.

::: tip 중도금을 넣는 편이 안전합니다
화면에 이런 안내가 있습니다.

> 인테리어나 명도조건일 경우 중도금 지급하는 방식의 계약을 권장합니다.

중도금이 필요 없으면 **중도금 숨기기**를 체크하면 계약서에서 빠집니다.
:::

::: warning 잔금일에 대한 규정이 있습니다
잔금지급일까지 임대인과 신규임차인 사이에 임대차계약이 체결되지 않으면
**임대차계약 체결일을 잔금지급일로 봅니다.** 계약서에 이미 들어 있는 조항입니다.
:::

## 4. 무엇을 넘기는 것인지 정리하세요

제2조에 임차인의 의무가 들어 있습니다. 잔금 지급 때까지 권리금의 대가로
**유형·무형의 재산적 가치**를 이전해야 합니다.

| 구분 | 무엇 |
| --- | --- |
| **유형** | 영업시설 · 비품 등 |
| **무형** | 거래처 · 신용 · 영업상의 노하우 · 상가건물의 위치에 따른 영업상의 이점 등 |

::: danger 유형자산은 사진으로 남기세요
계약서 안내에도 **사진 촬영하여 별지로 첨부할 것을 권장**한다고 되어 있습니다.
무엇을 넘겼는지가 나중에 분쟁의 핵심이 됩니다.
:::

임차인은 신규임차인을 임대인에게 **주선**하고 임대차계약 체결에 협력해야 하며,
전화가입권 이전과 사업자등록 폐지에도 협력해야 합니다.

## 5. 임대차계약이 안 되면 무효입니다

제3조가 중요합니다.

임대인의 계약 거절, 무리한 임대조건 변경, 목적물 훼손 등
**임차인과 신규임차인의 책임 없는 사유로 임대차계약이 체결되지 못하면 본 계약은 무효**이고,
임차인은 받은 계약금 등을 신규임차인에게 **즉시 반환**해야 합니다.

## 여기서 막히셨다면

::: details 포괄양수도 계약이 뭔가요
사업 전체를 통째로 넘기는 형태로, 부가가치세가 과세되지 않습니다.
요건이 까다로우니 **세무 상담을 거친 뒤** 고르시는 것이 안전합니다.
:::

::: details 특약은 어느 구분을 고르나요
**상가 임대차 기본 특약**을 고르세요.
:::
