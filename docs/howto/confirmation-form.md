# 확인설명서 작성하기

> **걸리는 시간** 약 15분 &nbsp;·&nbsp; **미리 준비할 것** 등기부등본, 건축물대장, 토지이용계획확인서, 현장에서 확인한 시설 상태

중개대상물 확인·설명서를 작성하는 방법입니다.
교부 의무가 있고 누락 시 과태료 대상이므로, 마지막 확인 단계를 꼭 거치세요.

::: warning 이 문서는 [아파트 매매계약서 쓰기](/howto/contract-apartment)에서 이어집니다
확인설명서는 **따로 만드는 서류가 아닙니다.** `계약 → 계약 생성` 화면 안에서 계약서와 **함께** 작성합니다.
계약서 부분을 아직 안 쓰셨다면 [계약서 문서](/howto/contract-apartment)를 먼저 보세요.
:::

## 계약서와 함께 쓰기 때문에 좋은 점

당사자·주소·거래금액을 다시 입력할 필요가 없습니다. 계약서에 넣은 값이 그대로 넘어옵니다.
그리고 **두 서류의 내용이 어긋날 일이 없습니다.** 따로 만들면 이게 가장 흔한 사고입니다.

## 1. 확인설명서 부분으로 넘어가기

<!-- ![확인설명서 이어쓰기](/images/confirmation-01.png) -->

계약서 작성을 마친 뒤 같은 화면에서 확인설명서 부분으로 넘어갑니다.
당사자·주소·거래금액이 이미 채워져 있는지 먼저 확인하세요.

## 2. 공적장부 불러오기

<!-- ![공적장부 불러오기](/images/confirmation-02.png) -->

**공적장부 조회**를 누르면 등기부등본·건축물대장·토지이용계획을 한 번에 조회합니다.
조회된 내용이 해당 항목에 자동으로 채워집니다.

::: tip 공적장부만 따로 떼실 때
계약과 무관하게 장부만 열람하실 때는 상단 메뉴 **부동산 원장 → 공적장부**에서 바로 하실 수 있습니다.
등기 내용이 바뀌었는지 확인하실 때는 **부동산 원장 → 등기변동**을 보세요.
:::

::: tip 열람 수수료
등기부 열람에는 수수료가 발생합니다. 부동산이지 이용료와는 별개입니다.
:::

## 3. 기본 확인사항 채우기

<!-- ![기본 확인사항](/images/confirmation-03.png) -->

소재지·면적·권리관계·공법상 제한 등을 확인합니다.
자동으로 채워진 값도 **원본 서류와 대조**하세요. 자동 조회는 보조 수단이지 근거가 아닙니다.

## 4. 세부 확인사항 채우기

<!-- ![세부 확인사항](/images/confirmation-04.png) -->

실제 권리관계, 내·외부 시설물 상태, 벽면·바닥·도배 상태, 환경조건을 입력합니다.
현장에서 확인하신 내용을 그대로 적으시면 됩니다.

## 5. 중개보수 입력하고 출력하기

<!-- ![중개보수와 출력](/images/confirmation-05.png) -->

거래금액에 따른 중개보수가 자동 계산됩니다. 협의한 요율이 다르면 직접 고치세요.
**미리보기**로 빈칸이 없는지 확인한 뒤 출력합니다.

::: warning 출력 전 마지막 확인
빈칸으로 남은 항목이 있으면 미리보기 상단에 표시됩니다.
**빈칸인 채로 교부하면 과태료 대상이 될 수 있습니다.** 반드시 확인하고 출력하세요.
:::

## 여기서 막히셨다면

::: details 계약서 내용이 확인설명서로 안 넘어옵니다
계약서 부분을 **저장하지 않은 상태**에서 확인설명서 부분으로 넘어가면 값이 비어 있습니다.
계약서 부분으로 돌아가 저장한 뒤 다시 시도하세요.

같은 단지의 다른 호수를 연달아 작업하실 때 이전 호수 정보가 남는 경우가 있습니다.
이때는 창을 모두 닫고 계약서 목록에서 다시 여세요.
:::

::: details 공적장부 조회가 실패합니다
주소가 도로명주소로 확정되지 않았거나, 집합건물의 동·호수가 빠진 경우가 대부분입니다.
매물 화면에서 주소를 다시 검색해 저장한 뒤 재시도하세요.
계속 실패하면 열람 기관 점검 시간일 수 있으니 잠시 후 다시 시도해 보세요.
:::
