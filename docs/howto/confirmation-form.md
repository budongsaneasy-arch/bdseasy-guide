# 확인설명서 작성하기 (주거용)

> **걸리는 시간** 공부를 미리 떼어 두셨다면 약 10분 &nbsp;·&nbsp;
> **미리 준비할 것** 작성 중인 계약서, 공적장부(등기·대장·토지이용계획), 매물 사진

확인설명서는 **별도 메뉴가 없습니다.** 계약서를 만든 다음, 그 계약 안의 **확인 설명서** 탭에서 씁니다.

::: warning 이 문서는 주거용만 다룹니다
단독주택·공동주택·주거용 오피스텔에 쓰는 **[Ⅰ] 주거용 건축물** 서식입니다.
비주거용·토지 서식은 여기서 항목이 빠진 형태라 흐름은 같습니다.
:::

## 법정 양식과 무엇이 다른가

먼저 이것부터 보셔야 합니다. **항목 번호도 순서도 법정 양식 그대로입니다.**
①~⑮, `Ⅰ 기본 확인사항` / `Ⅱ 세부 확인사항` / `Ⅲ 중개보수`가 화면에 그대로 있습니다.

다른 것은 **손으로 옮겨 적던 칸이 버튼으로 바뀌었다**는 점입니다.

| 항목 | 법정 양식에서는 | 부동산이지에서는 |
| --- | --- | --- |
| ① 대상물건의 표시 | 대장을 보고 옮겨 적음 | **대장 정보로 입력** |
| ② 권리관계 | 등기를 보고 옮겨 적음 | **발급 받은 등기로 [토지] 입력** · **[건축물] 입력** |
| ③ 토지이용계획 | 확인서를 보고 옮겨 적음 | **토지이용(열람)으로 입력** |
| ⑧ 거래예정금액 | 공시가격을 찾아 적음 | **공시지가 조회** · **공시가격 조회** · **시가표준액 조회** |
| ⑨ 취득 시 부담할 조세 | 세율을 찾아 적음 | **취득조세 계산기** |
| ⑮ 중개보수 산출내역 | `550,000,000 × 0.4%` 처럼 직접 씀 | 거래금액·유형·요율을 고르면 **문자열이 만들어짐** |

옮겨 적지 않으니 틀릴 일이 없습니다.
왜 이렇게 만들었는지는 → [왜 대장이 먼저인가](/concept/why-records-first)

::: tip 공부를 먼저 떼어 두세요
이 버튼들은 **이미 발급받은 공적장부가 있어야** 값을 가져옵니다.
확인설명서를 열기 전에 공부부터 떼는 것이 순서입니다.
→ [공적장부 한 번에 떼기](/howto/public-records)
:::

## 1. 확인설명서 열기

`계약 → 계약 관리`에서 계약을 열고 **확인 설명서** 탭을 누릅니다.

![확인설명서 첫 화면](/images/confirm-01.png)

맨 위에 **주거용 / 비주거용** 토글이 있습니다. 매물 종류에 따라 이미 골라져 있습니다.

::: danger 다 쓴 뒤에 양식을 바꾸지 마세요
토글을 누르면 이런 경고가 뜹니다.

> 확인설명서 양식을 전환하시겠습니까?
> (두 양식 간 차이가 있는 값은 없어지거나 **최악의 경우 모든 데이터가 초기화**될 수 있습니다.)

![양식 전환 경고](/images/confirm-07.png)

바꿔야 한다면 **쓰기 전에** 바꾸세요.
:::

## 2. 주택 유형과 거래형태 고르기

| 고르는 것 | 선택지 |
| --- | --- |
| 주택의 유형 | 단독주택 · 공동주택 · 주거용 오피스텔 |
| 거래형태 | 매매·교환 · 임대 |

::: tip 거래형태를 고르면 칸이 잠깁니다
**매매·교환**을 고르면 **④ 임대차 확인사항이 회색으로 비활성화**됩니다.
법정 작성방법에서 "임대차의 경우에만 작성"이라고 한 부분을 화면이 대신 막아 줍니다.

③ 토지이용계획 아래에도 이런 안내가 붙습니다.

> 확인설명서 작성방법에 의거, 임대차 계약을 체결하는 경우에는 생략됩니다.
:::

거래형태별로 빠지는 항목은 이렇습니다.

| 항목 | 매매·교환 | 임대 |
| --- | :---: | :---: |
| ③ 그 밖의 이용제한 및 거래규제사항 | 작성 | 생략 |
| ④ 임대차 확인사항 | **잠김** | 작성 |
| ⑥ 관리에 관한 사항 | 의무 아님 | 작성 |
| ⑧ 개별공시지가 · 건물공시가격 | 작성 | 생략 가능 |
| ⑨ 취득 시 부담할 조세 | 작성 | 제외 |

## 3. 확인·설명 자료 체크하기

내가 무엇을 보고 확인했는지를 체크하는 칸입니다.

> 등기권리증 · 등기사항증명서 · 신탁원부 · 토지대장 · 건축물대장 · 지적도 · 임야도 ·
> 토지이용계획확인서 · 확정일자부여현황 · 전입세대확인서 · 국세납세증명서 · 지방세납세증명서 · 그밖의 자료

::: warning 실제로 본 것만 체크하세요
이 체크가 곧 **"내가 이 자료로 확인했다"는 기록**입니다.
분쟁이 생기면 여기가 근거가 됩니다. 떼지 않은 서류를 체크하지 마세요.
:::

옆의 **추가서류 관리로 이동**을 누르면 그 서류를 첨부하는 화면으로 갑니다.

### 자료요구사항은 문구가 미리 들어 있습니다

**대상물건의 상태에 관한 자료요구사항** 칸에는 이 문장이 이미 채워져 있습니다.

> 거래당사자는 위 "확인·설명근거자료 등"에 대한 사항을 발급/열람,검색을 통해 확인하였으며,
> 물건의 현장답사를 통해 육안으로 확인/인지한 후 개업공인중개사가 작성한 아래
> "Ⅱ. 개업공인중개사 세부 확인사항"에 대한 설명을 통해 각 항목 기재 사항을 확인하고 내용에 동의함.

법정 양식에는 없는 문구입니다. 사무소 사정에 맞게 고쳐 쓰셔도 됩니다.

## 4. Ⅰ. 기본 확인사항 — 공부에서 끌어오기

여기는 **중개사가 공부를 보고 확인하는** 영역입니다. ①~⑨.

![대상물건의 표시와 권리관계](/images/confirm-02.png)

### ① 대상물건의 표시

계약서와 원장에서 **소재지·면적·전용면적·대지지분·준공년도·구조·건축물대장상 용도가 이미 채워져** 들어옵니다.

손으로 채우실 곳은 **실제 이용상태 · 실제 용도 · 방향**입니다.

| 버튼 | 무엇을 하나 |
| --- | --- |
| **대장 정보로 입력** | 건축물대장상 **위반건축물 여부**와 **위반내용**을 가져옵니다 |
| 직접입력 (대지지분) | 자동값을 쓰지 않고 직접 넣을 때 |

::: tip 방향은 무엇을 기준으로 적나요
주택은 **거실이나 안방 등 주실(主室)의 방향**, 그 밖의 건축물은 **주된 출입구의 방향**입니다.
남향·북향처럼 적고 **기준을 함께** 적습니다.
:::

### ② 권리관계

::: danger 계약서의 인적사항을 옮겨 적으면 안 됩니다
화면에 빨간 글씨로 이 경고가 붙어 있습니다.

> ※ 주의 - [계약서]의 인적사항을 기재하면 안됩니다

여기 적는 것은 **등기사항증명서에 적힌 등기명의인**입니다.
계약 당사자와 등기명의인이 다를 수 있고, 다르면 그 자체가 확인할 사항입니다.
:::

**발급 받은 등기로 [토지] 입력** / **[건축물] 입력** 버튼을 누르면
소유권에 관한 사항과 소유권 외의 권리사항이 채워집니다.

내용이 길면 **별지에 기재**를 체크합니다.

아래 세 가지는 체크로 답합니다.

| 항목 | 선택지 |
| --- | --- |
| 신탁등기 여부 | 확인 / 유효한 임대차계약 여부 등 주요내용 설명 / 해당 없음 |
| 공동담보 여부 | 확인 / 공동담보 목록 등 선순위권리관계 설명 / 해당 없음 |
| 계약갱신 요구권 행사여부 | 확인(확인서류 첨부) / 미확인 / 해당사항없음 |

계약갱신 요구권 옆에도 **추가서류 관리로 이동**이 있습니다.

### ③ 토지이용계획, 공법상 이용제한 및 거래규제

![토지이용계획과 임대차 확인사항](/images/confirm-03.png)

| 버튼 | 무엇을 하나 |
| --- | --- |
| **토지이용(열람)으로 입력** | 발급받은 토지이용계획확인서에서 채웁니다 |
| **토지 이용 계획 열람** | 토지이음으로 이동 |
| **기타 정보 확인** | 그 밖의 정보를 확인합니다 |

용도지역·용도지구·용도구역, 건폐율/용적률 상한, 도시·군계획시설,
허가·신고 구역 여부(토지거래허가구역),
투기지역 여부(토지투기지역·주택투기지역·투기과열지구)를 넣습니다.

::: tip 건폐율·용적률 상한은 조례를 봅니다
**시·군 조례**에 따라 다릅니다. 확인서에 적힌 용도지역에 해당하는 조례값을 넣으세요.
:::

### ④ 임대차 확인사항 (임대 계약일 때만)

확정일자 부여현황 정보 · 국세 및 지방세 체납정보 · 전입세대 확인서 ·
최우선변제금 · 민간임대 등록 여부를 확인합니다.

각 줄마다 **추가서류 관리로 이동** 버튼이 있어 서류를 붙일 수 있습니다.

::: warning 최우선변제금은 "지금"이 아니라 "그때" 기준입니다
근저당권 등 선순위 담보물권이 설정되어 있으면,
**그 담보물권을 설정할 당시**의 소액임차인범위와 최우선변제금액을 기준으로 적습니다.
:::

### ⑤~⑨ 나머지 기본 확인사항

| 항목 | 넣는 것 |
| --- | --- |
| ⑤ 입지조건 | 도로와의 관계, 접근성, 대중교통, 주차장, 교육시설 |
| ⑥ 관리에 관한 사항 | 경비실, 관리주체, 관리비 금액과 포함 비목, 부과방식 |
| ⑦ 비선호시설(1km이내) | 없음 / 있음(종류 및 위치) |
| ⑧ 거래예정금액 등 | 거래예정금액, 개별공시지가(㎡당), 건물(주택)공시가격 |
| ⑨ 취득 시 부담할 조세 | 취득세 · 농어촌특별세 · 지방교육세 |

::: danger 도로 폭은 보수적으로 적으세요
교안의 실무 지침입니다.

> 도로의 폭은 실제 예상보다 **작게 적으면 문제가 없지만, 크게 적으면 문제가 됩니다.**

넓게 적었다가 실제가 좁으면 책임이 따라옵니다.
:::

⑧에는 **공시지가 조회 · 공시가격 조회 · 부동산공시가격알리미 · 시가표준액 조회(서울시) · 시가표준액 조회(그 외)** 버튼이,
⑨에는 **취득조세 계산기**가 붙어 있습니다.

## 5. Ⅱ. 세부 확인사항 — 직접 보고 물어서

여기부터는 성격이 다릅니다. 공부가 아니라 **의뢰인에게 자료를 요구하고, 현장에서 눈으로 본** 것을 적습니다.

### ⑩ 실제 권리관계 또는 공시되지 않은 물건의 권리 사항

매도(임대)의뢰인이 고지한 사항을 적습니다. 유치권, 법정지상권, 미등기 임차인,
토지에 부착된 조각물·정원수, 계약 전 소유권 변동 여부 같은 것들입니다.

길면 **별지에 기재**를 체크합니다.

### ⑪ 내부·외부 시설물의 상태 (건축물)

![내부·외부 시설물](/images/confirm-04.png)

수도(파손여부·용수량) · 전기 · 가스(취사용) · 소방(단독경보형 감지기) ·
난방방식 및 연료공급 · 승강기 · 배수 · 그 밖의 시설물.

::: tip 보일러 사진은 여기로 들어옵니다
**난방방식 및 연료공급 → 시설작동** 옆, `*개별공급인 경우 사용연한` 아래에 **[사진]** 버튼이 있습니다.

누르면 매물 사진이 뜨고, 분류에 **보일러**가 따로 있습니다.

![사진 분류에 보일러가 있습니다](/images/confirm-05.png)

> 전체 · 대표사진 · 평면도 · 매물내부 · 매물외부 · 단지사진 · 단지시설 · 주변 · **보일러** · 기타 · 미분류

매물을 접수하실 때 보일러 명판을 찍어 **보일러 분류로 넣어 두시면**,
여기서 바로 꺼내 보며 사용연한을 적을 수 있습니다.
→ [매물 접수하기](/howto/property-register)
:::

### ⑫ 벽면·바닥면 및 도배 상태

벽면 균열·누수(있으면 위치), 바닥면, 도배.

### ⑬ 환경조건

일조량 · 소음 · 진동.

### ⑭ 현장안내

현장안내자를 고릅니다 — 개업공인중개사 / 소속공인중개사 / 중개보조원 / 해당없음.

::: danger 중개보조원이 안내했다면 신분고지 여부를 반드시
중개보조원을 고르면 **신분고지 여부(예/아니오)** 가 따라옵니다.

중개보조원은 법 제18조의4에 따라 현장안내 전에 **본인이 중개보조원임을 미리 알려야** 합니다.
알리지 않으면 제재 대상입니다.
:::

## 6. Ⅲ. 중개보수

![중개보수 산출내역](/images/confirm-06.png)

오른쪽 **&lt;산출내역&gt;** 에서 세 가지를 고르면 산출식이 만들어집니다.

| 고르는 것 | 설명 |
| --- | --- |
| 거래예정금액 | **계약서에서 자동으로** 들어옵니다 (매매는 거래금액) |
| 부동산유형 | **주택 / 오피스텔(85㎡이하 등) / 그 외** — 요율표가 갈립니다 |
| 요율 | 고르면 한도가 함께 표시됩니다 |

만들어진 산출내역은 **확인설명서를 인쇄할 때 [산출내역] 칸에 그대로 찍힙니다.**
옆의 **중개보수 요율표 확인** 버튼으로 요율을 확인할 수 있습니다.

왼쪽에는 중개보수 · 실비 · 계 · 지급시기를 넣고,
계 아래에서 **부가세 10% 포함 / 부가세 4% 포함 / (부가세 별도)** 를 고릅니다.

::: tip 임대차 중개보수 계산식
법정 작성방법 기준입니다.

- 기본: **(보증금 + 월차임 × 100)** × 요율
- 거래예정금액이 **5천만원 미만**이면: **(보증금 + 월차임 × 70)** × 요율
:::

::: tip 지급시기를 비워두지 마세요
`* 별도 약정이 없을 시, 잔금지급일을 입력하세요` 라고 안내가 붙어 있습니다.
:::

## 7. 저장하고 인쇄하기

오른쪽 위 **저장**을 누릅니다. **마지막 저장 일시**가 옆에 표시됩니다.

**미리보기 및 인쇄**로 실제 서식에 어떻게 찍히는지 확인한 뒤 출력합니다.

::: danger 서명·날인이 빠지면 제재 대상입니다
확인설명서에는 **개업공인중개사(법인은 대표자)의 서명 및 날인**이 반드시 있어야 하고,
해당 중개행위를 한 **소속공인중개사가 있으면 그 사람도 함께** 서명·날인해야 합니다.

공동중개라면 **참여한 개업공인중개사 모두** 서명·날인합니다.
:::

## 여기서 막히셨다면

::: details 버튼을 눌러도 값이 안 들어옵니다
그 공부를 아직 발급받지 않으셨습니다.
`부동산 원장 → 공적장부` 또는 계약 화면의 **공적장부[계약]** 에서 먼저 떼세요.
→ [공적장부 한 번에 떼기](/howto/public-records)
:::

::: details ④ 임대차 확인사항이 눌러지지 않습니다
거래형태가 **매매·교환**으로 되어 있습니다. 매매에서는 잠기는 것이 정상입니다.
:::

::: details 양식을 잘못 골라서 바꿔야 합니다
**주거용 / 비주거용** 토글을 누르면 됩니다. 다만 **입력한 값이 사라질 수 있습니다.**
바꾸기 전에 미리보기로 내용을 남겨두시는 편이 안전합니다.
:::

::: details 보일러 사진이 목록에 없습니다
매물 접수 때 사진을 **보일러** 분류로 넣지 않으셨습니다.
사진 창에서 분류를 **전체**로 바꿔 찾아보시거나, 매물 사진을 다시 정리하세요.
:::

::: details 비주거용·토지는 어떻게 쓰나요
흐름은 주거용과 같고 항목이 일부 빠집니다.
이 가이드는 주거용만 다룹니다. 막히시면 help@neobsoft.co.kr 로 문의해 주세요.
:::
