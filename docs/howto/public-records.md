# 공적장부 한 번에 떼기

> **걸리는 시간** 약 4분 &nbsp;·&nbsp; **미리 준비할 것** 부동산 지번주소, 등기 열람용 포인트

등기부등본·건축물대장·토지대장·토지이용계획확인서를 **한 번에 신청해서 한 번에 인쇄**하는 방법입니다.

**부동산이지를 처음 쓰신다면 여기부터 시작하세요.** 효과가 가장 빨리 보이는 기능입니다.
서류를 하나씩 떼면 10분에서 30분, 많게는 두 시간이 걸리지만 여기서는 3분 30초면 끝납니다.

## 왜 이걸 먼저 하나

표시·광고는 **대장이 기준**이고, 확인설명서는 **공인중개사법 제25조**가 기준입니다.
성실하게 확인·설명하지 않았거나 설명 근거자료를 제시하지 못해서
**125만원에서 500만원까지 과태료**를 부담하는 경우가 실제로 많습니다.

서류를 떼는 일이 번거로우면 결국 안 떼게 됩니다. 그래서 여기부터 쉬워져야 합니다.

→ 부동산이지가 왜 대장을 출발점으로 삼는지는 [왜 대장이 먼저인가](/concept/why-records-first)에 정리해 두었습니다.

## 뗄 수 있는 서류

| 서류 | 어디서 | 비용 | 열람/발급 |
| --- | --- | --- | --- |
| 부동산 등기사항증명서(건물) | 등기소 | 700원 | 열람 |
| 부동산 등기사항증명서(토지) | 등기소 | 700원 | 열람 |
| 일반건축물대장 | 세움터 | 무료 | 발급 |
| 집합건축물대장 (총괄표제부·표제부·전유부) | 세움터 | 무료 | 발급 |
| 건축물대장 다가구주택의 호(가구)별 면적대장 | 세움터 | 무료 | 발급 |
| 토지대장 · 임야대장 | 정부24 | 무료 | 발급 |
| 지적도 · 임야도 | 정부24 | 무료 | 발급 |
| 대지권등록부 | 정부24 | 무료 | 발급 |
| 토지이용계획확인서 | 토지이음 | 무료 | 열람 |

*(2026.09 기준)*

::: warning 열람과 발급은 다릅니다
**열람한 공부는 법적 효력이 없습니다.** 계약서 작성에 필요한 공부는 반드시 **발급**받으시고,
발급받은 서류에 **직인이 찍혀 있는지** 확인하세요.
:::

::: tip 다가구주택을 다루신다면
표시·광고를 하고 확인설명서를 문제없이 쓰시려면
**반드시 사전에 '다가구주택의 호(가구)별 면적대장'을 발급**받아 해당 호실 면적을 확인하셔야 합니다.
:::

## 1. 공적장부 화면 열기

<!-- 스크린샷: docs/public/images/public-records-01.png 로 저장하고 아래 주석을 푸세요 -->
![공적장부 화면 열기](/images/public-records-01.png)

상단 메뉴에서 **부동산 원장 → 공적장부**를 누릅니다.
계약과 상관없이 서류만 떼실 때 쓰는 가장 빠른 길입니다.

::: tip 공적장부는 여러 곳에서 들어갈 수 있습니다
한 메뉴에만 있는 기능이 아닙니다. 하시던 일을 멈추지 않고 그 자리에서 바로 서류를 떼실 수 있게 만들어져 있습니다.

| 어디서 | 어떻게 |
| --- | --- |
| 상단 메뉴 | `부동산 원장 → 공적장부` |
| 매물 접수 화면 | 화면 안의 **공적장부** 버튼 |
| 계약서 작성 화면 | 화면 위쪽의 **공적장부** 버튼 |
| 원장 상세 · 원장 그리드 | **공적장부** 버튼 |

계약서 화면에서 뗀 서류는 **[계약]**으로, 그 밖에서 뗀 서류는 **[원장]**으로 분류됩니다.
:::

## 2. 발급 신청하기

![발급 신청](/images/public-records-02.png)

**추가 +** 를 눌러 주소를 넣고, 필요한 서류를 고릅니다.

등기를 뗄 때는 옵션이 두 가지 나옵니다.

- **현재유효사항 / 말소사항포함** — 권리관계 이력까지 보시려면 말소사항포함
- **영구보존문서(신탁등기 등) 포함 / 제외**

## 3. 처리될 때까지 기다리기

![처리중](/images/public-records-03.png)

신청하면 **처리중**으로 바뀌고 여러 건이 동시에 진행됩니다.
같은 시간에 신청이 몰리면 순서를 기다릴 수 있습니다. 요청한 시각이 함께 표시됩니다.

## 4. 위반건축물인지 확인하기

![위반건축물 배지](/images/public-records-04.png)

일반건축물대장에는 **(위반)** 또는 **(적법)** 배지가 자동으로 붙습니다.

건축물대장 변동내용에서 **위반항목만 복사**를 누르면 위반 내용만 뽑아낼 수 있습니다.
확인설명서에 그대로 옮겨 넣으시면 됩니다.

## 5. 한 번에 인쇄하기

<!-- ![일괄 출력](/images/public-records-05.png) -->

**일괄 출력**을 누르면 신청한 서류가 한 번에 인쇄됩니다.

내려받으면 파일명이 주소로 자동 저장되고, 발급 시점까지 함께 남습니다.

## 여기서 막히셨다면

::: details 대장이 발급되지 않습니다
세 가지 중 하나입니다. 공공사이트 접속 문제 / 공공 시스템 장애 / 부동산이 이중으로 조회되는 문제.

1. **재발급**을 먼저 눌러 보세요.
2. 그래도 안 되면 **수정 후 재발급**에서 건물명·동명칭·호명칭을 직접 넣어 보세요.
3. 계속 안 되면 해당 사이트(세움터·정부24·토지이음)에 직접 방문하셔야 합니다.
:::

::: details 등기가 발급되지 않습니다
**수정 후 재발급**을 누르고, 대법원 인터넷등기소에서 **부동산 고유번호**(하이픈 포함 16자리)를 찾아 넣으면 바로 발급됩니다.

고유번호는 인터넷등기소 간편검색에서 주소로 찾으실 수 있습니다.
:::

::: details 하루 몇 건까지 되나요
베이직(무료)은 **하루 3건**, 플러스는 **하루 10건**입니다.
하나의 주소에 포함된 모든 대장을 여는 것이 **1건**으로 계산됩니다.
등기사항증명서는 건수 제한이 없습니다. *(2026.09 기준)*

넘기시려면 `마이페이지 → 결제 관리 → 구독`에서 플러스로 바꾸시면 됩니다.
:::

::: details 발급이 실패했는데 포인트가 빠져나갔습니다
**발급 실패 시 차감된 포인트는 즉시 반환됩니다.** 부가세는 본사가 부담합니다.
반환이 안 되어 있으면 `고객센터 → 문의하기`로 알려주세요.
:::

::: details 이미 뗀 서류를 다시 찾고 싶습니다
원장 상세 화면에서 **공적장부** 글씨가 **파란색**이면 보관 중인 서류가 있다는 뜻입니다. 눌러서 바로 보실 수 있습니다.

단지 그리드에서는 호실에 **서류 아이콘**이 붙어 있으면 저장된 공적장부가 있다는 표시입니다.
:::

::: details 집합건물인데 토지가 여러 필지입니다
하나의 집합건물 대지권의 목적인 토지가 여러 필지인 경우 **부속필지의 권리상태를 반드시 확인**하셔야 합니다.
부동산이지는 부속필지가 있으면 바로 확인할 수 있고, 1건에서 최대 5건까지 발급됩니다.

토지거래허가 때 토지면적을 기록하신다면 **여러 필지 면적의 합**을 기준으로 지분이 기록되어야 합니다.
:::

## 계약할 때는 이렇게 이어집니다

계약서 화면에서 서류를 떼면 **[계약] 공적장부**로 따로 분류되어 관리됩니다.
원장에서 뗀 것은 **[원장]**, 계약에서 뗀 것은 **[계약]**으로 표시가 바뀝니다.

또 건축물대장 전유부를 발급받으면 **전유부의 소유자 정보가 자동으로 기록되고 우편번호까지 채워집니다.**
**고객 등록 및 소유자 지정**을 누르면 그대로 고객 관리로 넘어갑니다.

등기를 발급받으셨다면 **발급 받은 등기로 추가하기 +** 로
소유자뿐 아니라 **근저당 같은 권리 제한사유까지 자동 입력**됩니다. 정확히 들어갔는지는 꼭 확인하세요.
