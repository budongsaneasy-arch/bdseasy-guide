# 등기 열람 포인트 충전하기

> **걸리는 시간** 약 3분 &nbsp;·&nbsp; **미리 준비할 것** 신용카드 또는 계좌

등기사항증명서를 뗄 때 쓰는 포인트를 충전합니다.

## 무엇에 돈이 드나

::: tip 대장은 전부 무료입니다
건축물대장·토지대장·지적도·토지이용계획확인서는 **무료**입니다.
**등기사항증명서만 건당 700원**입니다. *(2026.09 기준)*
:::

| 서류 | 비용 |
| --- | --- |
| 부동산 등기사항증명서 (건물/토지) | **700원** |
| 그 밖의 대장류 전부 | 무료 |

::: warning 발급 실패는 돌려받습니다
**발급 실패 시 차감된 포인트는 즉시 반환**됩니다. 부가세는 본사가 부담합니다.
반환이 안 되어 있으면 `고객센터 → 문의하기`로 알려주세요.
:::

## 1. 충전하기

`마이페이지 → 결제 관리`로 갑니다. 탭이 이렇게 있습니다.

> 구독 / **충전** / 쿠폰 / 결제내역 / 구독정보

**충전하기**를 누르고 금액을 고릅니다.

| 방법 | 내용 |
| --- | --- |
| **신용카드** | 1만 / 2만 / 5만 / 10만원. **1회 최대 10만원, 하루 3회까지** |
| 실시간 계좌이체 | 뱅크페이. 절차가 번거로운 편입니다 |

## 2. 자동충전 걸어두기

**자동충전 설정**으로 카드를 등록해 두면 포인트가 떨어질 때 자동으로 충전됩니다.

::: tip 자동충전을 권합니다
계약 도중에 포인트가 떨어지면 등기를 못 뗍니다.
급할 때 충전하느라 흐름이 끊기는 것보다 걸어두는 편이 낫습니다.
:::

## 3. 무료 쿠폰 받기

**추천하면 등기 열람 쿠폰을 받습니다.**

우측 상단 프로필에서 **추천인 코드**를 확인하고 **추천 문자 보내기**로 보냅니다.
추천인과 피추천인 **양쪽 모두** 무료 열람 쿠폰을 받습니다.

받은 쿠폰은 `마이페이지 → 결제 관리 → 쿠폰`에서 **사용하기**를 누릅니다.

## 4. 대장 일괄열람 한도는 별개입니다

포인트와 헷갈리기 쉬운데 다릅니다.

| | 베이직 | 플러스 |
| --- | --- | --- |
| 공적장부 일괄열람 | **하루 3건** | **하루 10건** |
| 등기사항증명서 | 제한 없음 (포인트 차감) | 제한 없음 |

*(2026.09 기준)* 하나의 주소에 포함된 **모든 대장을 여는 것이 1건**입니다.

::: tip 한도를 넘기면
`마이페이지 → 결제 관리 → 구독`에서 플러스로 바꾸시면 됩니다.
**플러스는 월 2,000원, 6개월 10,000원**입니다. (부가세 별도)
일일 발급 한도를 초과하더라도 **등기는 계속 발급**됩니다.
:::

## 여기서 막히셨다면

::: details 포인트가 있는데 발급이 안 됩니다
공공사이트 장애일 수 있습니다. **재발급**을 눌러 보시고,
그래도 안 되면 **수정 후 재발급**에서 부동산 고유번호를 넣어 보세요.
→ [공적장부 한 번에 떼기](/howto/public-records)
:::

::: details 하루 3회 충전을 다 썼습니다
신용카드 기준 제한입니다. 다음 날 다시 가능하고, 급하면 실시간 계좌이체를 쓰세요.
:::

::: details 환불이 되나요
결제 관리 화면에 **환불하기**가 있습니다.
:::
