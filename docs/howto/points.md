# 등기 열람 포인트 충전하기

> **걸리는 시간** 약 3분 &nbsp;·&nbsp; **미리 준비할 것** 신용카드 또는 계좌

등기사항증명서를 뗄 때 쓰는 포인트를 충전합니다.

## 무엇에 돈이 드나

::: tip 대장은 전부 무료입니다
건축물대장·토지대장·지적도·토지이용계획확인서는 **무료**입니다.
**등기사항증명서만 건당 700원**입니다. *(2026.09 기준)*
:::

| 서류 | 비용 |
| --- | --- |
| 부동산 등기사항증명서 (건물/토지) | **700원** |
| 그 밖의 대장류 전부 | 무료 |

::: warning 발급 실패는 돌려받습니다
**발급 실패 시 차감된 포인트는 즉시 반환**됩니다. 부가세는 본사가 부담합니다.
반환이 안 되어 있으면 `고객센터 → 문의하기`로 알려주세요.
:::

## 1. 잔액 확인하기

`마이페이지 → 결제 관리`로 가서 **충전** 탭을 엽니다.
탭은 왼쪽부터 **구독정보 · 구독 · 충전 · 결제내역 · 쿠폰** 순서입니다.

![충전 화면](/images/points-01.png)

맨 위에 잔액이 **세 칸**으로 나뉘어 있습니다.

| | 무엇인가 |
| --- | --- |
| **전체 충전 잔액** | 아래 둘을 합친 금액. 실제 쓸 수 있는 돈입니다 |
| **유상 충전 잔액** | 카드나 계좌로 직접 넣은 금액 |
| **무상 충전 잔액** | **쿠폰·이벤트로 받은 금액** |

아래 내역은 **충전 내역 / 사용 내역 / 환불 내역** 세 가지로 나뉘어 있고,
조회기간(전체·1개월·3개월·6개월)으로 걸러 볼 수 있습니다.

## 2. 충전하기

오른쪽 **충전하기**를 누릅니다.

![충전 창](/images/points-02.png)

| 넣는 것 | 고를 수 있는 것 |
| --- | --- |
| 충전 금액 | **1만원 / 2만원 / 5만원 / 10만원** |
| 결제 수단 | **신용카드 / 실시간 계좌이체** |

::: warning 카드 결제 한도
화면에 이렇게 적혀 있습니다.

> 카드 결제는 1회 최대 10만원, 하루 최대 3회까지 가능합니다.

하루에 30만원까지입니다. 더 필요하시면 실시간 계좌이체를 쓰세요.
:::

## 3. 자동충전 걸어두기

**자동충전 설정**을 누릅니다. 창에 이렇게 나옵니다.

> 자동충전을 이용하시려면, 먼저 카드 등록이 필요합니다.

**+ 카드 등록**으로 카드를 먼저 넣어야 자동충전을 켤 수 있습니다.

::: tip 자동충전을 권합니다
계약 도중에 포인트가 떨어지면 등기를 못 뗍니다.
급할 때 충전하느라 흐름이 끊기는 것보다 걸어두는 편이 낫습니다.
:::

## 4. 추천하고 무료 쿠폰 받기

**추천하면 등기 열람 쿠폰을 받습니다. 추천한 분과 받은 분 양쪽 다입니다.**

화면 **오른쪽 위 사람 아이콘**을 누르면 메뉴가 열리고, 그 안에 **추천인 코드**가 있습니다.
누르면 공유 창이 뜹니다.

![내 추천인 코드](/images/points-03.png)

| 여기서 할 수 있는 것 | |
| --- | --- |
| 코드 복사 | 코드 옆 복사 아이콘 |
| 문자로 보내기 | **수신인 추가 +** 로 번호를 넣고 **추천 문자 보내기**. **최대 10명**까지 |
| 문구만 복사 | **클립보드에 복사** — 카톡에 붙여넣기 좋습니다 |

오른쪽에 **실제로 가는 문자 미리보기**가 나옵니다. 그대로 나갑니다.

::: warning 가입할 때 코드를 넣어야 합니다
링크만 보내면 쿠폰이 안 나옵니다.
상대가 **회원가입 화면에서 추천인 코드를 직접 입력**해야 양쪽 다 지급됩니다.
:::

받은 쿠폰은 `마이페이지 → 결제 관리 → 쿠폰`에서 **사용하기**를 누릅니다.
누르면 **700원이 무상 충전 잔액으로 즉시 들어옵니다.**
쿠폰 목록은 **전체 / 미사용 / 사용**으로 걸러 볼 수 있습니다.

## 5. 대장 일괄열람 한도는 별개입니다

포인트와 헷갈리기 쉬운데 다릅니다.

| | 베이직 | 플러스 |
| --- | --- | --- |
| 공적장부 일괄열람 | **하루 3건** | **하루 10건** |
| 등기사항증명서 | 제한 없음 (포인트 차감) | 제한 없음 |

*(2026.09 기준)*

::: tip 1건이 어디까지인가
구독정보 화면에 이렇게 적혀 있습니다.

> 1단위 요청 기준 (여러 장부 선택 후 발급요청 클릭 시, 1회로 차감)

즉 **한 주소에서 여러 장부를 골라 한 번에 요청하면 1건**입니다.
나눠서 여러 번 누르면 그만큼 차감됩니다. **한 번에 다 고르고 한 번만 누르세요.**

발급한 장부는 **3년간 보관**되고 언제든 다시 내려받을 수 있습니다.
:::

::: tip 한도를 넘기면
`마이페이지 → 결제 관리 → 구독`에서 플러스로 바꾸시면 됩니다.
**플러스는 월 2,000원, 6개월 10,000원**입니다. (부가세 별도)
일일 발급 한도를 초과하더라도 **등기는 계속 발급**됩니다.

구독을 중지해도 **기본 기능은 계속 쓸 수 있습니다.**
:::

## 여기서 막히셨다면

::: details 포인트가 있는데 발급이 안 됩니다
공공사이트 장애일 수 있습니다. **재발급**을 눌러 보시고,
그래도 안 되면 **수정 후 재발급**에서 부동산 고유번호를 넣어 보세요.
→ [공적장부 한 번에 떼기](/howto/public-records)
:::

::: details 하루 3회 충전을 다 썼습니다
신용카드 기준 제한입니다. 다음 날 다시 가능하고, 급하면 실시간 계좌이체를 쓰세요.
:::

::: details 쿠폰을 받았는데 잔액이 그대로입니다
쿠폰은 받아두는 것만으로는 쓸 수 없습니다.
`마이페이지 → 결제 관리 → 쿠폰`에서 **사용하기**를 눌러야 잔액에 들어옵니다.
:::

::: details 환불이 되나요
충전 탭의 **환불 내역**에서 확인하실 수 있습니다.
:::
