# 아파트 매매계약서 쓰기

> **걸리는 시간** 약 10분 &nbsp;·&nbsp; **미리 준비할 것** 접수한 매물, 매도인·매수인 인적사항, 거래금액과 지급일정, 발급받은 등기부등본

아파트 매매계약서를 처음부터 끝까지 작성해서 출력하는 방법입니다.

**확인설명서는 이 화면 안에서 계약서와 함께 작성합니다.** 따로 만드는 서류가 아닙니다.
이 문서는 계약서 부분까지 다룹니다. 이어지는 확인설명서 작성법은 준비 중입니다.

## 시작하기 전에

계약서를 쓰기 전에 **매물이 먼저 등록되어 있어야** 합니다.
매물에 입력해 둔 주소·면적·동호수가 계약서로 그대로 넘어오기 때문에,
여기서 정확히 넣어두면 계약서에서 다시 칠 일이 없습니다.

화면 위쪽에는 이런 안내가 붙어 있습니다. 한 번 읽어 두세요.

> 계약서 작성을 돕기 위한 수단으로써 부동산 계약서 작성 및 확인의무는
> 공인중개사법 및 시행령 시행규칙에 따라 공인중개사에게 있음을 알려드립니다.

## 들어가는 길이 세 가지입니다

| 어떤 경우 | 어디서 | 무엇이 자동으로 들어오나 |
| --- | --- | --- |
| **기본** — 접수한 매물이 있을 때 | `매물 → 매물 관리` 에서 매물을 열고 **계약서 작성** | 물건 정보 + 고객 정보 + 대장 정보 |
| **바로가기** — 매물은 없고 주소만 알 때 | `계약 → 계약 생성` 에서 **불러오기** | 대장 정보 |
| **응용** — 백지에서 직접 쓸 때 | `계약 → 계약 생성` 에서 **"거래대상물을 직접 입력하겠습니다"** 체크 | 없음 |

가능하면 **기본**으로 쓰세요. 다시 입력할 일이 가장 적습니다.

## 1. 계약 유형 고르기

<!-- 스크린샷: docs/public/images/contract-apartment-01.png 로 저장하고 아래 주석을 푸세요 -->
<!-- ![계약 유형 선택](/images/contract-apartment-01.png) -->

거래 유형에서 **매매/권리금**을 고르고, 계약서 유형에서 **부동산 매매 계약서**를 고른 뒤 **다음**을 누릅니다.

거래 유형에 따라 고를 수 있는 계약서가 달라집니다.

| 거래 유형 | 계약서 유형 |
| --- | --- |
| 매매/권리금 | 부동산 매매 계약서 · 분양권 매매 계약서 · 입주권 매매 계약서 · 권리금 계약서 |
| 전세 | 부동산 전세 계약서 · 표준 임대차 계약서(전세) |
| 월세 | 부동산 월세 계약서(주거용) · 부동산 월세 계약서(비주거용) · 표준 임대차 계약서 |

전세와 월세에는 **전대차 계약** 체크가 따로 있습니다.

## 2. 본계약으로 바꾸기

<!-- ![본계약 토글](/images/contract-apartment-02.png) -->

계약서 화면은 **[가계약]** 이 먼저 선택된 상태로 열립니다.
본계약을 쓰실 거라면 **[본계약]** 으로 바꿔 주세요.

위쪽에 있는 버튼들입니다.

| 버튼 | 무엇을 하나 |
| --- | --- |
| **가계약 관리** | 가계약 문자를 만들고 보냅니다 |
| **토지거래허가구역 부동산 매매 약정서** | 허가구역일 때 쓰는 약정서를 엽니다 |
| **AI 권리분석** | 권리관계를 분석합니다. 공적장부를 먼저 떼야 제대로 나옵니다 |
| **안내문자** | 계약금·중도금·잔금·중개보수 단계별 문자를 만듭니다 |
| **미리보기 및 인쇄** / **저장** | 마지막 저장 일시가 옆에 표시됩니다 |

## 3. 부동산 표시 확인하기

<!-- ![부동산 표시](/images/contract-apartment-03.png) -->

소재지·지목·면적·대지권종류·대지권비율·구조·용도가 대장에서 자동으로 들어옵니다.
거래면적은 계산되어 표시됩니다.

::: warning 토지가 여러 필지라면
**부속필지 편집**을 눌러 확인하세요.
집합건물 대지권의 목적인 토지가 여러 필지인 경우 부속필지의 권리상태를 반드시 보셔야 합니다.
:::

## 4. 거래금액과 지급일정 입력하기

<!-- ![금액 입력](/images/contract-apartment-04.png) -->

매매대금을 넣고 계약금·중도금·잔금과 각 지급일을 입력합니다.
**만단위 적용**을 체크하면 만원 단위로 넣을 수 있고, 한글 표기가 자동으로 붙습니다.

칸이 더 필요하면 **계약금 추가 · 중도금 추가 · 잔금 추가**를 누릅니다.

::: tip 승계·인수가 있을 때
**권리 인수 추가**를 누르면 인수 항목을 고를 수 있습니다.

> 임대차 보증금 · 근저당 채권최고액 · 전세금 · 대출금 · 미납금

각각 **중도금 승계/인수** 또는 **잔금 승계/인수** 중 언제 처리할지와 날짜를 함께 정합니다.
:::

## 5. 특약사항 넣기

<!-- ![특약 입력](/images/contract-apartment-05.png) -->

특약사항 칸 왼쪽에 버튼이 두 개 있습니다.

**자주 쓰는 특약**에는 기본 118건이 들어 있습니다.
특약구분(부동산 매매 기본 특약 · 주거용 매매 특약 · 정비사업 매매 특약 · 전세,월세 기본 특약 ·
상가 임대차 기본 특약 · 비주거용 매매 특약)으로 걸러서 고르고 **적용**을 누르면 됩니다.

자주 쓰시는 문구는 **특약 추가**로 등록해 두시면 다음 계약서에서 바로 불러 쓰실 수 있습니다.
등록해 둔 특약은 `마이페이지 → 템플릿 관리 → 자주 쓰는 특약 관리`에서 모아 보고 고치실 수 있습니다.

::: tip AI로 특약 초안 받기
**AI특약**을 누르면 먼저 질문이 나옵니다.
주거용인지 비주거용인지, 근저당 같은 권리 제한이 있는지, 공동담보인지, 계약금을 나누는지,
전세/월세 임차인이 있는지, 전입신고는 어떻게 할지, 토지거래허가 대상인지, 주택임대사업자인지.

예/아니오로 답하고 **분석하기**를 누르면 특약 초안이 나오고 **적용**으로 넣을 수 있습니다.
공적장부를 떼어 두셨다면 그 내용을 기준으로 선택지가 미리 골라져 있습니다.

**초안은 초안입니다.** 그대로 쓰지 마시고 반드시 읽고 고치세요.
특약은 분쟁이 났을 때 책임 소재를 가르는 문장입니다.
만들어 준 결과는 `AI → AI 히스토리`에서 `특약` 태그로 다시 찾아보실 수 있습니다.
:::

## 6. 매도인·매수인 입력하기

<!-- ![당사자 입력](/images/contract-apartment-06.png) -->

각 당사자마다 넣는 방법이 세 가지입니다.

| 버튼 | 언제 쓰나 |
| --- | --- |
| **고객 목록에서 추가** | 이미 등록된 고객일 때. 가장 좋습니다 |
| **새로 추가하기 +** | 처음 만난 고객일 때. 고객으로도 함께 등록됩니다 |
| **임시추가(고객관리불가)** | 이 계약에만 쓰고 말 때 |

::: warning 임시추가는 연결되지 않습니다
임시추가로 넣은 정보는 **본 계약에만 저장되고 다른 부분과 연동되지 않습니다.**
상담일지·일정·만기 관리로 이어지지 않으니, 앞으로도 볼 고객이면 **새로 추가하기**를 쓰세요.
:::

공동명의면 같은 버튼을 다시 눌러 인원수만큼 늘립니다.
**신분증 진위여부 확인**도 이 화면에서 하실 수 있습니다.

공동중개일 때는 개업공인중개사 줄에서 **중개사무소 목록에서 추가**를 누릅니다.
소속 공인중개사는 **수정**을 눌러 재직 중인 직원 목록에서 고르시면 됩니다.

## 7. 확인하고 출력하기

<!-- ![출력](/images/contract-apartment-07.png) -->

**미리보기 및 인쇄**로 전체를 한 번 확인한 뒤 출력합니다.
PDF로 저장하시려면 인쇄 대화상자에서 대상을 **PDF로 저장**으로 바꾸시면 됩니다.

다 쓰셨으면 **저장**을 누르세요.

## 여기서 막히셨다면

::: details 매물을 불러왔는데 주소가 비어 있습니다
매물 등록 화면에서 주소가 **지번주소로 확정되지 않은 상태**일 수 있습니다.
매물 화면으로 돌아가 주소 검색을 다시 하고 저장한 뒤, 계약서에서 **다시 불러오기**를 누르세요.
:::

::: details 출력하면 글자가 칸 밖으로 밀려 나옵니다
특약사항이 길면 한 장에 다 들어가지 않습니다.
미리보기에서 확인하시고, 내용을 줄이거나 별지로 나누어 출력하세요.
:::

::: details 작성하던 계약서를 다시 찾지 못하겠습니다
**계약 → 계약 관리**에 저장됩니다.
생성일자·소재지·계약 당사자로 검색하시면 되고, 계약단계(가계약·본계약)로도 거를 수 있습니다.
:::

::: details 주민등록번호가 아닌 번호를 넣어야 합니다
주민등록번호 칸의 **자유입력**을 쓰시면 됩니다.
다만 **임시 제공 기능**이라 다른 조작으로 값이 바뀔 수 있으니 저장 전후로 꼭 다시 확인하세요.
:::

::: details 공동중개 상대 부동산과 같이 쓰고 싶습니다
상단의 **계약 공유 생성**으로 링크를 만들어 보내시면 됩니다.
상대가 부동산이지 회원이면 함께 편집할 수 있고, 비회원이면 조회와 인쇄만 됩니다.
**거래당사자 인적사항과 부속필지는 링크를 만든 분만** 고칠 수 있습니다.
:::
