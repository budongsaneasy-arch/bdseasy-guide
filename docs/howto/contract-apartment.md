# 아파트 매매계약서 쓰기

> **걸리는 시간** 약 10분 &nbsp;·&nbsp; **미리 준비할 것** 매물 주소, 매도인·매수인 인적사항, 거래금액과 지급일정, 등기부등본

아파트 매매계약서를 처음부터 끝까지 작성해서 출력하는 방법입니다.

**확인설명서는 이 화면 안에서 계약서와 함께 작성합니다.** 따로 만드는 서류가 아닙니다.
이 문서는 계약서 부분까지 다루고, 이어지는 확인설명서 부분은 [확인설명서 작성하기](/howto/confirmation-form)에서 계속됩니다.

## 시작하기 전에

계약서를 쓰기 전에 **매물이 먼저 등록되어 있어야** 합니다.
매물에 입력해 둔 주소·면적·동호수가 계약서로 그대로 넘어오기 때문에,
여기서 정확히 넣어두면 계약서에서 다시 칠 일이 없습니다.

## 1. 계약서 작성 화면 열기

<!-- 스크린샷: docs/public/images/contract-apartment-01.png 로 저장하고 아래 주석을 푸세요 -->
<!-- ![계약서 작성 화면 열기](/images/contract-apartment-01.png) -->

상단 메뉴에서 **계약 → 계약 생성**을 누릅니다.
계약 종류를 고르는 화면이 나오면 **매매**를 선택합니다.

## 2. 매물 불러오기

<!-- ![매물 불러오기](/images/contract-apartment-02.png) -->

**매물 불러오기**를 눌러 등록해 둔 매물을 선택합니다.
주소·면적·동호수가 자동으로 채워집니다.

::: warning 같은 단지 다른 호수를 연달아 작업하실 때
앞서 작업하던 계약서를 닫지 않고 새 매물을 불러오면
이전 호수의 정보가 남아 있는 경우가 있습니다.
**새 계약서를 시작할 때는 기존 창을 먼저 닫아 주세요.**
:::

## 3. 매도인·매수인 입력하기

<!-- ![당사자 입력](/images/contract-apartment-03.png) -->

성명·주민등록번호·주소·연락처를 입력합니다.
이미 등록된 고객이라면 **고객 불러오기**로 한 번에 채울 수 있습니다.

공동명의인 경우 **당사자 추가**를 눌러 인원수만큼 늘립니다.
지분 비율을 적는 칸이 함께 나타납니다.

## 4. 거래금액과 지급일정 입력하기

<!-- ![금액 입력](/images/contract-apartment-04.png) -->

매매대금을 넣으면 계약금·중도금·잔금 칸이 나타납니다.
각 금액과 지급일을 입력합니다.

금액은 숫자만 넣으시면 한글 표기가 자동으로 붙습니다.

## 5. 특약사항 넣기

<!-- ![특약 입력](/images/contract-apartment-05.png) -->

**특약사항** 칸에 직접 쓰시거나, **자주 쓰는 특약**에서 골라 넣습니다.
자주 쓰시는 문구는 **특약 저장**을 눌러 등록해 두면 다음 계약서에서 바로 불러올 수 있습니다.

::: tip AI로 특약 초안 받기
이 화면에서 **AI 특약 작성**을 쓰실 수 있습니다. 거래 조건을 넣으면 특약 문구 초안이 나옵니다.

**초안은 초안입니다.** 그대로 쓰지 마시고 반드시 읽고 고치세요. 특약은 분쟁이 났을 때 책임 소재를 가르는 문장입니다.
AI가 만들어 준 결과는 나중에 `AI → AI 히스토리`에서 다시 찾아보실 수 있습니다.
:::

## 6. 확인하고 출력하기

<!-- ![출력](/images/contract-apartment-06.png) -->

**미리보기**로 전체를 한 번 확인한 뒤 **출력**을 누릅니다.
PDF로 저장하시려면 인쇄 대화상자에서 대상을 **PDF로 저장**으로 바꾸시면 됩니다.

## 여기서 막히셨다면

::: details 매물을 불러왔는데 주소가 비어 있습니다
매물 등록 화면에서 주소가 **도로명주소로 확정되지 않은 상태**일 수 있습니다.
매물 화면으로 돌아가 주소 검색을 다시 하고 저장한 뒤, 계약서에서 다시 불러오세요.
:::

::: details 출력하면 글자가 칸 밖으로 밀려 나옵니다
특약사항이 길면 한 장에 다 들어가지 않습니다.
미리보기에서 확인하시고, 내용을 줄이거나 **별지 특약**으로 나누어 출력하세요.
:::

::: details 작성하던 계약서를 다시 찾지 못하겠습니다
**계약 → 계약 관리**에 저장됩니다.
작성일 또는 매물 주소로 검색하시면 됩니다.
출력하지 않고 닫은 계약서도 임시저장 상태로 남아 있습니다.
:::
