# 입주권 매매계약서 쓰기

> **걸리는 시간** 약 20분 &nbsp;·&nbsp; **미리 준비할 것** 종전자산 감정평가액, 이주비 대출 내역, 근저당 실채무액, 분양계약서(있다면)

재개발·재건축 **조합원 입주권**을 사고파는 계약서입니다.

`계약 → 계약 생성`에서 거래 유형 **매매/권리금** → 계약서 유형 **입주권 매매 계약서**를 고릅니다.

::: danger 가장 먼저 정비사업 단계를 고르세요
계약서 상단에 **정비사업단계** 선택이 있습니다. 여기서 무엇을 고르느냐에 따라
**입력 항목 자체가 달라집니다.** 잘못 고르면 처음부터 다시 써야 합니다.

> ① 이주 전 &nbsp;&nbsp; ② 이주완료, 분양계약 전 &nbsp;&nbsp; ③ 분양계약 완료
:::

## 단계별로 무엇이 다른가

| 단계 | 종전자산평가등에 넣는 것 | 정산지불금 계산 |
| --- | --- | --- |
| **① 이주 전** | 감정가 · 보증금/월세 · 근저당 채권최고액 · **근저당 실채무액** | 보증금 + 실채무액 |
| **② 이주완료, 분양계약 전** | 감정가 · **이주비 등 대출합계** | 총매매금액 − 이주비등대출합계 |
| **③ 분양계약 완료** | 위 ② + **분양계약 내용 전체** | 위 ② 와 같고 분양 항목이 추가 |

공통으로 들어가는 것은 이렇습니다.

- **프리미엄** — 마이너스 프리미엄도 넣을 수 있습니다
- **총 매매 금액** = 감정가 + 프리미엄
- **정산지불금** → 이것이 계약서의 매매대금이 됩니다

## 1. 이주 전일 때

부동산 표시에 **종전 부동산**을 적습니다. 소재지 / 토지면적·지목·대지권비율 / 건물면적·용도.

::: warning 건물이 이미 헐렸다면
**건물이 멸실된 경우에도 종전 토지 및 건물 면적을 기재**합니다.
지금 없어졌다고 비워두면 안 됩니다.
:::

**근저당 실채무액**을 꼭 넣으세요. 채권최고액이 아니라 **실제 남은 빚**입니다.
정산지불금 계산에 쓰이는 값이라, 이것이 틀리면 금액이 전부 어긋납니다.

::: tip 정산지불금과 잔금의 관계
정산지불금은 **중도금으로 상환하거나, 잔금보다 많아야** 합니다.
잔금보다 적으면 잔금일에 정산이 안 됩니다.
:::

## 2. 이주완료, 분양계약 전일 때

이주가 끝났으면 **이주비 등 대출합계**를 넣습니다. 세 종류입니다.

| 종류 | 성격 |
| --- | --- |
| 무이자 이주비 대출 | 이주비는 **매수자가 입주 시 반환** |
| 유이자 이주비 대출 | 이주비는 매수자가 입주 시 반환하며 **이자는 매매잔금일 기준 정산** |
| 이사비 대출 | |

이때 **정산지불금 = 총매매금액 − 이주비등대출합계** 입니다.

## 3. 분양계약 완료일 때

분양까지 끝났으면 계약서 제목이 **조합원 입주권 매매 계약서 [재개발]** 로 바뀌고,
**재개발 / 재건축** 선택이 추가로 나타납니다.

부동산 표시가 **2단 구성**이 됩니다.

- **분양 부동산** — 소재지 / 분양면적·전용면적·TYPE / 대지권의 목적인 토지의 표시면적·대지권비율
- **종전 부동산** — 소재지 / 토지면적·지목·대지권비율 / 건물면적·용도

그리고 **분양계약 내용**이 들어옵니다.

- 조합원 분양가
- **(예상)비례율 %**
- 추가부담금
- **권리가액** (직접 입력할 수 있습니다)
- 분양계약금(비율 %) / 중도금 대출금액(비율 %, 대출 회차) / 중도금 자납금액(자납 회차) / 잔여 금액

::: danger 인쇄물이 두 장입니다
**분양계약 완료를 고르면 "입주권 계약서"와 "토지계약서" 총 2장이 인쇄됩니다.**
둘 다 출력해서 교부해야 합니다.
:::

## 4. 조문이 11조까지 있습니다

일반 매매(9조)보다 깁니다. 정비사업 전용 조항이 앞에 붙기 때문입니다.

- 조합원 지위 승계 및 소유권 이전 등기 서류 일체 교부
- 이주비·이사비 및 조합원 지위 승계, 등기절차 협력
- **잔금일 기준 조합원 지위·권리의무 자동 승계, 추가부담금**
- **조합원 지위 미승계 시 계약 무효**
- 제한물권 소멸 / 지방세 / 해제 / 손해배상 / 중개보수 / 중개보수 외
- **제11조 중개대상물 확인설명서 및 정비사업구역 안 설명고지 확인서 작성·교부**

::: danger 정비사업구역 안 설명고지 확인서
일반 매매에 없는 서류입니다. 확인설명서와 **함께** 작성해서 교부해야 합니다.
:::

## 여기서 막히셨다면

::: details 채권최고액과 실채무액 중 무엇을 넣나요
**둘 다 넣습니다.** 다만 정산지불금 계산에 쓰이는 것은 **실채무액**입니다.
은행에서 받은 부채증명서로 확인하세요.
:::

::: details 단계를 잘못 골랐습니다
입력 항목이 통째로 바뀌므로, `계약 → 계약 관리`에서 그 계약을 지우고 새로 만드시는 편이 빠릅니다.
:::

::: details 비례율을 모르겠습니다
조합에서 고시한 (예상)비례율을 확인해야 합니다.
확정 전이면 예상치임을 **특약사항**에 명시해 두세요.
:::

::: details 특약은 어느 구분인가요
**정비사업 매매 특약**을 고르세요.
:::
