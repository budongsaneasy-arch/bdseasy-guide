# 네이버에 매물 광고하기

> **걸리는 시간** 처음 한 번은 하루 이틀, 그다음부터 매물당 약 10분
> **미리 준비할 것** 접수한 매물, 최근 90일 이내 발급한 등기부등본, 매물 사진

접수한 매물을 네이버 부동산에 올리는 방법입니다.

::: warning 먼저 알아두실 것
네이버 부동산에는 **중개사가 직접 올릴 수 없습니다.** 반드시 CP사를 거쳐야 하고,
부동산이지는 **렛츠**와 연결되어 있습니다.

그래서 이 일은 **부동산이지와 렛츠를 오가며** 진행됩니다.
어디까지가 어느 쪽 일인지는 [네이버 부동산 CP 연동이란](/concept/naver-cp)에 정리해 두었습니다.
:::

## 전체 흐름

한 건을 올리기까지 열두 단계쯤 됩니다. 그중 **다섯 단계가 부동산이지**, 나머지는 렛츠입니다.

| 순서 | 무엇을 | 어디서 |
| --- | --- | --- |
| 1 | 렛츠 이용 신청 | **부동산이지** |
| 2 | 멤버십 결제 (99,000원 / 6개월) | 렛츠 |
| 3 | 충전금 결제 | 렛츠 |
| 4 | 광고 접수 (매물 전송 폼 작성) | **부동산이지** |
| 5 | 광고 정보 확인 · 사진/등기부 자동 첨부 | 렛츠 |
| 6 | 소유자 정보 확인 · 광고 결제 | 렛츠 |
| 7 | 매물 전송 | **부동산이지** |
| 8 | 확인매물 관리 | 렛츠 |
| 9 | 광고 상태 · 노출 순위 확인 | **부동산이지** |

*(2026.09 기준)*

**1·2·3번은 사무소당 한 번만** 하면 됩니다. 매물마다 반복하는 것은 4번부터입니다.

## 메뉴 이름이 세 가지로 나옵니다

같은 기능인데 화면마다 이름이 다릅니다. 헷갈리지 마세요.

| 어디서 보이나 | 이름 |
| --- | --- |
| 상단 메뉴 | `매물 → N 광고 관리` |
| 그 화면 제목 | **네이버 광고(RETS)** |
| 매물 관리 목록의 버튼 | **광고하기** |
| 원장 상세의 버튼 | **네이버 부동산 광고** |

`RETS`는 렛츠를 뜻합니다. 전부 같은 곳으로 갑니다.

## 1. 렛츠 이용 신청하기 (처음 한 번만)

![렛츠 이용 신청](/images/naver-ad-02.png)

상단 메뉴에서 **매물 → N 광고 관리**를 누릅니다.

아직 신청 전이라면 **렛츠 이용 신청** 화면이 나옵니다.
사무실명·대표자·개설등록번호·사업자등록번호·주소·전화번호가 **이미 채워져 있습니다.**
`마이페이지 → 설정`의 중개사무소 정보에서 자동으로 가져온 것입니다.

업태와 업종만 채우고 **신청**을 누르면 됩니다.

::: tip 먼저 사무소 정보부터 맞춰두세요
여기 채워지는 값이 틀리면 렛츠 가입이 반려됩니다.
`마이페이지 → 설정 → 중개사무소 정보`를 먼저 확인하세요.
:::

신청 후 처리에는 시간이 걸립니다. 승인되면 렛츠에서 연락이 옵니다.

## 2. 멤버십과 충전금 결제하기 (렛츠에서)

승인이 나면 **렛츠 사이트에서 직접** 두 가지를 결제합니다.

| 무엇 | 얼마 | 성격 |
| --- | --- | --- |
| 멤버십 | **99,000원 / 6개월** | 렛츠를 쓰기 위한 기본료 |
| 충전금 | 쓰는 만큼 | 광고 한 건마다 차감되는 광고비 |

*(2026.09 기준)* 렛츠 멤버십은 CP사 중에서는 저렴한 편입니다.

::: warning 이 단계 문의는 렛츠로 하세요
결제·승인·환불은 렛츠 담당입니다. **렛츠 고객센터 02-430-4909**
부동산이지 고객센터에서는 처리할 수 없습니다.
:::

## 3. 광고할 매물 고르기

![매물 관리에서 광고하기](/images/naver-ad-01.png)

상단 메뉴 **매물 → 매물 관리**에서 광고할 매물을 찾아 **광고하기**를 누릅니다.

목록에서 **광고여부** 필터로 전체 / 광고 / 미광고를 걸러 볼 수 있습니다.
아직 광고하지 않은 매물만 보려면 **미광고**를 고르세요.

## 4. 매물 전송 폼 채우기

![매물 전송 폼](/images/naver-ad-03.png)

**매물 전송** 화면이 열립니다. 접수해 둔 내용이 대부분 채워져 있습니다.

**광고사**를 먼저 고릅니다. **렛츠**와 **이지(BETA)** 중 하나 이상을 골라야 합니다.

::: warning 매물종류가 접수할 때와 다릅니다
매물 접수 화면의 물건유형은 17종이지만, **네이버 광고용 매물종류는 21종**으로 따로 있습니다.

> 아파트 · 아파트분양권 · 재건축 · 오피스텔 · 오피스텔분양권 · 단독/다가구 · 전원주택 ·
> 상가주택 · 한옥주택 · 원룸 · 빌라/연립 · 사무실 · 상가점포 · 지식산업센터 ·
> 빌딩/건물 · 숙박/콘도 · 건물-기타 · 상가건물 · 공장/창고 · 토지 · 재개발

여기서 고른 것이 네이버에 표시되는 분류입니다.
:::

**층**에는 **직접노출 / 고·중·저** 선택이 있습니다. 이 선택이 나중에 노출 순위에 영향을 줍니다.
아래 [노출 순위 확인하기](#_6-노출-순위-확인하기)에서 다시 설명합니다.

## 5. 거래정보와 상세정보 채우기

![거래정보와 상세정보](/images/naver-ad-04.png)

아래로 내려가며 나머지를 채웁니다.

- **거래정보** — 거래유형 · 금액 · 융자여부 · 입주가능일 · 건축물일자
- **관리비 상세입력** — 부과방식과 세부내역. **세분화해서 넣어야 합니다**
- **시설정보** — 냉방·생활·보안·기타 시설 체크
- **상세정보** — 매물특징(40자) · 매물 설명(1,000자)

::: danger 위반건축물은 반드시 적으셔야 합니다
**위반건축물은 매물설명란에 반드시 기재**해야 합니다. 2025년 1월 1일부터 시행되었습니다.

건축물대장을 떼면 **(위반)** 배지가 자동으로 붙고,
건축물대장 변동내용에서 **위반항목만 복사**로 뽑아 붙이실 수 있습니다.
→ [공적장부 한 번에 떼기](/howto/public-records)
:::

::: tip 설명글이 막히면 AI를 쓰세요
원장 상세의 **AI광고설명** 버튼을 누르면 매물특징(광고제목)과 매물설명 초안이 나옵니다.
잘 되고 있는 광고를 참고해서 고쳐 쓰시면 더 좋습니다.
:::

다 채우면 **저장하기**를 누릅니다.

## 6. 렛츠에서 확인하고 결제하기

여기서부터는 **렛츠 화면**입니다. 여섯 단계로 진행됩니다.

> 매물정보입력 → 결제 → 정보확인 → 등본확인 → 등록 → 종료

**광고 상품을 고르는 단계가 가장 중요합니다.** 어떤 검증방식을 고르느냐에 따라 **노출 순위가 달라집니다.**

| 매물검증방식 | 대략 가격 | 노출 순위 |
| --- | --- | --- |
| 현장확인2 | 50,500원 | 최상위 |
| 현장확인 | 21,100원 | 1위 |
| 모바일확인 v1·v2 | 1,530원 | 2~3위 |
| 신용보호확인서 | 1,530원 | 3위 |
| 홍보확인서확인 | 2,030원 | 5·7위 |
| 전화확인 | 1,990원 | 6위 |

*(2026.09 기준. 정확한 금액은 렛츠 전송가격표를 보세요)*

### 등기부등본이 자동으로 붙습니다

부동산이지에서 등기를 떼어 두셨다면 **자동으로 첨부**되고,
소유자명과 발급일자가 검증되어 표시됩니다.

::: warning 90일이 지나면 못 씁니다
**최근 90일 이내에 발급(열람)한 등본만** 쓸 수 있습니다.
오래됐으면 [공적장부 한 번에 떼기](/howto/public-records)로 다시 떼세요.
:::

사진도 등록해 두신 것이 자동으로 붙습니다. 최대 20장, 각 10MB까지입니다.

## 7. 매물 전송하기

렛츠에서 결제까지 끝나면 부동산이지로 돌아와 **전송하기**를 누릅니다.

정보가 맞지 않으면 네이버 전송 실패 알림이 옵니다. 그때는 어긋난 항목을 고치고 다시 보내시면 됩니다.

## 8. 광고 상태와 노출 순위 확인하기

`매물 → 매물 관리`에서 광고 중인 매물의 **네이버(R)** 버튼을 누르면 광고 정보 창이 뜹니다.

여기서 보는 것들입니다.

| 항목 | 무엇인가 |
| --- | --- |
| 광고관리 | 렛츠로 이동 |
| 광고중인 페이지 URL | PC·모바일 주소. 복사해서 고객에게 보낼 수 있습니다 |
| 상태 / 등록일 | 광고중인지 종료인지 |
| **매물전체순위** | 그 단지·지역에서 몇 번째로 보이는지. **20번째 안에 들면 숫자가 나옵니다** |
| **동일매물순위 / 동일매물수** | 같은 매물로 묶였을 때 그 묶음 안에서 몇 번째인지 |
| 순위갱신 | 지금 순위를 다시 확인 |

### 알림 두 가지는 꼭 보세요

| 알림 | 무슨 뜻인가 | 무엇을 해야 하나 |
| --- | --- | --- |
| **[가격]** | 나보다 더 싼 가격으로 광고하는 매물이 있다 | 중개의뢰인께 확인하고 광고 가격을 조정 |
| **[층]** | 나는 저/중/고로 올렸는데 다른 곳은 층을 노출해서 위에 있다 | 층 노출로 광고를 수정 |

이 두 알림이 곧 **"왜 내 매물이 밀렸나"의 답**입니다.

## 여기서 막히셨다면

::: details 렛츠 가입이 승인되지 않습니다
사무소 정보가 실제 등록 내용과 다르면 반려됩니다.
`마이페이지 → 설정 → 중개사무소 정보`에서 개설등록번호·사업자등록번호·주소를 다시 확인하세요.

그래도 안 되면 **렛츠 고객센터 02-430-4909**로 문의하셔야 합니다.
:::

::: details 고쳤는데 네이버에 그대로입니다
렛츠를 거쳐 네이버로 넘어가는 데 시간이 걸립니다. 대부분 반영 대기 상태입니다.

다만 **매물종류와 면적은 전송 후에는 수정할 수 없고**,
가격은 최초등록가의 **±20% 이내**로만 고칠 수 있습니다.
:::

::: details 등기부등본이 첨부되지 않습니다
90일이 지난 등본은 쓸 수 없습니다. 다시 떼시면 자동으로 붙습니다.
:::

::: details 순위가 자꾸 밀립니다
노출 순서는 **네이버가 정합니다.** 부동산이지나 렛츠가 정하지 않습니다.

영향을 주는 것은 검증방식(광고 상품), 가격, 층 노출 여부, 정보의 충실도, 사진 수입니다.
광고 정보 창의 **[가격]·[층] 알림**부터 확인해 보세요.
:::

::: details N 광고 관리와 매물 관리가 뭐가 다른가요
- **매물 관리** — 내가 접수한 **모든 매물**
- **N 광고 관리** — 그중 **네이버에 광고 중인 매물만**

같은 매물이 양쪽에 다 보이는 것이 정상입니다.
:::
