# 네이버에 매물 광고하기

> **걸리는 시간** 처음 한 번은 하루 이틀, 그다음부터 매물당 약 10분
> **미리 준비할 것** 접수한 매물, 최근 120일 이내 발급한 등기부등본, 매물 사진

접수한 매물을 네이버 부동산에 올리는 방법입니다.

::: warning 먼저 알아두실 것
네이버 부동산에는 **중개사가 직접 올릴 수 없습니다.** 반드시 CP사를 거쳐야 하고,
부동산이지는 **렛츠**와 연결되어 있습니다.

그래서 이 일은 **부동산이지와 렛츠를 오가며** 진행됩니다.
어디까지가 어느 쪽 일인지는 [네이버 부동산 CP 연동이란](/concept/naver-cp)에 정리해 두었습니다.
:::

## 전체 흐름

한 건을 올리기까지 열두 단계쯤 됩니다. 그중 **다섯 단계가 부동산이지**, 나머지는 렛츠입니다.

| 순서 | 무엇을 | 어디서 |
| --- | --- | --- |
| 1 | 렛츠 이용 신청 | **부동산이지** |
| 2 | 멤버십 결제 (99,000원 / 6개월) | 렛츠 |
| 3 | 충전금 결제 | 렛츠 |
| 4 | 광고 접수 (매물 전송 폼 작성) | **부동산이지** |
| 5 | 광고 정보 확인 · 사진/등기부 자동 첨부 | 렛츠 |
| 6 | 소유자 정보 확인 · 광고 결제 | 렛츠 |
| 7 | 매물 전송 | **부동산이지** |
| 8 | 확인매물 관리 | 렛츠 |
| 9 | 광고 상태 · 노출 순위 확인 | **부동산이지** |

*(2026.09 기준)*

**1·2·3번은 사무소당 한 번만** 하면 됩니다. 매물마다 반복하는 것은 4번부터입니다.

## 메뉴 이름이 세 가지로 나옵니다

같은 기능인데 화면마다 이름이 다릅니다. 헷갈리지 마세요.

| 어디서 보이나 | 이름 |
| --- | --- |
| 상단 메뉴 | `매물 → N 광고 관리` |
| 그 화면 제목 | **네이버 광고(RETS)** |
| 매물 관리 목록의 버튼 | **광고하기** |
| 원장 상세의 버튼 | **네이버 부동산 광고** |

`RETS`는 렛츠를 뜻합니다. 전부 같은 곳으로 갑니다.

## 1. 렛츠 가입하기 (처음 한 번만)

상단 메뉴에서 **매물 → N 광고 관리**를 누릅니다.

![렛츠 이용 신청](/images/naver-ad-02.png)

::: tip 누르기만 하면 가입됩니다
**N 광고 관리를 누르면 렛츠 가입이 자동으로 진행됩니다.**
사무실명·대표자·개설등록번호·사업자등록번호·주소·전화번호는
`마이페이지 → 설정`의 중개사무소 정보에서 자동으로 넘어갑니다.

**조금 기다리셔야 합니다.** 바로 끝나지 않습니다.
:::

::: tip 먼저 사무소 정보부터 맞춰두세요
여기 넘어가는 값이 틀리면 렛츠 가입이 반려됩니다.
`마이페이지 → 설정 → 중개사무소 정보`를 먼저 확인하세요.
:::

::: warning 중개사무소는 중복 가입이 안 됩니다
한 사무소는 렛츠에 **한 번만** 가입됩니다.
사업자등록번호가 기준이라, 이미 렛츠를 쓰고 계셨다면 여기서 막힙니다.
→ 아래 [이미 렛츠를 쓰고 계셨다면](#이미-렛츠를-쓰고-계셨다면)
:::

### 이미 렛츠를 쓰고 계셨다면

부동산이지를 거치지 않고 **렛츠를 직접 쓰고 계셨던 분**은
가입 과정에서 이런 메시지를 보시게 됩니다.

> 이미 존재하는 사업자번호입니다.

그 사업자번호로 **렛츠에 가입된 이력이 있다는 뜻**입니다. 자동으로 연결되지는 않습니다.
`고객센터 → 문의하기`에 이렇게 남겨 주세요.

> **[제목]** 기존 렛츠 회원의 계정 연동 신청

통상 **1~2 영업일 이내**에 처리됩니다.
기존 렛츠 계정은 **그대로 유지**되고, 부동산이지 로그인용 계정이 **추가로** 생성됩니다.

::: danger 신청 전에 한 번 생각해 보세요 — 멤버십이 이중으로 나갈 수 있습니다
계정이 두 개가 되므로, **이미 렛츠 멤버십을 결제해 쓰고 계신 경우**
멤버십이 중복 결제되거나 계정 관리가 번거로워질 수 있습니다.

**렛츠를 직접 쓸지, 부동산이지를 통해 쓸지 먼저 정하신 뒤** 연동을 신청하세요.
판단이 어려우시면 문의하기에 **현재 멤버십 상태를 함께 적어** 물어보시면 됩니다.
:::

## 2. 멤버십과 충전금 결제하기 (렛츠에서)

::: danger 여기가 가장 많이 막히는 지점입니다
**렛츠에 가입만 해서는 광고가 나가지 않습니다.**
렛츠에서 **두 가지를 결제**해야 비로소 부동산이지에서 네이버 광고를 보낼 수 있습니다.

1. **멤버십** — 렛츠를 쓸 자격
2. **충전금** — 광고 한 건마다 빠져나갈 돈

둘 중 하나만 해도 광고가 안 됩니다. 순서대로 둘 다 하세요.
:::

렛츠는 `매물 → N 광고 관리` 화면 오른쪽 위 버튼으로 들어갑니다.

![N 광고 관리 상단](/images/naver-ad-05.png)

| 버튼 | 언제 누르나 |
| --- | --- |
| **렛츠 멤버십 가입** | 아직 멤버십을 결제하지 않았을 때 |
| **렛츠 로그인** | 렛츠 화면을 열고 싶을 때 |
| **네이버 광고(RETS)** | 광고 접수 화면으로 |

### 멤버십 — 99,000원 / 6개월

렛츠에서 `광고상품안내`를 열면 상품이 하나뿐입니다.

![렛츠 광고상품안내](/images/lets-01.png)

> 렛츠알리고 멤버십 (회원제) — 회원비(6개월) **99,000원**
> 서비스내용: 충전금으로 네이버부동산 매물전송

결제한 내역은 `계정관리 → 기간제상품 관리`에서 볼 수 있습니다.
**6개월마다 재계약**이고, 만료되어도 **이미 등록된 매물은 노출 종료일까지 유지**됩니다.

![렛츠 계정관리](/images/lets-02.png)

### 충전금 — 광고 한 건마다 빠져나갑니다

`계정관리 → 충전금 관리 → 충전하기`입니다.

![렛츠 충전금 결제](/images/lets-03.png)

충전 단위는 **1만 / 3만 / 5만 / 10만 / 15만 / 20만 / 30만 / 50만원**이고,
결제는 **간편카드결제 · 신용카드 · 무통장입금(가상계좌) · 실시간계좌이체** 중에 고릅니다.

::: tip 충전금은 만기가 없습니다
화면에 이렇게 적혀 있습니다.

> 충전금은 별도의 만기일이 존재하지 않습니다.

한 번 넣어두면 없어지지 않으니 조금 넉넉히 넣어두셔도 됩니다.
:::

::: warning 법인은 계좌이체가 안 됩니다
> 법인계좌에서는 계좌이체 서비스를 이용하실 수 없습니다.(신용카드는 사용가능 합니다.)

법인 사무소는 **신용카드**로 결제하세요.
:::

### 전송 단가 — 검증방식에 따라 크게 다릅니다

충전금에서 **매물 한 건을 보낼 때마다** 아래 금액이 빠집니다.

| 검증방식 | 전송가격(부가세 포함) | 알아두실 것 |
| --- | ---: | --- |
| 현장확인2 | **50,500원** | 사업자등록번호당 **100건까지 12,000원**으로 할인. 100건은 모든 CP사 합산 |
| 일반현장확인 | **21,100원** | 부산·인천·대구·대전·경북 경산·경기 양주·경남 양산·세종은 **4,600원**<br>서울·경기의 빌라/연립·단독/다가구는 **10,100원** |
| 원룸현장확인 | **2,900원** | 월 100건 넘으면 21,100원 적용 |
| 신홍보확인서 | **1,530원** | |
| 모바일확인 · 모바일확인2(집주인확인) | **1,530원** | |
| 홍보확인서 | **2,030원** | |

*(2026.09 기준. 정확한 금액은 렛츠 충전 화면에서 확인하세요)*

화면 아래에 이런 단서가 붙어 있습니다.

> 충전금 전송 단가는 네이버 정책 및 매물의 조건에 따라 추가로 조정(무료, 하향 혹은 상향)될 수 있음

::: warning 이 단계 문의는 렛츠로 하세요
결제·승인·환불은 렛츠 담당입니다. **렛츠 고객센터 02-430-4909** (평일 09~18시, 점심 12:30~13:30)
부동산이지 고객센터에서는 처리할 수 없습니다.
:::

## 3. 광고할 매물 고르기

![매물 관리에서 광고하기](/images/naver-ad-01.png)

상단 메뉴 **매물 → 매물 관리**에서 광고할 매물을 찾아 **광고하기**를 누릅니다.

목록에서 **광고여부** 필터로 전체 / 광고 / 미광고를 걸러 볼 수 있습니다.
아직 광고하지 않은 매물만 보려면 **미광고**를 고르세요.

## 4. 매물 전송 폼 채우기

![매물 전송 폼](/images/naver-ad-03.png)

**매물 전송** 화면이 열립니다. 접수해 둔 내용이 대부분 채워져 있습니다.

**광고사**를 먼저 고릅니다. **렛츠**와 **이지(BETA)** 중 하나 이상을 골라야 합니다.

::: warning 매물종류가 접수할 때와 다릅니다
매물 접수 화면의 물건유형은 17종이지만, **네이버 광고용 매물종류는 21종**으로 따로 있습니다.

> 아파트 · 아파트분양권 · 재건축 · 오피스텔 · 오피스텔분양권 · 단독/다가구 · 전원주택 ·
> 상가주택 · 한옥주택 · 원룸 · 빌라/연립 · 사무실 · 상가점포 · 지식산업센터 ·
> 빌딩/건물 · 숙박/콘도 · 건물-기타 · 상가건물 · 공장/창고 · 토지 · 재개발

여기서 고른 것이 네이버에 표시되는 분류입니다.
:::

**층**에는 **직접노출 / 고·중·저** 선택이 있습니다. 이 선택이 나중에 노출 순위에 영향을 줍니다.
아래 [노출 순위 확인하기](#_6-노출-순위-확인하기)에서 다시 설명합니다.

::: danger 층을 저·중·고로 내보내시려면 렛츠에서 한 번 더 확인하세요
여기서 **고·중·저**를 고르셔도 **렛츠 화면에는 「동의(층노출)」로 넘어갑니다.**
그대로 두면 네이버에 **실제 층수가 그대로 노출됩니다.**

렛츠 매물수정 화면의 **층** 항목에서 **비동의(고/중/저)** 로 직접 바꿔 주세요.
그래야 네이버에 「저층」으로 나갑니다. *(2026.09 확인)*

의뢰인이 상세주소 노출을 원하지 않으시는 경우, 이 한 번의 확인이
표시·광고 위반 여부를 가릅니다. → [매물 접수하기](/howto/property-register)의 상세주소 표시
:::

## 5. 거래정보와 상세정보 채우기

![거래정보와 상세정보](/images/naver-ad-04.png)

아래로 내려가며 나머지를 채웁니다.

- **거래정보** — 거래유형 · 금액 · 융자여부 · 입주가능일 · 건축물일자
- **관리비 상세입력** — 부과방식과 세부내역. **세분화해서 넣어야 합니다**
- **시설정보** — 냉방·생활·보안·기타 시설 체크
- **상세정보** — 매물특징(40자) · 매물 설명(1,000자)

::: danger 관리비 금액은 「원」 단위로 넣으세요 — 만원으로 넣으면 25원이 됩니다
이 화면의 **관리비금액 칸에는 단위 표시가 없습니다.** 바로 위 매매금에는 「만원」이 붙어 있어
같은 만원 단위로 착각하기 쉽습니다.

**25만원짜리 관리비를 `25`로 넣으면 네이버에 「관리비 25원」으로 노출됩니다.**
반드시 **`250000`** 처럼 원 단위로 넣으세요. *(2026.09 실제 확인)*

![관리비금액 칸에는 단위 표시가 없습니다](/images/naver-ad-07.png)

| 넣는 값 | 네이버 표시 |
| --- | --- |
| `25` | 관리비 **25원** ← 잘못 |
| `250000` | 관리비 **25만원** ← 맞음 |

관리비는 표시·광고 명시사항입니다. 틀리면 과태료 대상이 될 수 있으니
**광고가 나간 뒤 네이버에서 실제 표시를 꼭 확인하세요.**

렛츠 화면에서는 「25,0000 원」처럼 **만 단위로 콤마**가 찍힙니다. 이 표기가 곧 250,000원입니다.
:::

::: danger 위반건축물은 반드시 적으셔야 합니다
**위반건축물은 매물설명란에 반드시 기재**해야 합니다. 2025년 1월 1일부터 시행되었습니다.

건축물대장을 떼면 **(위반)** 배지가 자동으로 붙고,
건축물대장 변동내용에서 **위반항목만 복사**로 뽑아 붙이실 수 있습니다.
→ [공적장부 한 번에 떼기](/howto/public-records)
:::

::: tip 설명글이 막히면 AI를 쓰세요
원장 상세의 **AI광고설명** 버튼을 누르면 매물특징(광고제목)과 매물설명 초안이 나옵니다.
잘 되고 있는 광고를 참고해서 고쳐 쓰시면 더 좋습니다.
:::

다 채우면 **저장하기**를 누릅니다.

## 6. 렛츠에서 확인하고 결제하기

부동산이지에서 **저장하기**를 누르면 **렛츠 매물관리센터가 새 창으로 자동으로 열립니다.**
여기서부터는 **렛츠 화면**이고, 여섯 단계로 진행됩니다.

> 매물정보입력 → 결제 → 정보확인 → 등본확인 → 등록 → 종료

::: tip 실제로는 몇 분이면 끝납니다
연습으로 한 건을 올려보니 결제부터 등록까지 **1분**이 걸렸습니다.

> 매물정보입력 13:38 → 결제 13:53 → 정보확인 13:53 → 등본확인 13:54 → **등록 13:54**

등본확인이 자동으로 통과하기 때문입니다. 등기를 미리 떼어 두신 효과입니다.
:::

### 결제 전에 채워야 하는 것

렛츠 결제 화면에서 **의뢰인 정보**를 넣어야 합니다. 신홍보확인서는
**등기부상 소유자 실명과 네이버 회원정보로 검증**하는 방식이라 여기가 정확해야 합니다.

| 항목 | 넣는 것 |
| --- | --- |
| 매물 소유자 구분 | 소유자와 의뢰인이 같으면 **개인매물** |
| 매도/임대 의뢰인명 | **등기부상 소유자 이름** |
| 의뢰인 연락처 | **그 소유자 본인 명의 휴대폰** |

::: danger 이름이나 번호가 틀리면 검증 실패하고 환급되지 않습니다
렛츠 안내 그대로입니다.

> 1차 검증 실패 시, 최초 수동검증요청 이후 **2 영업일 이내**에 재검증 요청하지 않으면
> 매물 등록이 취소되고 **검증비가 환급되지 않습니다.**

주소의 면적을 잘못 기재한 경우에는 **재검증 기회조차 없습니다.**
:::

마지막으로 **신홍보확인서 이용 동의서**에 체크해야 결제 버튼이 동작합니다.

> 개인정보 수집 및 이용, 부동산렛츠 및 네이버파이낸셜, 한국부동산원, 한국인터넷자율정책기구로의
> 개인정보 제공에 대하여 **소유주가 모두 동의하였습니다.**

**공동명의 매물이면 공동소유자 전원의 동의**를 뜻합니다. 미리 받아두세요.

**광고 상품을 고르는 단계가 가장 중요합니다.** 어떤 검증방식을 고르느냐에 따라 **노출 순위가 달라집니다.**

| 매물검증방식 | 대략 가격 | 노출 순위 |
| --- | --- | --- |
| 현장확인2 | 50,500원 | 최상위 |
| 현장확인 | 21,100원 | 1위 |
| 모바일확인 v1·v2 | 1,530원 | 2~3위 |
| 신용보호확인서 | 1,530원 | 3위 |
| 홍보확인서확인 | 2,030원 | 5·7위 |
| 전화확인 | 1,990원 | 6위 |

*(2026.09 기준. 정확한 금액은 렛츠 전송가격표를 보세요)*

### 등기부등본과 사진은 자동으로 붙습니다

이 단계에서 **따로 올리실 것이 없습니다.** 부동산이지에 이미 있는 것이 그대로 넘어갑니다.

| 무엇이 | 어디에 있던 것이 | 조건 |
| --- | --- | --- |
| **등기부등본** | 부동산이지에서 **열람·발급해 둔 등기** | 최근 **120일 이내** 발급(열람)분 |
| **사진** | **매물 접수 때 등록해 둔 사진** | 최대 **20장**, 각 **10MB**까지 |

등기는 **소유자명과 발급일자가 검증되어** 표시됩니다. 렛츠 화면에 이렇게 나옵니다.

> ▶▶▶ 첨부된 등기부등본 분석결과입니다.
> **분석결과** — 자동검증 가능한 등본입니다
> **소유자** — 일치 (○○○)
> **발급일자** — 유효 (2026-09-18 발급, 발급 2일차)

::: danger 매물과 무관한 사진은 올려도 네이버에 나오지 않습니다
렛츠 화면에 이렇게 적혀 있고, **실제로 그렇습니다.**

> 등록하신 사진은 네이버부동산 검수 절차를 거쳐 노출되며,
> **매물과 관련없는 이미지나 홍보성 이미지는 검수과정에서 삭제될 수 있습니다.**

사무소 홍보 이미지나 로고를 대표사진으로 넣으면 **렛츠에는 올라가지만 네이버에서는 빠집니다.**
사진이 하나도 안 보이는 광고가 되니, **반드시 그 매물을 찍은 사진**만 올리세요.
*(2026.09 실제 확인)*
:::

::: warning 120일이 지나면 못 씁니다
**최근 120일 이내에 발급(열람)한 등본만** 쓸 수 있습니다.
오래됐으면 [공적장부 한 번에 떼기](/howto/public-records)로 다시 떼세요.
:::

::: tip 그래서 접수 단계가 중요합니다
광고를 내기 직전에 서류를 떼고 사진을 올리려면 급해집니다.
**매물을 접수하실 때** 공부를 떼고 사진을 분류해 두시면 이 단계는 확인만 하고 넘어갑니다.

→ [공적장부 한 번에 떼기](/howto/public-records)
→ [매물 접수하기](/howto/property-register)
:::

## 7. 매물 전송하기

렛츠에서 결제까지 끝나면 부동산이지로 돌아와 **전송하기**를 누릅니다.

정보가 맞지 않으면 네이버 전송 실패 알림이 옵니다. 그때는 어긋난 항목을 고치고 다시 보내시면 됩니다.

## 8. 광고 상태와 노출 순위 확인하기

`매물 → N 광고 관리`를 열면 **광고 중인 매물이 표로 한눈에** 나옵니다.
매물을 하나씩 눌러볼 필요가 없습니다.

![N 광고 관리 순위표](/images/naver-ad-06.png)

맨 위에 상태별 건수가 나옵니다 — **전체 / 대기중 / 검증중 / 광고중 / 검증실패 / 종료**.

| 열 | 무엇인가 |
| --- | --- |
| 렛츠광고 관리 | **이동** — 그 매물의 렛츠 화면으로 |
| 광고중인 페이지 URL | **PC · 모바일** 아이콘. 실제 네이버 광고 페이지로 바로 갑니다 |
| 상태 / 검증타입 | 광고중인지, 어떤 검증방식으로 올렸는지 |
| 등록일 / 노출기간 | 언제부터 언제까지 |
| **매물전체순위** | 네이버에서 **전체 매물 중** 내 순위 |
| **동일매물순위 / 동일매물수** | **같은 매물로 묶인 것 중** 내 순위와 전체 개수 |
| **알림** | 순위가 밀린 이유 |
| 순위갱신 | 지금 순위를 다시 확인. 마지막 갱신 시각이 함께 표시됩니다 |

### 순위는 별 색으로 구분합니다

화면 설명 그대로입니다.

| 표시 | 뜻 |
| --- | --- |
| 별 + 숫자 | 그 순위. **1~3 / 4~6 / 7~9 / 10~20** 구간마다 별 색이 다릅니다 |
| **⚠ 순위 밖** | 매물전체순위가 **20위 밖**이라는 뜻입니다 |

동일매물순위는 `3 / 38` 처럼 나옵니다. **같은 매물을 38곳이 광고 중이고 내가 3번째**라는 뜻입니다.

::: tip 순위가 안 보이면
**상태가 `광고중`으로 갱신된 뒤에야** 순위 갱신 기능을 쓸 수 있습니다.
화면 설명에 이렇게 적혀 있습니다.

> 상태정보가 갱신되어 광고중 상태인 경우, 순위 갱신 기능을 사용할 수 있습니다.
:::

### 알림 세 가지가 "왜 밀렸나"의 답입니다

알림은 **내 광고보다 위에 있는 매물이 무엇을 더 했는지** 알려줍니다.

| 알림 | 무슨 뜻인가 | 무엇을 해야 하나 |
| --- | --- | --- |
| **층** | 층을 노출한 매물이 있다 (내 광고는 층 미노출) | 의뢰인께 확인하고 **층 노출**로 수정 |
| **가격** | 더 낮은 금액의 매물이 있다 | 의뢰인께 확인하고 **광고 가격 조정** |
| **검증** | **더 높은 검증 방식**의 매물이 있다 | 검증방식을 올릴지 판단 (비용이 올라갑니다) |

한 매물에 `가격` `검증` 처럼 두 개가 같이 뜨기도 합니다.

::: warning 알림은 순위 갱신할 때 같이 갱신됩니다
> *순위 갱신시 함께 갱신 됩니다.

방금 가격을 내렸다면 **순위갱신**을 눌러야 알림이 사라집니다.
:::

## 9. 이지허브에도 같이 광고하기

네이버 광고와 별개로, 부동산이지가 운영하는 **이지허브**에도 매물을 올릴 수 있습니다.

`매물 → 이지 광고 관리`입니다. *(2026.09 기준 BETA)*

> **이지허브는 따로 정리해 두었습니다.** 내 사무소 홈페이지 주소, 손님이 넣는 매물접수·중개의뢰,
> 들어온 의뢰를 받는 곳까지 한 번에 보시려면 → [이지허브에 매물 올리고 의뢰 받기](/howto/ez-hub)

![이지 광고 관리](/images/ez-ad-01.png)

| 네이버 광고와 다른 점 | |
| --- | --- |
| **비용** | 렛츠 멤버십·충전금이 필요 없습니다 |
| **검증방식·순위·알림** | 없습니다. 네이버가 아니므로 순위 경쟁이 없습니다 |
| **노출기간** | 사실상 **무기한**입니다 (종료일이 2099년으로 잡힙니다) |

![이지 광고 목록](/images/ez-ad-02.png)

화면 위쪽에 **홈페이지 / My홈페이지** 버튼이 있습니다.
플러스 요금제에 포함된 **중개사무소 홈페이지**로, 여기 올린 매물이 그 홈페이지에 나옵니다.

**광고 공유**로 고른 매물들을 묶어 링크로 보낼 수도 있습니다.

::: tip 올린 광고를 고칠 때도 같은 자리입니다
이지허브 광고의 내용을 바꾸시려면 **`매물 → 이지 광고 관리`에서 그 광고를 선택**해 수정하시면 됩니다.
매물 관리에서 매물을 고쳐도 이미 나간 광고에는 반영되지 않습니다.

네이버 광고처럼 매물종류·면적이 잠기는 제한은 없습니다.
:::

::: tip 고객이 이지허브로 의뢰를 넣으면
이지허브에서 들어온 의뢰는 `고객 → 허브 의뢰 관리`에서 받습니다.
내가 등록한 의뢰(`의뢰 접수`·`의뢰 관리`)와 다른 곳이니 헷갈리지 마세요.
:::

## 10. 거래가 끝나면 광고를 종료하세요

**계약이 성사되면 광고를 즉시 내려야 합니다.** 팔린 매물이 계속 걸려 있으면
표시·광고 위반이 됩니다.

부동산이지도 계약 화면에서 이렇게 알려줍니다.

> 종료하지 않은 매물광고가 ○건 있습니다! 거래하신 후 광고는 즉시 '노출종료' 해 주세요.

| 어디서 | 무엇을 |
| --- | --- |
| `매물 → N 광고 관리` | 그 매물 줄의 **종료하기** |
| `매물 → 이지 광고 관리` | 이지허브에 올렸다면 **여기도 따로 종료** |

![N 광고 관리의 종료하기](/images/naver-ad-08.png)

![이지 광고 관리의 종료하기](/images/ez-ad-03.png)

::: warning 두 곳을 따로 종료해야 합니다
광고사를 **렛츠와 이지 둘 다** 선택해서 보내셨다면 **광고도 두 곳에 올라가 있습니다.**
한쪽만 종료하면 다른 쪽은 계속 노출됩니다.

특히 이지허브는 **노출기간이 2099년까지**로 잡히기 때문에 저절로 내려가지 않습니다.
:::

::: tip 종료하면 렛츠에도 바로 반영됩니다
부동산이지에서 종료하면 렛츠 등록리스트에서 빠지고 **등록종료**로 넘어갑니다.
따로 렛츠에 들어가실 필요가 없습니다.

다만 **이미 결제한 검증비는 환급되지 않습니다.**
:::

## 여기서 막히셨다면

::: details 렛츠로 넘어가려는데 연결이 끊겨 있습니다
가끔 부동산이지에서 렛츠로 들어가려 할 때 연결이 풀려 있는 경우가 있습니다.

`매물 → N 광고 관리` 오른쪽 위의 **렛츠 로그인** 버튼을 누르면 **바로 다시 연결**됩니다.
따로 아이디·비밀번호를 넣지 않아도 됩니다.
:::

::: details 렛츠에 가입했는데 광고가 안 나갑니다
**멤버십과 충전금을 둘 다 결제하셨는지** 확인하세요.
가입만으로는 광고가 나가지 않습니다. → [2단계](#_2-멤버십과-충전금-결제하기-렛츠에서)
:::


::: details 렛츠 가입이 승인되지 않습니다
사무소 정보가 실제 등록 내용과 다르면 반려됩니다.
`마이페이지 → 설정 → 중개사무소 정보`에서 개설등록번호·사업자등록번호·주소를 다시 확인하세요.

그래도 안 되면 **렛츠 고객센터 02-430-4909**로 문의하셔야 합니다.
:::

::: details 고쳤는데 네이버에 그대로입니다
렛츠를 거쳐 네이버로 넘어가는 데 시간이 걸립니다. 대부분 반영 대기 상태입니다.

다만 **매물종류와 면적은 전송 후에는 수정할 수 없고**,
가격은 최초등록가의 **±20% 이내**로만 고칠 수 있습니다.
:::

::: details 등기부등본이 첨부되지 않습니다
120일이 지난 등본은 쓸 수 없습니다. 다시 떼시면 자동으로 붙습니다.
:::

::: details 순위가 자꾸 밀립니다
노출 순서는 **네이버가 정합니다.** 부동산이지나 렛츠가 정하지 않습니다.

영향을 주는 것은 검증방식(광고 상품), 가격, 층 노출 여부, 정보의 충실도, 사진 수입니다.
광고 정보 창의 **[가격]·[층] 알림**부터 확인해 보세요.
:::

::: details N 광고 관리와 매물 관리가 뭐가 다른가요
- **매물 관리** — 내가 접수한 **모든 매물**
- **N 광고 관리** — 그중 **네이버에 광고 중인 매물만**

같은 매물이 양쪽에 다 보이는 것이 정상입니다.
:::
