# 네이버 매물 보고 바로 접수하기

> **걸리는 시간** 단지 하나 훑는 데 약 3분 &nbsp;·&nbsp; **미리 준비할 것** 없음
>
> 네이버 부동산에 올라온 매물을 **부동산이지 안에서** 보고, 그 자리에서 내 매물로 접수합니다.

## 왜 여기서 보나

네이버 부동산에서 직접 보려면 불편한 점이 있습니다.

- 지도 기반이라 **원하는 단지만 골라 보기가 번거롭습니다**
- 같은 매물이 여러 중개사무소에 걸쳐 **자동으로 묶여** 있습니다
- 검색 조건이 제한적이고, 결국 **스크롤을 반복**하게 됩니다

부동산이지는 같은 정보를 **표로** 보여줍니다. 그리고 표에서 바로 접수할 수 있습니다.

## 1. 단지 찾기

![N 매물 모니터링 진입](/images/n-monitoring-01.png)

상단 메뉴에서 **매물 → N 매물 모니터링**을 누릅니다.

찾는 방법이 두 가지입니다.

| 무엇을 찾나 | 어떻게 |
| --- | --- |
| **아파트 · 오피스텔** | 위쪽 **통합검색**에 단지명을 칩니다 |
| **그 밖의 부동산** | 아래 **주소검색**에서 시/도 → 시/군/구 → 읍/면/동을 고릅니다 |

주소검색을 쓸 때는 **N 메뉴 선택**에서 종류를 고릅니다.

::: tip N 메뉴 선택이 17가지로 늘었습니다
**2026.10부터** 묶음 세 개가 아니라 **네이버 분류 그대로 17가지**입니다.

> 아파트 · 재건축 · 오피스텔 · 아파트분양권 · 오피스텔분양권 · 재개발 · 원룸 · 빌라 ·
> 단독/다가구 · 전원주택 · 상가주택 · 상가 · 토지 · 사무실 · 건물 · 공장/창고 · 지식산업센터

**여러 개를 한꺼번에 고를 수 있습니다.** 고른 것은 칸 안에 꼬리표로 붙고, 옆의 **×**로 하나씩 뺍니다.
:::

찾은 뒤에는 **거래 유형(매매 · 전세 · 월세 · 단기)**, 면적, 층, 금액, 월세로 더 좁힐 수 있습니다.
거래 유형 단추에는 **그 유형의 건수**가 함께 찍혀 있습니다.

<!-- 확인 필요: N 메뉴 선택 옆의 「타입 선택」이 무엇을 고르는 칸인지 개발팀 확인 후 보완 -->

::: warning 조건을 바꾸면 네이버에서 다시 찾아옵니다
**2026.10부터** 거래 유형이나 N 메뉴 선택을 바꾸면 **그때마다 새로 조회**합니다.
전에는 이미 불러온 목록 안에서만 걸러 냈습니다.

그래서 **안 보이던 매물이 나타날 수 있고**, 잠깐 기다리셔야 할 때도 있습니다.
:::

## 2. 매물 목록 보기

![단지의 네이버 매물](/images/n-monitoring-02.png)

단지를 고르면 그 단지에 올라온 네이버 매물이 전부 나옵니다.
위쪽에 **매매 / 전세 / 월세 / 단기 건수**와 **전체 건수**가 함께 표시됩니다.

::: tip 건수가 「지금 보이는 것」이 아니라 「전부」입니다
**2026.10부터** 이 숫자는 화면에 불러온 것만 센 것이 아니라 **그 단지의 전체**입니다.
더보기를 누르지 않아도 몇 건인지 알 수 있습니다.

**거래 유형**이나 **N 메뉴 선택**을 바꾸면 그때마다 **네이버에서 다시 찾아옵니다.**
전에는 이미 불러온 목록 안에서만 걸러 냈습니다. 지금은 고른 조건으로 새로 조회하므로
**안 보이던 매물이 나타날 수 있습니다.** 잠깐 기다리셔야 할 때도 있습니다.
:::

::: tip 원장에서 바로 들어갈 수도 있습니다
`부동산 원장 → 부동산 원장 관리`에서 단지를 열면 탭이 세 개 있습니다.
**단지 보기 · N 매물 모니터링 · 국토부 실거래가**

가운데 탭이 지금 이 화면입니다. 단지를 보다가 바로 넘어갈 수 있습니다.
일반 부동산은 원장 상세 우측 상단의 **N매물** 버튼으로 들어갑니다.
:::

## 3. 표에서 무엇을 읽나

![매물 목록](/images/n-monitoring-03.png)

한 줄에 이만큼이 들어 있습니다.

| 항목 | 무엇을 보나 |
| --- | --- |
| 거래유형 / 가격 | 매매·전세·월세와 금액 |
| 동 · 층/총층수 · 방향 | 어느 동 몇 층인지 |
| 면적 | 공급/전용 |
| 등록일 | 언제 올라온 매물인지 |
| **집주인** | 집주인이 직접 올린 매물인지 |
| **중개업소명** | 어느 사무소가 광고하고 있는지 |
| **동일매물** | 같은 매물을 **몇 곳이 함께** 광고하는지 |
| 매물접수 / 보러가기 | 내 매물로 접수 / 네이버 원본 페이지로 이동 |

::: tip 동일매물 숫자를 보세요
**8곳 · 15곳**처럼 나옵니다. 숫자가 클수록 여러 사무소가 같은 물건을 잡고 있다는 뜻입니다.
숫자가 **1곳**이면 그 사무소만 가진 물건일 가능성이 높습니다.
:::

목록은 우측 상단 아이콘으로 **엑셀로 내려받을** 수 있습니다.

## 4. 그 자리에서 접수하기

**매물접수**를 누르면 접수 화면으로 넘어갑니다.

::: tip 아파트는 호실을 추정해 줍니다
네이버 광고에는 호수가 없습니다. 그런데 표시·광고에 의무적으로 들어가는 정보
(면적 · 총 층수 · 방수 · 승인일자 · 방향 등)를 대장과 맞춰보면 **호실을 좁힐 수 있습니다.**

아파트·오피스텔은 접수 팝업의 **접수 물건** 목록에 **추정 호실 후보가 자동으로 제시**됩니다.
고르기만 하면 됩니다.
:::

일반 건축물은 후보가 안 나올 수 있습니다. 그때는 `부동산 원장 관리` 우측 상단의
**물건 찾기**에서 **사용승인일 · 총층수 · 면적**으로 직접 좁혀 찾으시면 됩니다.

접수한 뒤 단계는 [매물 접수하기](/howto/property-register)와 같습니다.

::: tip 사진도 같이 넘어옵니다
여기서 접수하면 네이버에 올라 있던 **사진도 함께 저장**되어,
따로 찍지 않아도 바로 광고를 낼 수 있습니다.
:::

## 5. 이미 광고 중인 내 매물 가져오기

`N 매물 모니터링` 화면 위쪽에 **내 N 매물 가져오기** 탭이 있습니다.

다른 CP사로 이미 네이버에 광고하고 있는 **내 매물을 부동산이지로 옮겨오는** 기능입니다.

방법이 두 가지입니다.

1. **네이버 중개사 ID**를 넣고 **네이버에서 불러오기**
2. 네이버 부동산에서 **광고 중인 매물 페이지 URL**을 복사해 붙여넣기

::: danger 광고 URL 방식은 지금 쓰지 마세요 — 네이버 중개사 ID를 쓰십시오
네이버 부동산 주소 모양이 바뀌면서 **새 주소를 붙여넣으면 불러오지 못합니다.**
오류가 아니라 아무것도 안 나오는 식이라, 중개사는 **내 매물이 없는 줄 압니다.**
*(2026.10 확인)*

**1번 네이버 중개사 ID 방식을 쓰세요.** 그쪽은 정상입니다.
광고 URL 칸은 앞으로 없어질 예정입니다.
:::

불러온 목록에서 가져올 매물을 체크하고 **내 매물로 등록하기**를 누릅니다.
**사진도 함께 저장** 옵션을 켜두면 사진까지 넘어옵니다.

::: tip 이제 모든 매물종류가 됩니다
전에는 **아파트와 오피스텔만** 가져올 수 있었습니다. **2026.10부터 모든 매물종류**가 됩니다.
빌라·주택·상가·사무실·토지도 그대로 넘어옵니다.

하루에 한 번만 불러올 수 있는 것은 그대로입니다. 목록 위에 **최종 업데이트** 시각이 찍혀 있습니다.
:::

::: warning 가져온 뒤 한 번 확인하세요
**일부 항목이 비어서 넘어올 수 있습니다.**
가져온 뒤 `매물 → 매물 관리`에서 면적·층·방수 같은 것이 제대로 들어왔는지 한 번 보세요.

주소를 못 찾은 매물은 **「부동산 이지와 연결된 소재지가 없습니다」**라고 뜹니다.
그 줄의 **소재지 선택**을 눌러 직접 골라 주셔야 등록됩니다.

*(화면에 붙어 있던 Beta 표시는 2026.10에 떨어졌습니다)*
:::

## 여기서 막히셨다면

::: details 단지를 검색했는데 매물이 0건입니다
그 단지에 지금 네이버 광고가 없을 수 있습니다.
거래 유형 필터가 걸려 있지 않은지, 면적·금액 범위가 좁게 잡혀 있지 않은지 확인해 보세요.
:::

::: details 주소로 검색했는데 아무것도 안 나옵니다
아파트·오피스텔은 **통합검색**, 그 밖의 부동산은 **주소검색**입니다.
주소검색을 쓸 때는 **N 메뉴 선택**에서 종류(빌라·주택 / 원룸·투룸 / 상가·업무·공장·토지)를 반드시 고르세요.
:::

::: details 접수할 때 호실 후보가 안 나옵니다
아파트·오피스텔이 아니면 추정할 데이터가 없습니다.
`부동산 원장 관리`의 **물건 찾기**에서 사용승인일·총층수·면적으로 직접 찾으세요.
:::

::: details 내 N 매물 가져오기에서 "개설등록번호가 일치하지 않습니다"가 뜹니다
입력한 네이버 ID의 개설등록번호가 내 사무소와 다를 때 나옵니다.
내 네이버 중개사 ID가 맞는지 확인하세요.
:::

::: details 광고 URL을 붙여넣었는데 아무것도 안 나옵니다
**네이버 주소 모양이 바뀌어 새 주소로는 불러오지 못합니다.** *(2026.10 확인)*
내 매물이 없는 것이 아니라 **그 방식이 지금 안 되는 것**입니다.

**네이버 중개사 ID**를 넣고 불러오세요.
:::

::: details 가져왔는데 「부동산 이지와 연결된 소재지가 없습니다」가 뜹니다
네이버 주소를 부동산이지 원장에 붙이지 못한 경우입니다.
그 줄의 **소재지 선택**을 눌러 직접 고르시면 등록됩니다.
:::
