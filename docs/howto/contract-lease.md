# 전세·월세 계약서 쓰기

> **걸리는 시간** 약 10분 &nbsp;·&nbsp; **미리 준비할 것** 접수한 매물, 임대인·임차인 인적사항, 보증금과 월세, 발급받은 등기부등본

전세와 월세 계약서를 쓰는 방법입니다.

**기본 흐름은 매매계약서와 같습니다.** 이 문서는 **전세·월세만 다른 부분**을 설명합니다.
계약 생성부터 저장까지의 공통 단계는 [아파트 매매계약서 쓰기](/howto/contract-apartment)를 보세요.

![전세 계약 유형 선택](/images/contract-lease-01.png)

## 계약서가 다섯 가지입니다

`계약 → 계약 생성`에서 거래 유형을 고르면 계약서 유형이 달라집니다.

| 거래 유형 | 계약서 유형 | 언제 쓰나 |
| --- | --- | --- |
| **전세** | 부동산 전세 계약서 | 일반적인 전세 |
| | 표준 임대차 계약서(전세) | 주택임대사업자 물건 등 표준서식이 필요할 때 |
| **월세** | 부동산 월세 계약서(주거용) | 주택 월세 |
| | 부동산 월세 계약서(비주거용) | 상가·사무실 월세 |
| | 표준 임대차 계약서 | 표준서식이 필요할 때 |

::: warning 주택임대사업자 물건은 표준서식입니다
주택임대사업자는 **표준임대차계약서 양식 사용**이 의무입니다.
임대료 증액 제한·임대의무기간 준수 같은 의무도 함께 걸립니다.
매물이 주임사 물건인지 먼저 확인하세요.
:::

## 전대차는 체크로 구분합니다

전세와 월세에는 **전대차 계약** 체크가 따로 있습니다.

임차인이 다시 다른 사람에게 빌려주는 계약이면 여기를 체크합니다.
체크하면 계약서의 당사자 표기가 전대인·전차인으로 바뀝니다.

## 매매와 다른 곳

### 1. 금액 칸이 다릅니다

![전세 계약서 금액](/images/contract-lease-02.png)

매매는 **매매대금** 하나지만, 전세·월세는 이렇게 나뉩니다.

- **전세** — 전세보증금 / 계약금 / 중도금 / 잔금
- **월세** — 보증금 / 월세 / 계약금 / 중도금 / 잔금

월세에는 **차임 지급일(매월 며칠)** 을 함께 정합니다.

### 2. 임대 기간을 정합니다

매매에 없는 항목입니다. **임대차 기간**(시작일 ~ 종료일)을 넣습니다.

::: tip 여기가 만기 관리로 이어집니다
여기 넣은 종료일이 그대로 **임대차 만기**가 됩니다.
2년 뒤 이 물건이 다시 시장에 나올 때 먼저 연락할 수 있습니다.
→ [임대차 만기일 관리하기](/howto/lease-expiry)
:::

### 3. 특약이 다릅니다

**자주 쓰는 특약**에서 고를 때 특약구분을 바꿔 주세요.

- 주거용 전세·월세 → **전세,월세 기본 특약**
- 상가·사무실 → **상가 임대차 기본 특약**

매매용 특약을 그대로 쓰면 맞지 않는 조항이 들어갑니다.

## 여기서 막히셨다면

::: details 전세와 표준 임대차 계약서(전세)는 뭐가 다른가요
내용을 담는 틀이 다릅니다. **표준 임대차 계약서**는 국토교통부 표준서식이고,
주택임대사업자 물건처럼 표준서식이 의무인 경우에 씁니다.

어느 쪽을 써야 할지 애매하면 표준서식이 안전합니다.
:::

::: details 상가 계약인데 주거용을 골랐습니다
상단 **계약 유형**을 다시 골라야 합니다. 이미 내용을 넣으셨다면
`계약 → 계약 관리`에서 그 계약을 지우고 새로 만드시는 편이 빠릅니다.
:::

::: details 월세인데 보증금만 있고 월세가 0원입니다
보증금만 있는 계약이면 **전세**로 쓰시는 것이 맞습니다.
:::
