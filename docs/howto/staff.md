# 직원 등록하고 배분비율 정하기

> **걸리는 시간** 약 10분 &nbsp;·&nbsp; **미리 준비할 것** 직원 인적사항, 사무소 배분 기준

소속공인중개사·중개보조원을 등록하고, 중개보수를 **누가 얼마씩 가져갈지** 미리 정해 둡니다.
여기서 정해 둔 비율이 계약을 정산할 때 **자동으로 따라옵니다.**

## 1. 직원 등록하기

`마이페이지 → 설정`으로 가서 **직원 정보** 탭을 엽니다.

![직원 정보 탭](/images/staff-01.png)

오른쪽 위 **신규 직원 등록**을 누릅니다.

::: tip 직원 수 한도가 화면에 나옵니다
목록 위에 **"최대 재직중인 직원 수 제한: N - 구독관리"** 라고 내 플랜의 한도가 적혀 있습니다.
한도에 걸리면 **구독관리** 링크로 플랜을 올리시면 됩니다.

베이직은 **1인**, 플러스는 **2인**입니다. *(2026.09 기준)*
:::

## 2. 직원 정보 넣기

![신규 직원 등록](/images/staff-02.png)

| 넣는 것 | 설명 |
| --- | --- |
| 아이디 · 비밀번호 | **직원이 로그인할 계정**입니다. 대표가 만들어 직원에게 알려 줍니다 |
| 프로필 사진 | 200px × 200px 권장 |
| 이름 · 주소 · 주민등록번호 · 이메일 | 인적사항 |
| 전화번호1 · 전화번호2 | |
| **직원 유형** | **소속 공인중개사 / 중개보조원** 중 하나 |
| 공인중개사 자격증번호 | 소속공인중개사인 경우 |
| 고용형태 | 정규직 / 계약직 / 프리랜서 |
| 재직상태 | 재직 / 퇴사 |
| 근무 시작일(입사일) | |

::: warning 자격 구분을 정확히 하세요
소속공인중개사와 중개보조원은 할 수 있는 일이 다릅니다.
**중개보조원이 중개행위를 하면 적발 대상**입니다. 등록할 때 구분을 정확히 넣으세요.
:::

::: warning 직원의 주민등록번호를 다루는 화면입니다
체험 계정(`testuser1`~`testuser5`)에서는 **실제 주민등록번호를 넣지 마세요.**
누구나 들어올 수 있는 공용 계정입니다.
:::

등록한 직원은 매물·계약·일정의 **담당자**로 지정할 수 있게 됩니다.

직원의 휴대폰 번호 변경은 **대표 권한**으로만 됩니다.
(`마이페이지 → 설정 → 직원 정보`)

## 3. 배분비율 정하기

`마이페이지 → 배분 비율 관리`로 갑니다.

**업무 분야 추가 +** 를 누르면 표가 하나 생깁니다.

![배분 비율 관리](/images/staff-03.png)

표는 이렇게 생겼습니다.

- **세로(행)** — 정산유형. **매매 · 전세 · 월세 · 기타매출** 네 가지로 **고정**되어 있습니다
- **가로(열)** — 임직원. 등록한 직원이 늘어나면 열이 늘어납니다
- **칸** — 그 사람이 그 유형에서 가져가는 **비율(%)**

맨 위 칸에 **업무 분야 이름**을 넣고, 비율을 채운 뒤 **저장**을 누릅니다.

::: tip 업무 분야는 어떻게 나누나요
매매·전세·월세는 **이미 행으로 들어가 있습니다.** 그러니 업무 분야는 그보다 한 단계 위,
**배분 기준 자체가 다른 묶음**으로 나누시면 됩니다.

예를 들어 `주거용 중개` / `상업용 중개` / `분양 대행`처럼요.
사무소가 하나의 기준으로만 배분한다면 업무 분야는 하나만 만들어도 됩니다.
:::

표를 여러 개 만들 수 있고, 지울 때는 왼쪽 체크박스를 고르고 **선택삭제**를 누릅니다.

## 4. 계약에서 정산하기

계약 상세의 **계약 후 관리** 탭에 정산 항목이 있습니다.

- 현금영수증 및 세금계산서 발행 — 홈택스 바로가기
- **정산관리** — 매출 추가
- 일정관리 — 중도금·잔금 일정

**매출 추가**를 누르고 **담당자 · 업무 분야 · 정산 유형**을 고르면
방금 정해 둔 **배분비율이 자동으로 채워집니다.**

![배분비율 자동 표시](/images/sales-02.png)

자세한 정산 방법은 → [매출 관리하기](/howto/sales)

## 여기서 막히셨다면

::: details 직원을 더 등록할 수 없습니다
플랜 한도에 걸렸습니다. 직원 정보 화면 위에 적힌 **최대 재직중인 직원 수 제한**을 확인하시고,
옆의 **구독관리** 링크로 플랜을 올리세요.
:::

::: details 배분비율 칸에 사람 이름이 하나뿐입니다
아직 직원을 등록하지 않으셨습니다. 대표 한 사람만 열로 나옵니다.
`마이페이지 → 설정 → 직원 정보`에서 직원을 먼저 등록하세요.
:::

::: details 배분비율을 저장했는데 계약에 반영되지 않습니다
이미 만들어 둔 정산 내역에는 자동으로 다시 적용되지 않습니다.
해당 계약의 **계약 후 관리 → 정산관리**에서 매출을 다시 확인하세요.
:::

::: details 퇴사한 직원은 어떻게 하나요
직원 정보에서 그 직원을 열고 **재직상태**를 **퇴사**로 바꿉니다.
목록 위 **재직 상태** 조건으로 재직중인 직원만 골라 볼 수 있습니다.

그 직원이 담당자로 들어간 과거 매물·계약 기록은 그대로 남습니다.
:::

::: details 화면 안내와 메뉴 이름이 다릅니다
계정 정보 탭에 `[대표계정>마이페이지>사무실정보>직원정보]` 라고 적힌 안내가 있습니다.
지금 메뉴에 `사무실정보`는 없습니다. **`마이페이지 → 설정 → 직원 정보`** 가 맞습니다.
:::
