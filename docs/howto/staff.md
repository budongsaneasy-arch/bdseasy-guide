# 직원 등록하고 배분비율 정하기

> **걸리는 시간** 약 10분 &nbsp;·&nbsp; **미리 준비할 것** 직원 인적사항, 사무소 배분 기준

소속공인중개사·중개보조원을 등록하고, 중개보수를 **누가 얼마씩 가져갈지** 미리 정해 둡니다.

## 1. 직원 등록하기

`마이페이지 → 설정`으로 가서 **직원 정보** 탭을 엽니다.

::: warning 자격 구분을 정확히 하세요
소속공인중개사와 중개보조원은 할 수 있는 일이 다릅니다.
**중개보조원이 중개행위를 하면 적발 대상**입니다. 등록할 때 구분을 정확히 넣으세요.
:::

등록한 직원은 매물·계약·일정의 **담당자**로 지정할 수 있게 됩니다.

::: tip 직원 수에 제한이 있습니다
베이직은 **1인**, 플러스는 **2인**입니다. *(2026.09 기준)*
더 필요하시면 `마이페이지 → 결제 관리 → 구독`에서 플랜을 올리세요.
:::

직원의 휴대폰 번호 변경은 **대표 권한**으로만 됩니다.
(`대표계정 > 마이페이지 > 사무실정보 > 직원정보`)

## 2. 배분비율 정하기

`마이페이지 → 배분 비율 관리`로 갑니다.

**업무 분야 추가 +** 로 분야를 먼저 만들고, 그 안에서 비율을 정한 뒤 **저장**합니다.

::: tip 업무 분야부터 만드세요
비율은 업무 분야 안에 들어갑니다. 분야가 하나도 없으면 비율을 넣을 자리가 없습니다.

분야는 사무소 기준으로 나누시면 됩니다. 예를 들어 매매 / 임대차 / 상가처럼
**배분 기준이 다른 단위**로 나누면 쓰기 좋습니다.
:::

여기서 정해 둔 비율이 계약의 **정산**에 쓰입니다.

## 3. 계약에서 정산하기

계약 상세의 **계약 후 관리** 탭에 정산 항목이 있습니다.

- 현금영수증 및 세금계산서 발행
- **정산관리** — 매출 추가
- 일정관리

**매출 추가**를 누르면 그 계약의 중개보수가 매출로 잡히고,
배분비율에 따라 나뉩니다.

## 여기서 막히셨다면

::: details 직원을 더 등록할 수 없습니다
플랜 한도에 걸렸습니다. 베이직 1인 / 플러스 2인입니다.
`마이페이지 → 결제 관리 → 구독`에서 확인하세요.
:::

::: details 배분비율을 저장했는데 계약에 반영되지 않습니다
이미 만들어진 계약에는 자동으로 적용되지 않을 수 있습니다.
해당 계약의 **계약 후 관리 → 정산관리**에서 확인하세요.
:::

::: details 퇴사한 직원은 어떻게 하나요
직원 정보에서 정리하시면 됩니다. 다만 그 직원이 담당자로 들어간
과거 매물·계약 기록은 그대로 남습니다.
:::
