# 고객 등록하고 관리하기

> **걸리는 시간** 한 명에 약 2분 &nbsp;·&nbsp; **미리 준비할 것** 고객 이름과 연락처

고객을 한 곳에 모아두면 상담일지·일정·의뢰·연관부동산·계약이 **그 사람에게 전부 붙습니다.**

왜 한 곳에 모아야 하는지는 [고객을 왜 한 곳에 모으나](/concept/why-one-customer)를 먼저 보세요.

## 1. 고객 관리 열기

![고객 관리](/images/customer-01.png)

상단 메뉴에서 **고객 → 고객 관리**를 누릅니다.

목록 오른쪽에 **상담일지 · 일정 · 의뢰 · 연관부동산 · 계약** 건수가 숫자로 붙어 있습니다.
그 고객에게 무엇이 얼마나 쌓였는지 한눈에 보입니다.

::: warning 한 고객은 한 번만 등록하세요
같은 분을 두 번 등록하면 이 숫자들이 둘로 쪼개집니다.
등록 전에 **고객명이나 연락처로 먼저 검색**해 보세요.
:::

## 2. 고객 추가하기

**고객 추가 +** 를 누르면 유형을 먼저 고릅니다.

| 고객유형 | 언제 |
| --- | --- |
| **개인고객** | 일반적인 매도·매수·임대·임차 고객 |
| **법인고객** | 법인 명의 거래 |
| **중개사무소** | 공동중개 상대 부동산 |

그다음 **고객구분**을 고릅니다.

> 매도 · 임대 · 매수 · 임차 · 기타(관계자)

::: danger 타부동산 여부를 꼭 확인하세요
다른 부동산을 통해 들어온 고객이면 **타부동산 여부**를 체크합니다.
체크된 고객에게 **먼저 연락하면 안 됩니다.**
:::

**블랙 여부**와 **고객등급**, **담당자**도 여기서 지정합니다.

## 3. 법인·중개사무소는 다릅니다

::: warning 법인고객
법인 정보와 **관리자(담당자) 정보를 함께** 넣어야 합니다.
법인등록번호와 사업자등록번호만으로 계약하면 안 됩니다. 실제 서명하는 사람을 확인하세요.
:::

::: warning 중개사무소
개업공인중개사 정보를 검색하면 자동으로 입력됩니다.
**소속공인중개사와 중개보조원도 개업공인중개사 정보에 포함해서** 등록하세요.
무자격자가 중개하는 일이 적발되는 사례가 있습니다.
:::

## 4. 고객은 매물·의뢰에서 만드는 것이 낫습니다

화면 위에 이런 안내가 있습니다.

> 고객의 기본정보를 관리합니다.
> 매도&임대 고객은 **[매물접수]** 를, 매수&임차 고객은 **[의뢰접수]** 를 통해 관리해주세요.

고객 관리에서 직접 추가해도 되지만, **매물이나 의뢰를 만들면서 함께 등록**하면
그 자리에서 연관부동산까지 연결됩니다.

- 매도·임대 고객 → [매물 접수하기](/howto/property-register)의 소유자 등록
- 매수·임차 고객 → `고객 → 의뢰 접수`

::: tip 대장에서 소유자를 바로 가져올 수 있습니다
건축물대장 전유부나 등기를 발급받으면 **소유자 정보가 자동으로 기록**됩니다.
**고객 등록 및 소유자 지정**을 누르면 그대로 고객이 됩니다.
→ [공적장부 한 번에 떼기](/howto/public-records)
:::

## 5. 찾기

고객이 쌓이면 검색으로 찾습니다. 걸 수 있는 조건이 많습니다.

> 고객명 · 연락처 · 고객등급 · 고객 별칭 · 고객 유형 · 고객 구분 · 담당자 ·
> 고객노트 · 중개사무소명 · 개설등록번호 · **타부동산 포함** 체크

## 여기서 막히셨다면

::: details 같은 고객을 두 번 등록했습니다
둘 중 정보가 적은 쪽을 **선택삭제**로 지우고, 필요한 내용을 남은 쪽으로 옮기세요.
계약이 붙어 있는 쪽은 지우지 마세요.
:::

::: details 고객 등급은 무엇에 쓰나요
브론즈부터 시작합니다. 사무소 기준에 맞게 쓰시면 됩니다.
등급으로 목록을 걸러 볼 수 있어서 DM이나 브리핑 대상을 추릴 때 유용합니다.
:::

::: details 계약서에서 임시추가로 넣은 고객이 목록에 없습니다
**임시추가(고객관리불가)** 로 넣은 정보는 그 계약에만 저장되고 고객 관리로 오지 않습니다.
앞으로도 볼 고객이면 **새로 추가하기**로 다시 넣으세요.
:::
