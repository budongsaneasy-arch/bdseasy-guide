# 가계약 문자 보내기

> **걸리는 시간** 약 5분 &nbsp;·&nbsp; **미리 준비할 것** 매물, 거래예정금액, 가계약금, 입금계좌

매도인용·매수인용 가계약 문자를 만들어 보내고, 그 내용을 **본계약까지 그대로 이어 쓰는** 방법입니다.

스마트폰 작은 화면에서 문자를 새로 치실 필요가 없습니다.
여기서 만들면 **가계약일이 자동으로 기록되고 신고기한이 함께 관리됩니다.**

::: warning 가계약일부터 30일입니다
거래 신고기한은 계약일로부터 30일, **가계약이 있는 경우 가계약일로부터 30일**입니다.
그래서 가계약을 저장하는 순간부터 날짜 관리가 시작됩니다.
:::

## 1. 매물에서 계약서 작성 시작하기

<!-- 스크린샷: docs/public/images/pre-contract-sms-01.png 로 저장하고 아래 주석을 푸세요 -->
![계약서 작성 시작](/images/pre-contract-sms-01.png)

상단 메뉴 **매물 → 매물 관리**에서 해당 매물을 열고 **계약서 작성**을 누릅니다.

거래 유형(매매/권리금 · 전세 · 월세)과 계약서 유형을 고르고 **다음**을 누릅니다.

계약서 화면이 열리면 **기본이 [가계약]으로 선택되어 있습니다.** 대부분의 계약이 가계약 먼저이기 때문입니다.

## 2. 계약 내용 채우기

![계약 내용 입력](/images/pre-contract-sms-02.png)

거래금액과 계약금·중도금·잔금, 그리고 매도인·매수인을 넣습니다.

**여기 넣은 내용은 본계약에서 다시 입력하지 않으셔도 됩니다.**
가계약과 본계약이 같은 계약 안에서 이어지기 때문입니다.

## 3. 가계약 관리 열기

![가계약 관리](/images/pre-contract-sms-03.png)

상단의 **가계약 관리**를 누르면 문자 편집 창이 뜹니다.

::: tip 이미 저장해 둔 계약이라면
계약서를 새로 쓰는 중이 아니라 **저장해 둔 계약을 다시 여실 때**는 이 길로 가세요.

> `계약 → 계약 관리` → 그 계약을 클릭(계약 상세) → **가계약 관리** 버튼

AI로 특약 초안을 받는 버튼도 이 창 안에 있습니다. **거래약정내용** 칸 옆입니다.
:::

왼쪽에 넣는 내용이 **오른쪽 미리보기에 바로 문자로 완성되어** 보입니다.

왼쪽에서 채우는 것은 이렇습니다.

- **가계약금**
- **본계약 체결일** — 범위로 지정하거나 "일자 협의"로 둘 수 있습니다
- **거래약정내용** — **AI작성** 으로 초안을 받거나 **복사** 로 기존 문구를 가져옵니다
- **발송대상** — 매도인용 / 매수인용
- **사무실 소개문구** — 매번 치지 마시고 `마이페이지 → 템플릿 관리 → 템플릿 설정`의
  **가계약 사무실 소개 템플릿**에 한 번 저장해 두시면 자동으로 붙습니다

기본 계약정보에는 **켜고 끌 수 있는 체크가 두 개** 있습니다.

| 체크 | 켜 두면 |
| --- | --- |
| **계약금 표시** | 계약서에 넣은 **계약금 합계**가 문자에 찍힙니다 *(2026.09 추가)* |
| **거래당사자 표시** | 매도인·매수인 이름이 문자에 찍힙니다 |

당사자 이름을 문자에 넣고 싶지 않으시면 **거래당사자 표시** 체크를 해제하세요.

::: tip 계약금을 나눠 받기로 했다면
계약서에서 **계약금 추가**로 여러 줄을 넣으셨어도 문자에는 **합계 한 줄**로 나갑니다.
회차를 각각 알려주셔야 한다면 **거래약정내용**에 적으세요.
:::

## 4. 매도인·임대인용 문자 만들기

![매도인용 문자](/images/pre-contract-sms-04.png)

발송대상을 **매도인용**으로 고르고 **매도/임대인용 양식 생성**을 누릅니다.

완성된 문자는 이런 순서로 만들어집니다.

1. 부동산의 표시
2. 거래예정금액
3. 가계약금
4. 본계약 체결일
5. 거래당사자
6. 거래약정내용
7. **가계약에 대한 효력**

7번은 분쟁이 났을 때 기준이 되는 부분이라 자동으로 들어갑니다.
해약금·위약금, 효력유지기간, 개업공인중개사의 책임 범위가 담겨 있습니다.

내용은 얼마든지 고쳐서 저장하실 수 있습니다.

## 5. 매수인·임차인용 문자 만들기

![매수인용 문자](/images/pre-contract-sms-05.png)

발송대상을 **매수인용**으로 바꾸면 **입금계좌정보** 칸이 새로 나타납니다.
은행·계좌번호·예금주를 넣고 **매수/임차인용 양식 생성**을 누릅니다.

## 6. 문자 보내기

![문자 발송](/images/pre-contract-sms-06.png)

아래쪽 가계약 양식에 매도인용·매수인용 두 칸이 각각 만들어집니다.
칸마다 **저장 · 클립보드에 복사 · 문자 발송** 이 있습니다.

현장에서는 스마트폰이나 태블릿의 크롬·삼성인터넷 주소창에
`https://bdseasy.com/` 을 입력해 로그인하시면 그대로 **문자 발송**을 누르실 수 있습니다.

## 7. 저장하고 날짜 관리 시작하기

![가계약일 저장](/images/pre-contract-sms-07.png)

**저장**을 누르면 가계약일이 기록되고 신고 기한 관리가 시작됩니다.

가계약일이 비어 있으면 "가계약일을 입력하시겠습니까?" 하고 물어봅니다. 날짜는 직접 고치실 수 있습니다.

## 8. 신고기한 확인하기

![계약 관리 D-30](/images/pre-contract-sms-08.png)

상단 메뉴 **계약 → 계약 관리**에서 전체를 봅니다.

계약단계(가계약·본계약)와 **거래신고여부(미완료·완료)** 로 걸러 볼 수 있고,
목록에 **가계약일**과 **(D-30)** 이 함께 보입니다.
신고를 아직 안 한 매매 계약이 몇 건인지 화면 위쪽에 경고로 뜹니다.

같은 일정이 `마케팅 → 일정 관리` 캘린더에도 표시됩니다.

## 여기서 막히셨다면

::: details 본계약으로 어떻게 넘어가나요
같은 계약서 화면에서 **[가계약] / [본계약]** 토글을 **본계약**으로 바꾸시면 됩니다.
가계약에서 넣은 내용이 그대로 남아 있습니다.
:::

::: details 특약 문구를 매번 새로 쓰기 번거롭습니다
거래약정내용에서 **AI작성**을 누르면 초안이 나옵니다.
**초안은 초안입니다.** 특약은 분쟁 때 책임 소재를 가르는 문장이므로 반드시 읽고 고치세요.

계약서 특약사항에는 **자주 쓰는 특약**이 기본 118건 들어 있습니다.
자주 쓰시는 문구는 `마이페이지 → 템플릿 관리 → 자주 쓰는 특약 관리`에 등록해 두시면
계속 불러 쓰실 수 있습니다.
:::

::: details 가계약 문자에 고객 이름이 들어가지 않게 하고 싶습니다
가계약 관리 창의 기본 계약정보에서 **거래당사자 표시** 체크를 해제하세요.
:::

::: details 알림이 너무 많이 옵니다
계약 상세의 **계약 후 관리** 탭 아래 일정관리에서
계약일·계약금·실거래 신고기한(D-20, D-10, D-5 …) 항목마다 **알림을 개별로 끌 수 있습니다.**
:::
