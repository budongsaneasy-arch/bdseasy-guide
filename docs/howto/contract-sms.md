# 계약 단계별 안내문자 보내기

> **걸리는 시간** 한 건에 약 2분 &nbsp;·&nbsp; **미리 준비할 것** 거래당사자가 등록된 계약서

계약금·중도금·잔금·중개보수 **각 단계마다** 당사자에게 보낼 문자를 만들어 보냅니다.

## 왜 문자로 보내나

계약을 하고 나면 당사자에게 연락해서 챙겨야 할 일이 많습니다.
그런데 전화로만 하면 두 가지가 남지 않습니다.

- **근거가 남지 않습니다**
- 상대방이 들은 내용을 **다시 받아 적어야** 합니다

준비서류처럼 항목이 많은 안내는 특히 그렇습니다.
문자로 보내면 근거가 남고, 상대는 보면서 준비할 수 있습니다.

## 1. 안내문자 열기

![거래당사자 안내 문자 편집](/images/contract-sms-01.png)

계약 관리 화면 **계약서 관리** 탭 상단의 **안내문자**를 누릅니다.
(AI 권리분석 버튼 옆입니다)

::: warning 거래당사자를 먼저 등록하세요
당사자가 없으면 *"등록된 매도인/임대인이 없습니다. 거래 당사자 등록 후 이용해주세요"* 가 나옵니다.
계약서의 **3. 거래당사자** 에서 매도인·매수인을 먼저 넣어야 합니다.
→ [아파트 매매계약서 쓰기](/howto/contract-apartment)
:::

## 2. 단계와 받는 사람 고르기

**문자양식** 탭이 네 개입니다.

> 계약금 · 중도금 · 잔금 · 중개보수

단계를 고르고 **받는사람**에서 `[매도] 고객명` 또는 `[매수] 고객명`을 고릅니다.
같은 단계라도 매도인과 매수인에게 보낼 내용이 다릅니다.

::: tip 공동명의면 받는사람에 전원이 나옵니다
매도인이 **공동명의로 여러 명**인 계약서라면 그 사람들이 모두 받는사람에 올라오고,
**한 번 만든 문자를 함께 보낼 수 있습니다.** *(2026.09 개선)*
<!-- 확인 필요: 공동명의 2인 이상 계약서로 받는사람 목록이 실제로 어떻게 보이는지 확인하지 못했습니다 -->
:::

::: tip 중도금이 여러 번이면 회차별로 찍힙니다
계약서에서 **중도금 추가**로 1차·2차를 나눠 넣으셨다면
중도금 문자에 **회차별로 각각** 들어갑니다. *(2026.09 개선)*
<!-- 확인 필요: 중도금 2회차 이상 계약서로 실제 출력을 확인하지 못했습니다 -->
:::

## 3. 양식 생성하고 보내기

**양식생성**을 누르면 문자 본문이 자동으로 만들어집니다.
**미리보기**로 먼저 확인할 수 있습니다.

만들어진 뒤 **저장 · 복사 · 문자발송** 중에서 고릅니다.

## 어떤 내용이 들어가나

계약금 단계의 매도인용을 예로 들면 이렇게 만들어집니다.

1. 인사말
2. **계약서 작성 일시**
3. **매도인 준비서류** — 신분증 / 도장 / 계약금 입금 받을 계좌번호(예금주 성명 포함)
4. **임차인이 있는 경우** 권리관계 확인서류 — 임차인 확정일자 부여현황 / 전입세대 확인서 / 임차인 임대차 계약서
5. **대리인이 계약하는 경우** — 위임장, 인감도장, 인감증명서, 대리인 신분증

::: tip 임차인 서류는 미리 요청하는 것입니다
문자에 이런 안내가 함께 들어갑니다.

> 확정일자 및 전입세대 확인서는 계약 전 임차인에게 확인을 위해 요청드리는 서류입니다.

계약 당일에 없으면 확인이 안 되는 서류라 미리 챙기게 하는 장치입니다.
:::

## 중개보수 단계는 계좌가 붙습니다

**중개보수** 탭에서는 **계좌번호 선택**이 나옵니다.

> 개인 / 주-사용 / 보증금 계좌

**계좌관리 이동**으로 계좌를 등록·수정할 수 있습니다.

## 사무실 소개문구

네 탭 모두 아래에 **사무실 소개문구**가 붙습니다.
**수정**을 눌러 바꿀 수 있고, 한 번 저장해 두면 계속 쓰입니다.

## 여기서 막히셨다면

::: details 받는사람 목록이 비어 있습니다
계약서에 거래당사자를 등록하지 않으셨습니다.
**임시추가(고객관리불가)** 로 넣은 경우에도 목록에 나오지 않을 수 있으니,
**고객 목록에서 추가** 또는 **새로 추가하기**로 넣으세요.
:::

::: details 문자가 너무 깁니다
준비서류가 많으면 길어집니다. 해당되지 않는 부분(임차인·대리인)은
생성된 본문에서 지우고 보내시면 됩니다.
:::

::: details 어떤 문자가 반응이 좋았는지 알고 싶습니다
단계별로 보낸 내용이 계약에 기록됩니다.
어떤 유형의 고객에게 어떤 내용으로 보냈을 때 효과가 좋았는지 비교해 보세요.
:::
