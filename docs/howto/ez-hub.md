# 이지허브에 매물 올리고 의뢰 받기

> **걸리는 시간** 처음 한 번 약 10분 &nbsp;·&nbsp; **미리 준비할 것** 접수해 둔 매물, 사무소 정보

네이버 광고와 달리 **별도 비용이 들지 않습니다.**
매물을 보낼 때 광고사에 **이지**를 함께 고르면 그것으로 끝입니다.

## 이지허브가 무엇인가

![이지허브 첫 화면](/images/ez-hub-01.png)

**이지허브(`bdsez.com`)는 일반인이 보는 부동산 포털입니다.**
중개사가 쓰는 부동산이지와는 다른 사이트이고, 손님이 직접 들어와 매물을 봅니다.

중개사에게 중요한 것은 **매물이 두 곳에 동시에 걸린다**는 점입니다.

| 어디 | 주소 | 무엇이 보이나 |
| --- | --- | --- |
| **내 사무소 홈페이지** | `내아이디.r.bdsez.com` | **내 매물만** 나옵니다. 내 사무소 소개가 함께 붙습니다 |
| **이지허브 전체** | `bdsez.com` | 이지허브를 쓰는 **모든 중개사의 매물**이 지도에 함께 나옵니다 |

한 번 올리면 두 곳에 같이 올라가고, **내리면 두 곳에서 같이 내려갑니다.**
따로 관리하실 것이 없습니다.

::: tip 손님은 이지허브에서 이런 것을 합니다
지도에서 매물을 찾아보고, **매물접수**(내 물건을 내놓기)와 **중개의뢰**(원하는 조건 알리기)를
버튼으로 넣을 수 있습니다. 가입하면 **AI 챗봇**으로 물어볼 수도 있습니다.

손님이 넣은 두 가지는 모두 **`고객 → 허브 의뢰 관리`** 로 들어옵니다. → [5단계](#_5-들어온-의뢰-받기)
:::

## 1. 내 홈페이지 주소부터 확인하세요

`마이페이지 → 설정` 의 **중개사무소 정보** 탭을 끝까지 내립니다.

![My홈페이지(허브) ID](/images/ez-hub-04.png)

| 항목 | 무엇을 하나 |
| --- | --- |
| **My홈페이지(허브) ID** | 내 홈페이지 주소입니다. 옆에 `(내아이디.r.bdsez.com)` 로 완성된 주소가 보입니다 |
| **홈페이지(허브) 사무실 위치 지정** | 지도에서 **사무소 핀이 찍힐 자리**를 정합니다. **변경하기** 로 옮기고, **초기 주소로 이동** 으로 되돌립니다 |

::: tip 이 주소를 명함과 문자에 쓰세요
`내아이디.r.bdsez.com` 은 **내 매물만 모인 페이지**입니다.
손님에게 "제 매물은 여기 다 있습니다" 하고 보낼 수 있는 주소가 생기는 것입니다.

내 홈페이지 위쪽에는 **전체포탈** 버튼이 있어서 손님이 이지허브 전체로도 넘어갈 수 있습니다.
:::

## 2. 매물 올리기

**네이버 광고와 같은 화면에서 같이 보냅니다.** 따로 하는 일이 아닙니다.

`매물 → 매물 관리`에서 그 매물 줄의 **광고하기**를 누르면 **매물 전송** 화면이 열립니다.
맨 위 **광고사**에서 **이지**를 고르시면 됩니다.

> 광고사 \* &nbsp; `렛츠` &nbsp; `이지` &nbsp; \* 최소 한개 이상 선택 필수

**렛츠와 이지를 둘 다 고르면 네이버와 이지허브에 함께 나갑니다.**
전송 폼을 채우는 방법은 네이버 광고와 같습니다.
→ [네이버에 매물 광고하기](/howto/naver-ad)

::: warning 이지만 고르셔도 매물 정보는 정확해야 합니다
이지허브도 **일반인에게 공개되는 광고**입니다. 네이버가 아니라고 해서
표시·광고 의무가 없어지지 않습니다. 특히 **관리비 금액은 「원」 단위**로 넣으세요.
→ [관리비 금액은 원 단위로](/howto/naver-ad#_5-거래정보와-상세정보-채우기)
:::

## 3. 올라간 모습 확인하기

`매물 → 이지 광고 관리`에 이지허브로 보낸 매물이 모입니다.
그 줄의 **바로가기**를 누르면 **손님에게 보이는 화면 그대로** 열립니다.

올린 매물 화면에는 이런 것들이 함께 나옵니다.

| 무엇 | 설명 |
| --- | --- |
| **공유** | 그 매물 페이지 링크를 손님에게 보낼 수 있습니다 |
| **매물요약표 다운로드** | 그 매물의 요약표를 내려받습니다. **담당자 정보도 함께 찍힙니다** *(2026.09 개선)* |
| **허위매물 신고하기** | 손님이 신고할 수 있는 버튼입니다. 매물 정보를 최신으로 유지하셔야 합니다 |
| **중개사무소 이동** | 내 사무소 페이지로 넘어갑니다 |

::: tip 권리분석을 해 두면 손님이 먼저 알아봅니다
이지허브 지도 왼쪽 아래에 **권리분석 완료매물** 필터가 있습니다.
`AI 권리분석`을 돌려 둔 매물은 이 필터에 걸려 **손님이 먼저 골라 볼 수 있습니다.**
권리분석을 하려면 **공적장부를 먼저 떼셔야** 합니다.
→ [공적장부 한 번에 떼기](/howto/public-records)
:::

## 4. 손님이 넣을 수 있는 두 가지

이지허브 오른쪽 위에 버튼이 두 개 있습니다. **무엇이 다른지 알고 계셔야** 전화로 안내할 수 있습니다.

![중개의뢰 입력 창](/images/ez-hub-02.png)

| 버튼 | 누가 쓰나 | 무엇을 넣나 |
| --- | --- | --- |
| **매물접수** | **물건을 가진 사람** — 내놓겠다 | 거래유형 · 매물유형 · 중개방식 · 주소 · 희망가격 · 희망날짜 · 기타 요구사항 · 이름 · 연락처 |
| **중개의뢰** | **물건을 찾는 사람** — 구하겠다 | 위와 같고, **희망사항**(옵션 · 역세권 · 주차 · 반려동물 · LH대출)이 더 있습니다 |

두 창 모두 **중개방식**에서 `일반중개` 와 `전속중개(우대)` 중 하나를 고르게 되어 있습니다.

::: tip 전속중개로 들어온 의뢰를 먼저 보세요
손님이 **전속중개(우대)** 를 골랐다면 다른 사무소에 같이 내놓지 않겠다는 뜻입니다.
연락 순서를 정하실 때 참고가 됩니다.
:::

## 5. 들어온 의뢰 받기

`고객 → 허브 의뢰 관리`로 들어옵니다. 화면 위에 이렇게 적혀 있습니다.

![허브 의뢰 관리](/images/ez-hub-03.png)

> 이지 허브 개인 홈페이지를 통해 의뢰된 매물접수·중개의뢰 입니다. (`내아이디.r.bdsez.com`)

걸 수 있는 조건은 네 가지입니다.

| 조건 | 고를 수 있는 것 |
| --- | --- |
| **요청종류** | 전체 / **매물접수** / **중개의뢰** |
| **처리상태** | 전체 · (처리 단계) |
| **검색어** | 이름 · 연락처 · 주소로 찾습니다 |
| **접수일** | 날짜 범위 |

::: warning 의뢰 관리와 헷갈리지 마세요
이름이 비슷한 메뉴가 셋입니다. **들어오는 길이 다릅니다.**

| 메뉴 | 누가 넣었나 |
| --- | --- |
| `의뢰 접수` · `의뢰 관리` | **내가** 전화·방문으로 받아서 직접 넣은 의뢰 |
| **`허브 의뢰 관리`** | **손님이** 이지허브에서 직접 넣은 의뢰 |
:::

::: tip 받은 뒤에는 고객으로 옮기세요
허브로 들어온 손님도 앞으로 계속 볼 분이면 **고객으로 등록**해 두셔야
의뢰·계약·문자가 한 사람 아래로 모입니다.
→ [고객을 왜 한 곳에 모으나](/concept/why-one-customer)
:::

## 6. 거래가 끝나면 종료하기

`매물 → 이지 광고 관리`에서 그 줄의 **종료하기**를 누릅니다.

::: danger 이지허브는 저절로 내려가지 않습니다
이지허브 광고의 **노출기간이 2099년까지**로 잡힙니다. 그대로 두면 계속 걸려 있습니다.
팔린 매물이 남아 있으면 **표시·광고 위반**입니다.

네이버에도 광고 중이셨다면 **`N 광고 관리`에서 따로 한 번 더** 종료하셔야 합니다.
→ [거래가 끝나면 광고를 종료하세요](/howto/naver-ad#_10-거래가-끝나면-광고를-종료하세요)
:::

## 여기서 막히셨다면

::: details 내 홈페이지 주소가 안 보입니다
`마이페이지 → 설정 → 중개사무소 정보` 탭을 **끝까지 내려야** **My홈페이지(허브) ID**가 나옵니다.
위쪽 중개사무소명·주소만 보고 없다고 판단하지 마세요.
사무소 홈페이지는 **플러스 요금제**에 포함된 기능입니다.
<!-- 확인 필요: 베이직 요금제에서도 이지허브 전체 포털에는 노출되는지 확인이 필요합니다 -->
:::

::: details 지도에 우리 사무소 핀이 엉뚱한 곳에 있습니다
`마이페이지 → 설정 → 중개사무소 정보`의 **홈페이지(허브) 사무실 위치 지정**에서
지도를 옮기고 **변경하기**를 누르세요. 잘못 옮기셨으면 **초기 주소로 이동**으로 되돌립니다.
:::

::: details 이지허브에 올렸는데 손님 문의가 없습니다
매물 화면 아래쪽 **매물 설명**이 그대로 손님에게 보입니다. 비어 있으면 눈에 띄지 않습니다.
`AI 광고설명`으로 초안을 받아 손보시는 편이 빠릅니다.
→ [매물 접수하기](/howto/property-register)
:::

::: details 관리비가 이상한 숫자로 나옵니다
매물 전송 화면의 **관리비금액** 칸에는 **단위 표시가 없습니다.**
25만원이면 `250000`처럼 **원 단위**로 넣으셔야 합니다.
→ [관리비 금액은 원 단위로](/howto/naver-ad#_5-거래정보와-상세정보-채우기)
:::

::: details 손님이 허위매물로 신고했다고 합니다
매물 화면에 **허위매물 신고하기** 버튼이 있습니다.
거래가 끝났거나 조건이 바뀐 매물은 **바로 종료하거나 수정**하세요.
이지허브 매물 화면 아래에도 *"거래 완료 또는 매물 정보 변경 사실이 즉시 반영되지 않을 수 있으므로"*
라는 안내가 붙어 있지만, **관리 책임은 중개사에게 있습니다.**
:::
